# AIDD 数据可得性与普通 Harness 上下文对照预检

> 2026-09-26。先做公开数据只读预检，后在独立批准下运行普通 Harness 提前压缩对照；公开数据检查与付费 Agent 轨迹分开记录。没有泄漏结论。

## PBCNet2.0 的可核查范围

论文的数据可得性段指向 [Zenodo 新版记录 18299525](https://zenodo.org/records/18299525)。它标为 open，许可为 CC BY 4.0；其中训练数据包括约 5.4 GB 的 BindingDB 压缩包及大小不同的 CSV。仓库 [PBCNet2.0](https://github.com/YuJie-0202/PBCNet2.0) README 仍链接受限的[旧版记录 15656365](https://zenodo.org/records/15656365)，因此运行前要明确锁定新版数据与文件哈希，不能只照 README 下载。此次没有下载大包。

只读表头抽样确认：新版训练 CSV 有 `lig1`、`lig2`、`smile1`、`smile2`、`similarity`、`Label` 等字段；仓库的 FEP 直接输入 CSV 有配体对、标签和预测列；SAR-Diff 标签 CSV 有 assay、target、SMILES 和标签；突变预测 CSV 有配体对、标签和预测列。仓库也含对应结构输入。**这只证明存在做审计所需的一部分字段，不证明每项公布指标都可复算，也不证明训练／测试之间有或没有泄漏。**

进一步的可复算小检查已完成：只取 Zenodo 的 `training_data_8_6.csv`（38,413,018 字节、85,998 行；下载 MD5 与记录一致），以及 GitHub 提交 `b3563f119864e51177af363a690419214d624194` 下 16 个 `data/SAR-Diff/*/label.csv`（154 行）。[审计脚本](../scripts/audit-pbcnet-public-overlap.py)只去除 SMILES 首尾空白后做**原始字符串完全相等**：154 行中 29 行、对应 28 个不同 SMILES，在这个训练 CSV 的 `smile1` 或 `smile2` 中出现。两侧的 SMILES 字段在这批文件里都不缺失；逐文件哈希与计数保存在 `.local/benchmarks/research-weekly-loop/aidd-next-preflight/pbcnet-public-data/exact-overlap-audit.json`，不把分子或行内容提交进仓库。

这 **不是泄漏率**。论文称训练来自 BindingDB 2023.12，SAR-Diff 测试来自 ChEMBL，并称后者为 held-out；目前尚不知道这份 CSV 是否覆盖实际训练全集、重叠配体是否属于相同蛋白／测量、测试集划分到底要求配体不交叠还是只要求系列或样本不交叠，也没有规范化结构、配对级或日期级比较。论文报告的训练规模是 860 万复合物对，而该 CSV 只有约 8.6 万行，不能把它直接当成完整训练集。应先读补充材料和训练脚本／数据版本说明，再决定这个重叠是否构成对特定结果的有效反证。

下一步按公开数据先登记三张映射表：训练配体 ID／规范化结构／蛋白与日期，测试配体 ID／结构／目标与系列，论文图表的样本／指标定义。分别统计精确 ID 重叠、规范化结构重叠、骨架与系列近邻、蛋白同源、以及日期先后；每项先报告可映射分母和缺失率，再给比例。若原始记录缺日期、蛋白序列或拆分文件，对相应结论标为不可核查。不要把“发现近邻”直接称为模型泄漏；还要结合论文训练协议和评测定义判断。

## 普通 Harness 的窄上下文强基线

初次 AIDD 原生试点中，路由向 Harness 声明的窗口为 1,000,000 token。已加载的 `dsh-compaction-basic` 默认在约 80% 压力处触发；首轮最大提示约 110,009 token，因此轨迹中没有压缩事件。现在的 [提前压缩配置](../config/aidd-early-compaction.patch.yml)将该插件阈值改为 5%（约 50,000 token）、保留最近 12,000 token；摘要输出上限由默认 8,192 调至费用代理允许的 8,000。与原[受限工具配置](../config/aidd-scoped-baseline.patch.yml)合成的 `dsh --dump-config` 无模型检查已通过。它是普通上下文管理基线，**不是 Motif**。

若获准进行新一轮付费对照，固定同一 AIDD 任务提示词、已审核来源范围、20 个 MCP 工具、Flash 路由和每轮预算。不把首轮结果或本预检的答案喂给 Agent。此次提前压缩组用独立新会话自由执行，记录压缩触发、摘要请求及其 token、工具调用、缓存命中／失效、续写、总时间和所有失败。已有原生组记录可作**探索性同配置参考**，但只有一条样本且原生交付未过质量门，不能据此报告显著节省或“每份合格交付”的成本。正式机制比较要预先冻结评审标准，在更多独立任务或重复运行中对原生、上下文优化和 Motif 使用同一来源快照。若新版公开数据加入任务输入，需要各组都在同一冻结数据版本上重新运行，不能只给其中一组。

正式试验前需冻结执行预览：准确外发资料、配置／提示词哈希、请求数与美元上限、输出位置和评审表。项目 `AGENTS.md` 对付费调用及修改用户文件要求预算与预览／确认；本预检本身不构成授权，后续用户回复“继续”才触发本次对照。

[运行入口](../scripts/run-aidd-context-baseline.py)已完成无模型预览与语法检查。它复用此前获准的来源范围，但另要求此次运行的独立批准记录；最多 30 次 Agent 请求，摘要请求额外计入本机费用代理账本，总预留上限 US$2。由于摘要可能占用预算，这个上限不保证 Agent 一定走满 30 步。新会话结果只写入 `.local/benchmarks/research-weekly-loop/aidd-next-preflight/paid-context-baseline-01/`，不覆盖原试点。

研究者于预览后回复“继续”，本次独立批准记录已锁定同一来源、提示词和配置哈希。实际运行 15 次 Agent 请求、2 次摘要请求，含摘要共 454,476 token、71 次 MCP 调用、US$0.6870657 本机保守费用预留；首段达到输出上限，同会话在原批准剩余额度内续写完成。人工初审仍发现条件性实验数据规模被写成通用硬要求、无参数基线被要求同参数量等错误，**不合格**。原始与初审见 `.local/benchmarks/research-weekly-loop/aidd-next-preflight/paid-context-baseline-01/RESULT.md`；实际供应商扣费尚未对账。

## 压缩事件与 Motif 轨迹的边界修复

本轮 Harness 在第一次触发时裁短 18 个过长工具结果，并另外做两次模型摘要。裁短结果以**同一个工具调用 ID** 追加为 `surfaceOp: replace` 的 `tool/result` 事件，原始结果仍在持久日志中。此前 `dsh_trajectory.py` 取该 ID 的最后一个结果，可能把被裁短的模型可见文本当作真实工具观察，令 Motif 的观察摘要失真。现已改为只消费原始追加结果，忽略上下文替换事件；[回放检查脚本](../scripts/audit-dsh-compaction-invariance.py)在这条真实轨迹上确认：去掉 18 个替换事件前后，71 条工具记录的观察摘要、合格状态、参数来源完全一致，仍为 32 条合格参数边。对应回放摘要保存在私有运行目录的 `compaction-invariance-audit.json`；相关回归测试已通过。

这个修复保护了**轨迹证据**，没有让 Motif 接管 AIDD 任务，也没有证明语义摘要可靠。来源覆盖、逐步费用和工具使用三个审计在包含／移除 18 条替换事件的两种回放中相同；逐步费用仍为 15 次 Agent 消息、71 次工具调用、370,288 token，另有两次摘要请求的 84,188 token。工具使用报告还补认了外层未报错、正文却返回 `status: unavailable` 的一次失败；这条轨迹现与逐步费用审计一致，均为 7 次失败。Distil 的离线工具结果回放也改为只读取原始结果，避免把同一次调用的缩写重复计入可压缩量；尚未据此重跑 Distil 对照。第二次摘要与最终材料继续沿用对“9 万实验样本”的过强转述；科学主张仍须对当前版本原文和人的评审重新核验。下一个公平实验应让 Motif 结构执行与普通提前压缩同时启用，并与仅提前压缩比较合格交付总成本；跨任务认证还需要第二个独立研究任务。

两份已完成的 AIDD 报告现按同一提示词和四个原有必答点生成了 A/B 匿名标签的私有审阅包，位于 `.local/benchmarks/research-weekly-loop/aidd-next-preflight/blind-review-01/`；标签映射单独保存。研究者可先独立评分，再查看方法与用量。它属于**已有结果的开发阶段复核准备**：此前已有非盲初审，不能称为正式预注册盲评，评分前也尚无合格交付结论。
