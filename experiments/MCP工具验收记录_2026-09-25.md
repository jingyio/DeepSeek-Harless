# MCP 工具验收记录（2026-09-25）

这轮只检验连接、受控写入和跨工具数据交接，不运行 MotifAgent，也不把连接测试算作科研 benchmark 成绩。未调用付费模型。个人账号、笔记内容、OAuth 凭据和原始响应留在被忽略的 `.local/`。

| 服务 | 实际验收 | 当前结论 |
| --- | --- | --- |
| Zotero | 本机 9.0.6；上游 41 工具，`zotero_write_capabilities` 返回不可写；默认桥接只列 21 个读／状态工具；`get_recent`、真实 AIDD 条目元数据及 6 条批注读取成功 | 读取可用；本地写入需 Zotero 10+ 的另行授权与升级验收 |
| Obsidian | HTTPS MCP 列 19 工具；`vault_list` 成功；经 MCP 新建、读取、永久删除一篇专用临时测试笔记 | 读写路径可用；未修改现有研究笔记 |
| Python／Quarto | 沙盒内 pandas 复算得到 5；Quarto 输出 HTML；已有越界写入测试 | 本机私有工作区可用，仍需在不同真实数据格式上验收 |
| Gmail | 桥接列 13 工具，真实 `list_email_labels` 成功；自发自收测试邮件由研究者在审核页确认，Gmail API 返回消息 ID，随后用只读 MCP 按 ID 成功读取邮件头；本地状态 `sent`，同一编号不能再次发送 | 发信与只读回查通过；附件、其他收件地址和真实科研沟通未验收 |
| Google 日历 | 桥接列 11 工具，真实 `list-calendars` 成功；建立专用「SSS MCP Test」日历；测试事件进入审核页，参与者为空；本地测试覆盖重复创建拦截与不明结果停机 | 实际创建、读取、清理待研究者在页面确认后验收 |
| 文献发现 | 默认 9 个只读 MCP 工具；OpenAlex 检索、按 DOI 定位、被引检索及 Crossref DOI 核对成功；Europe PMC 按公开 DOI 定位开放全文、列出 19 个章节并读取有界片段成功；arXiv 普通主题检索和按编号查询成功 | Google Scholar 可选第三方接入只做模拟测试，尚无凭据；不同学科、非开放全文及证据质量仍需真实任务验收 |

默认 Harness 已重启并连接六个 MCP 服务，连接器实际列出的工具共 79 个：Zotero 21、Obsidian 19、Gmail 13、日历 11、本地 Python／Quarto 6、文献发现 9。`npm run connectors:doctor` 对六个服务逐一完成握手、列工具与代表性只读调用，全部通过；主服务也在本机监听。`npm run test:structure` 为 152/152。Google Scholar 可选工具因无第三方凭据未暴露，不计入 79 个。健康检查不证明所有列出的工具都已逐个执行。

跨工具无模型验收使用真实 AIDD Zotero 条目的 DOI 与批注数量：OpenAlex 与 Crossref 分别定位同一 DOI，Python 生成元数据核对输入，Quarto 渲染私有 HTML。原始元数据和报告位于 `.local/python-workspace/connector-chain/` 与 `.local/python-workspace/rendered/report.html`；它只检验数据交接，不输出科研结论。邮件和日历的独立连接测试不冒充与该 AIDD 决定有关的真实沟通和排期。

下一道验收门槛：研究者在本机审核页确认专用日历事件后，核对远端实际状态、重复保护，并清理测试事件。完整科研 benchmark 仍需研究者圈定真实决定、来源和后续事件；MotifAgent 的全链运行另行评测。
