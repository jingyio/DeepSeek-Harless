# 两项增量任务中 Motif 跳轮未带来净省费的复核

本记录复核已有的 AIDD 突变数据增量任务和 serving 批注影响任务，回答一个具体问题：运行时各成功跳过一次模型判断，为什么整题没有省钱。结论是，两次跳过都只覆盖了一组 Zotero 读取。普通 Agent 在相近位置已把其他读取合进同一轮；后续仍需模型判断资料和写结论。AIDD 诊断组还走了更长的计算及错误恢复路线。现有轨迹能证明局部接管真实发生、整题费用没有下降，但不能把两次运行路线的全部差异归因于 Motif。

## 口径与证据

这里只比较普通 DeepSeek Harness Agent 与 Motif 运行，不使用直接脚本结果推断普通 Agent 的行为。两题都读取了真实 MCP 来源，原始日志和逐轮统计留在 `.local/benchmarks/research-weekly-loop/`，不随本记录提交。费用是实验账本按 API usage 算出的代理值，尚未与供应商账单核对，也未计入人工修订。AIDD 使用 DeepSeek Flash 且 `reasoning_effort="off"`；较早的 serving 实验使用高推理档，**不能把两题费用水平横向比较**。serving 是历史批注模拟到来，AIDD 是同一研究决定的历史增量回放；均不是新的独立留出题。

| 任务与运行 | 模型请求 | 验证跳过 | MCP 调用及失败 | 未命中输入 | 缓存命中输入 | 输出 | 费用代理 | 用时 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| AIDD 普通 Agent | 45 | 0 | 76／7 | 46,231 | 1,698,944 | 21,422 | $0.049769 | 122.0 秒 |
| AIDD Motif 诊断 3 | 52 | 1 | 76／15 | 59,881 | 2,259,200 | 24,594 | $0.061032 | 145.2 秒 |

| serving Motif 诊断 7 | 7 | 1 | 25／0 | 39,422 | 106,496 | 9,949 | $0.02440 | 48.1 秒 |

AIDD 诊断组比普通组多 7 次模型请求、$0.011263 和 23.1 秒；serving 两组模型请求同为 7 次，Motif 多 $0.00421 和 3.4 秒。两组缓存命中输入都更多，因此按总 token 或单次“跳过”计收益会误导；表中比较使用实际记录的缓存计价费用代理。

## serving 的跳过为何没有减少整题请求

普通 Agent 第 3 个模型步骤一次选了 4 条 Zotero 批注、1 条书目、1 处笔记和 1 处 PDF，共 7 次工具调用。Motif 在相应位置不用模型，验证后自动读取 4 条批注和 1 条书目，共 5 次工具调用；这是实在的局部跳过。不过它**没有接管笔记和 PDF**。后续 Agent 仍发出模型请求去读这些来源、继续核对论文并形成判断，最终模型请求仍为 7 对 7。Motif 路线还读了 9 次 PDF 页，普通路线读了 7 次；两边取证范围已经变化，不能把多出的费用精确记到某一个读取上。

从整题账本看，Motif 比普通组多 7,816 个未命中输入、19,840 个缓存命中输入和 1,462 个输出 token。这是费用增加的直接计量依据，而“为什么 Agent 后来选择更多 PDF 页”无法由这一次自由运行证明为 Motif 所致。也不能把被跳过的第 3 步成本当成净节省：普通 Agent 原本用这一轮同时决定了 Motif 未覆盖的笔记和 PDF 读取。

## AIDD 的跳过为何被长路线盖过

Motif 在第 20 步从已核验的 Zotero `item` 句柄直接读取条目，模型请求数为零，工具结果通过版本和类型校验。普通 Agent 的相近读取位于第 6 步，同一模型步骤还选了 2 次笔记读取；两条路线在此之前已经不同。故这里同样只能证明局部跳过，不能断言普通组本会有一个完全独立、可省掉的模型请求。

在诊断组，`run_python` 为 34 次，普通组为 27 次。诊断组工具失败 15 次，其中 12 次发生在笔记或文本读取相关接口；普通组失败 7 次，其中没有笔记读取失败。诊断组曾把 `kind=text` 的来源句柄交给要求 `kind=note` 的接口，并继续尝试不同摘录接口和行范围。这一段造成了多轮可见的错误恢复，也使旧 Obsidian 状态复核不完整。另有计算探索与写稿路线差异。与普通组相比，诊断组多 13,650 个未命中输入、560,256 个缓存命中输入、3,172 个输出 token；这些是整题多付费的计量事实。**不能证明 Motif 的一次接管造成了全部额外探索或错误**，但一次短读取的局部收益显然不足以抵消本次观察到的路线波动。

原始冻结 Motif 组的 AIDD 请求数较少，却没有一次经过验证的模型请求跳过；serving 原始冻结 Motif 组也没有跳过，且比普通组更贵。上述成功跳过来自后续修复和阈值诊断，不能当作原冻结版本的正式增益成绩。

## 质量边界与下一步判据

serving 两份交付的技术复核暂定为 Motif 诊断组 7／10、普通组 6／10，都低于预定 8／10 合格线；评审前已见路线映射，不能称独立盲评。AIDD 突变数据增量答案虽报告相同的关键统计，Motif 诊断组自述未能完整读取旧 Obsidian 状态；尚无通过冻结量表的交付。因此目前既不能报告“合格交付成本”，也不能因局部跳过宣布方法有效。

这两次失败指向一个更窄、可检验的条件：需要找到普通 Agent **自然形成单独模型判断轮次**的多步参数链；结构接管要覆盖整段，同时保留来源版本、类型和结果校验。下一次测试前应先修复 `text` 与 `note` 句柄契约，并冻结一项新的独立研究决定及评审门槛。若普通 Agent 仍把语义判断与结构读取合在同一轮，或结构接管后没有减少整题模型请求和缓存计价费用，就应如实缩小 Motif 在该场景的收益主张。
