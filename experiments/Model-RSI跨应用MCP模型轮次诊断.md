# Model RSI 跨应用 MCP 模型轮次诊断

2026-09-27。研究问题是：研究者是否应为“模型内部、跨任务持久且可更新的能力状态”启动训练型最小原型，以及第一项反证实验怎样排除检索、长上下文和题目记忆的解释。Agent 只读取此前批准的四份 Model RSI 资料（Obsidian 笔记、开放问题、week6 文本、week7 PDF）和公开论文。没有应用写入。原始提示、事件、回答、逐请求用量和审计结果均留在忽略版本控制的 `.local/benchmarks/research-weekly-loop/model-rsi-handle-cost-only-20260927/`，不提交私人材料。

## “结构相似”与“跳过模型”之间的差距

Agent 在 AIDD 与 Model RSI 这两个不同科研决定中，都实际传递了 `pin_scoped_source` 返回的 `source_id`，再读取笔记、文本或 PDF。跨任务观察到三类 `pin → read` 参数边。这说明应用来源可以通过版本句柄形成结构性依赖，而非只留在自由命令文本中。

严格编译结果仍为 **0 个可执行候选**。AIDD 的相应读取常请求非默认行／页、经过失败读取或其他未列入本次合约的工具；Model RSI 的笔记／文本读取也自行选择了非默认范围。对 PDF，仅 Model RSI 有一条无屏障的默认范围实例，AIDD 没有。因此没有一种边同时在两题中获得安全、精确参数的见证。不能为了得到候选而把“要读哪一页”自动改成默认第一页，或事后忽略失败调用。

更窄的模型轮次审计显示：Model RSI 有 **1 个**跨轮安全读取目标，但那轮同时有其他工作；**0 个**完整模型轮次由安全读取构成。两题的结构相似尚不能带来一次可验证的模型请求跳过。AIDD 的提前压缩同题试跑曾有 2 个宽松的候选轮次，但那只是**上界机会**，不是执行后的节省；其数据不能与本轮拼成跨任务收益。

## 科研质量与下一步

本轮生成了一份完整的中文决定材料，建议先做“能力支持但实例不相交”的反证实验，暂缓训练型原型；列出 Metis、EvoAgentBench、MemTrapBench 的版本、页码、结果和未读页段。**这只证明 Agent 完成了交付形式**；关键论文数值、来源覆盖和建议是否被研究者采纳尚未人工核实，不能计为合格科研交付。arXiv 元数据搜索在本轮返回 HTTP 406，Agent 转而用 OpenAlex 定位并读取 arXiv PDF；这项连接器可靠性缺口也应计入使用体验。

下一步先改善来源读取的契约和失败可观测性，再选一个**第三个独立科研决定**做留出：它应自然包含 Obsidian／Zotero 既有判断、公开新论文、一次实际数据或批注变化，以及需研究者审核的行动。不得把同题重复或增量轮次冒充独立任务。Motif 若能在留出题无模型执行经见证的局部读取，仍要与普通缓存、预取和窄上下文在相同工具与资料条件下比较。只有质量过门槛且总费用与人工修订时间下降，才报告真实增益。
