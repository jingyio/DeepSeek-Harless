# 科研决定任务集扩展：导师审阅摘要

## 已形成的可审阅材料

原有组会决定链覆盖多项合成科研决定，并在三项独立留出题上稳定跳过完整 DeepSeek 请求；但任务结构过于统一，强脚本比 Motif 更便宜。这一负结果已固定在《组会决定链：跨任务跳过模型请求与强脚本基线》。因此只增加同形表格题无法解决导师会问的“是否只对一种固定流程有效”。

新增 `benchmarks/research_decision_portfolio_v1/`：**三种任务类型、每类三项独立决定，共九题**。每题有 Agent 可见任务卡、独立来源包、隐藏评审要点和哈希锁；八个只读 MCP 工具对所有题使用同一接口。三类分别检验文献证据修订研究主张、实验结果与方案变更的可比性、协作反馈后的取证和待审交接。它们的入口和交付物不同；是否仍能被一个足够通用的脚本更便宜地完成，必须实测。

九题并不是九项已完成的付费效果实验。当前已完成的是合成输入冻结、隔离工具实现和接口测试；尚未收集这些题的原生 DSH 轨迹、编译新 Motif、盲评答案或核算其费用。模拟论文、邮件和日历只检验方法边界，不是实际课题组资料。导师可先审阅任务问题与隐藏评审标准是否像日常科研，再决定哪些转为真实来源试跑。

## 可检验的机制假设

- **结构—语义分离**：来源 ID、版本、精确摘录位置、数据分组和已授权关联可以由工具核验；论文是否支持主张、实验口径是否可比、能向合作者承诺什么仍需判断。
- **局部重复性**：跨三类任务都存在事件→来源固定→读取，以及数据 ID→逐行/聚合、论文摘录→定位等小片段；是否真的重复，必须等普通 Agent 轨迹给出参数见证。九题的题卡本身不构成 Motif。
- **有界惯性**：未变来源可延续已认证读取；新论文方法、实验方案和邮件要求应打断旧结论或统计解释。评审包预先写明必须打断的错误，便于判断是否错误跳过。

## 向导师报告前还缺的证据

1. 三类任务各收普通 Harness 轨迹，从独立实例编译与认证，预留任务保持不可见。记录每题实际模型请求是否减少，而非只数工具调用。
2. 强脚本具备同样的来源权限、版本核验、计算和必要的模型选择；先盲评合格程度与人工修订，再比较完整费用和耗时。若脚本仍胜出，应把 Motif 价值主张收窄为开放变化下的可迁移性或维护成本，并单独验证。
3. 至少把每类一题替换成研究者正在使用的真实 Zotero/Obsidian/WPS 或协作资料；原始私人数据与轨迹留在 `.local`。真实邮件只拟草稿，不在对照组重复发送。

当前可交付给导师的是**任务集设计、可运行夹具、评审协议和已知负结果**；不是“SSS 已在多种真实科研任务上降低合格总成本”的结论。
