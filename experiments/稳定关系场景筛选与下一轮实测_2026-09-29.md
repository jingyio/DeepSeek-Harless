# 稳定关系场景筛选与下一轮实测（2026-09-29）

## 现有事实与取舍

下一轮目标已按用户反馈收窄为**一个适配的任务类型**：候选论文摘要初筛。先检验普通 Agent **自然**留下、可验证且能在同类不同任务中重新绑定的参数关系，并在阅读决定合格时降低总成本；连续多轮长链和覆盖所有 MCP 门类均非成功前提。具体试验见[单场景聚焦](单场景聚焦_候选论文初筛_2026-09-29.md)。不能用更多合成批注、强制工具顺序或事后改写轨迹制造轮次。

已证实的短关系：

| 关系 | 来源轨迹 | 已见结果 | 为什么还不够 |
| --- | --- | --- | --- |
| Zotero 固定来源 ID → 读取同版 item/annotation | AIDD、Flexibility 训练，Boltz 留出；serving 线上诊断 | 来源类型和版本可守卫；serving 诊断跳过一次请求 | 普通 Agent 可在同轮批量读 Zotero、PDF 和笔记；serving 全程 7 对 7 请求，费用未降 |
| Gmail 搜索得唯一 message ID → 按 ID 读取 | 不同真实邮件训练、留出及后续探索 | 多题稳定跳过一轮；第二版三题估算费用合计约降 2.43% | 被省中间轮很短且缓存命中多；直接脚本也容易做到，未形成合格跨应用科研交付 |
| PDF 引文定位 → 按定位页读取 | Flexibility 普通轨迹 | 唯一定位与页码可验证 | 该轨迹有先读页再定位、同轮并发及失败恢复；没有可直接认证的完整纯结构轮次，不能事后改写成 `match_id` 读取 |

因此当前不把上述任一关系直接包装成下一项“显著省钱”成绩。可优先寻找的**任务形态**是研究者真实的增量决定：新来源或新数据到了以后，Agent 先判断它关联哪条旧主张；关系确定后，来源身份、版本、附件/论文链、精确页或数据文件、受影响证据的重新读取与复算可能形成可复用子图；最后“是否改变科学结论”仍交给模型/研究者。只有实际自然轨迹出现这些依赖，才编译局部 Motif。

## 先做的工作（不调用付费模型）

第 1 项的首轮 17 份普通轨迹盘点已完成，逐轮结果见[现有普通 Agent 轨迹逐轮盘点](现有普通Agent轨迹逐轮盘点_2026-09-29.md)。目前发现的完整绑定轮次仍以短读取为主，未找到可据此宣称合格净省费的跨独立科研决定长链。

1. **盘点已有普通轨迹的请求边界。** 对批注、AIDD 增量、Gmail、文献发现及本地数据任务逐轮标出：工具输出如何决定下一轮参数；同轮可并行的调用；来源版本/权限；语义选择；工具失败与恢复。输出候选表，拒绝只靠频率、文件名或人工规定顺序的边。尤其不把“固定来源→读取”重复计成整条可省工作流。
2. **修好会污染观察的接口错误与证据单位。** `kind=text`/`kind=note`、批准笔记行段、PDF 每次页数、附件→论文关系应有清楚的返回和回退；AIDD 的配体字符串交集必须和蛋白–配体复合物映射分开。这样后续多轮不是由错误重试制造，也不会以错误科学结论换低费用。
3. **冻结新的独立研究决定。** 从实际课题组问题中选一项有真实旧判断、可核验的新来源或数据、原始数值和至少两种合理行动的任务。来源留在原应用；合成批注仅用于回归和扰动，不算真实增量、独立决定或科学证据。先封存任务、来源版本、评分表和预算，再收集普通 Agent 的自然轨迹；看到答案后不修改该题评分门槛。

## 进入 Motif 对照的门槛

- 至少两个**不同决定**的普通轨迹出现同型、带真实参数流的局部子图；第三个独立决定留出。研究者事先写的步骤清单不能充当 `motif_skill_library`。
- 普通 Agent 的轨迹里至少有一个**完整模型轮次**只负责可验证的结构性工具选择/参数传递；如果它已与语义选择或其他读取合在同轮，则该轮不算可跳过。记录实际可跳过轮次的上下文缓存状态与价格，不能只报请求数。
- Motif 在留出题上需同时通过来源/版本/权限守卫、正确参数绑定、失败回退和“新反证使旧路径失效”；至少有一个安全沿用和一个正确打断的变化。动态源只能用已观察到的新鲜结果作锚点，不能自行重放搜索并假装同一结果。
- 人工先判决定材料的证据单位、关键引用、限制与建议是否合格；再比较同题普通 Agent、同等权限的简单脚本/缓存、Motif 的实际请求数、缓存计价后的费用、重试、人工修订分钟数和耗时。若脚本同样好且更简单，应缩小 Motif 的额外价值主张。

## 本轮明确的决策点

第 1 项盘点完成后，优先检验 Zotero 多篇初筛中的“**模型确定候选 → 结构层读已固定条目 → 模型比较摘要**”。不要求连续多轮，只要求真实同类任务中有经核验的一轮跳过，并在合格质量下有净收益。若普通 Agent 把固定和读取自然合并一轮，或脚本达到相同质量与更低成本，就据实缩小该单场景的 Motif 主张；不继续调低匹配阈值、堆批注或用同题复跑宣称收益。
