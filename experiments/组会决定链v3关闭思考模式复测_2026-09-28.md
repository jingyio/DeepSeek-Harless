# 组会决定链 v3：关闭思考模式复测

## 范围与冻结

按用户“再测试一下”的授权，重跑 v3 已见过的三项**合成**组会决定任务：`site_transfer`、`tail_terms`、`lot_stability`。普通 Harness 和 Motif 使用相同的 DeepSeek Flash、任务、MCP 工具契约与交付要求；两组都显式设置 `reasoning_effort="off"`。Motif 复用 v3 已认证的在线产物及相似度门槛 `0.3`，但使用全新会话。顺序预先记录为普通→Motif、Motif→普通、普通→Motif。本次是已知题目的配置复测，**不是独立留出任务或真实应用试用**。

每组有独立预览与用户授权记录；本地费用闸门上限为每组 US$1、六组共 US$6，最多 15 次模型请求，模型单次输出上限 8000 token。原始预览、授权、API 账本、轨迹、答案、Motif 审计及汇总保存在 `.local/benchmarks/meeting-decision-chain-v3-off-retest-20260928/`，不提交 Git。首次启动误用了没有安装 Harness 的系统 Python，产生 0 次 API 请求及 0 费用；该失败记录单独保存在 `.local/benchmarks/meeting-decision-chain-v3-off-20260928/`。正式六组使用项目 Python 环境。

下表费用按 API usage、缓存命中与本地 Flash 峰时价格估算，**尚未与 DeepSeek 控制台账单核对**。六组均完成并渲染交付，模型返回的推理 token 均为 0。

| --- | ---: | ---: | ---: | ---: | ---: |

Motif 审计记录六次经验证的接管；相比普通 Harness，实际付费请求只少三次，因为外站迁移和测量批次仍在其他步骤调用模型。合计估算费用低 $0.000894（约 6.3%），用时低 1.370 秒。终稿轮的三题总费用不再反向抵消前段节省，但外站迁移、低频术语两题的 Motif 终稿仍各自略贵；关闭思考模式不能保证每题终稿更便宜。

与此前高思考档 v3 的直接观察相比，两组费用均明显降低，且推理 token 从非零变为 0；由于两次是独立会话、请求路线和答案不同，不能把费用变化全归因于一个开关。高思考档数据见 `experiments/组会决定链v3重复对照_2026-09-27.md`。

## 答案质量闸门

开发者非盲核对发现：Motif 的低频术语答案虽然把分组总数算对，却把 `candidate/tail` 的逐种子记录**新旧版本写反**，并据此说正确数“整体上调”。冻结表格实际为 w38 `26/25/24`、w39 `22/21/20`，方向是下降。这是与证据冲突的材料错误，不能计为合格交付。普通组的外站迁移答案把均衡分组问题标为“Simpson 型”，用词也需复核；其主要数字与决定方向正确。其余答案的主要数字和建议仅经过开发者检查，尚无独立盲评与修订时间记录。

Motif 的外站迁移执行中有一次 `find_dependent_claims` 工具报错，Agent 随后继续完成；其他五组没有工具错误。完整审计可用 `scripts/analyze-meeting-decision-v3.py --root .local/benchmarks/meeting-decision-chain-v3-off-retest-20260928` 重算。**本轮证明关闭思考后请求与估算费用的方向发生变化，但不证明 Motif 已降低合格交付总成本。**
