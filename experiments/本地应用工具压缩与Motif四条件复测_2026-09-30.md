# 本地应用：工具结果压缩 × Motif 跳请求四条件复测

日期：2026-09-30。**结论：两种机制已同时运行，不能把压缩当成默认省费项。**在已有的真实 Numbers、Keynote、Finder 应用测试资料上，分别运行普通 Agent／Motif 与原始工具结果／无损紧凑 JSON 的四种组合。Numbers 的“Motif＋压缩”三题均通过严格答案检查，较“普通＋压缩”模型请求 **15→6**、API 用量计价执行费 **US$0.005921→0.004425（−25.3%）**；但压缩单独加到普通 Agent 时，三种应用的观察费用均略升。Finder 没有任何经过验证的 Motif 跳轮。每个组合每题只运行一次、题目已在前轮使用，以下是**探索性复测**，不是新留出或长期净收益证明。

## 测试的“压缩”究竟是什么

本轮先测试低风险的**无损 JSON 紧凑化**：代理只在模型将要接收最新一批工具结果时，解析有效 JSON，保留全部字段、数值、字符串和数组顺序，删除格式空白；非 JSON、未变短和旧轮次首次出现的结果原样通过。每项变更的原文、短视图、SHA-256 和字节数留在本机 `.local`，审计重新解析二者并确认值相同。它不删证据字段、不摘要科研内容、不添加恢复工具，也不触碰运行中的应用资料。DeepSeek 的正常前缀缓存计价仍单独统计，不能把 JSON 字节降幅直接当作收费 token 降幅。

普通与 Motif 组使用相同 DeepSeek Flash、`reasoning_effort="off"`、提示、工具列表和来源文件；Motif 继续使用先前从普通轨迹编译和认证的只读算子。所有运行都访问实际 Numbers 14.4、Keynote 14.4 或 Finder，内容为本机自建的受控测试资料。36 次四条件首轮及随后 18 次修正代理的压缩组，每次有 US$0.02 费用闸、最多 12 次模型请求；两轮实际 API 用量计价合计约 **US$0.08894**，未与供应商账单核对，也未计训练、开发和本机计算。

## 为什么把首次压缩结果标为诊断

第一次压缩代理沿用了旧投影代理的实现，会把 DeepSeek 流式响应改成一次性响应。Numbers `debug_e` 的“Motif＋压缩”在**任何工具结果进入模型前**就把打开文件与错误的工作表查询合在同一轮，随后没有 Motif 接管；该差异不能归因于工具结果压缩。原 36 次费用、轨迹和答案完整保留在 `.local/benchmarks/local-app-compaction-v1/`，不混入下面的压缩成绩。

修复后，JSON 紧凑代理保留原始 `stream` 设置及上游回复，不增加工具 schema；本地端到端测试确认流式响应不变、工具 JSON 值不变。用同样九道题重新预览、封存 18 个压缩组，再依冻结顺序运行。下面的“原始”列来自已审计的首轮未压缩组，“压缩”列来自修正后的第二轮，来源和提示哈希均重新核对。两轮仍是不同模型会话，输出及调用批次可能波动。

**Numbers 可较清楚地区分两项作用。**三题 Motif 的实际工具顺序均为“打开→列工作表→列表格→读表”，压缩前后各 6 次模型请求、9 次验证跳轮；短视图只出现在最终整表读取的 3 个返回，共少送 1,514 字节。Motif 组的缓存未命中输入 **13,258→12,925 token**、命中输入均 10,368、输出 **410→404**，对应执行费约降 **2.36%**。这支持“在相同跳轮次数下，表格 JSON 紧凑化有小幅附加收益”的本次观察。普通组虽少送 1,838 字节，未命中输入却 **13,126→14,695**，执行费约升 **3.8%**；相同题目的独立会话仍会走出不同回复，不能把这个升幅全归压缩。

**Keynote 的额外降费不能记给那 72 字节。**Motif 原始组 9 次请求、压缩组 7 次，两组都验证跳过 3 次、都调用相同三种工具；两题的模型自行把调用合批，造成净请求数变化。压缩视图只涉及 4 个很短的返回；普通组单开压缩反而从 10→11 次请求、费用约升 4.8%。这显示“同题费用更低”不自动说明压缩字节带来了节省。

**Finder 不适合当前两项机制。**四组全部内容数字／文件判断正确，但 JSON-only 格式未稳定通过；Motif 四组对照中仍 0 次跳轮。压缩组每题只删去几十字节，普通组估算费约升 5.2%，Motif 组约升 8.0%。先前 Finder 两组有约 4% 数值差也不能归因于 Motif；这里再次没有接管证据。

## 工程与创业取舍

当前通用紧凑化只作为**可开关的实验能力**，不宜全应用默认开启。若后续启用，应由实际结果大小和可核算的成本收益守卫选择，例如 Numbers 整表结果；Keynote/Finder 的小元数据保持原样。更激进的字段裁剪或摘要没有在本轮试验中启用，不能把 Gmail 长 HTML 的历史压缩收益外推到这些短 JSON。Motif 跳请求是主要的观察收益，压缩只能在已验证的具体输出上争取增量。

对创业而言，Numbers 的同时开启结果是**功能演示与机制证据**，尚不是可收费产品的单位经济。三题重复使用了已知夹具，每题一次，API 费绝对差约千分之一美元量级；训练摊销、应用授权、维护与用户复核时间未计。下一步先在同学每周真实材料上验证减少漏错与人工核对分钟数，再决定是否把大结果紧凑化作为默认设置。单靠“减少工具结果字节”或“少一次模型请求”不足以构成用户付费理由。
