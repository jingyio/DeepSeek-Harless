# 组会决定链 v3：工具契约修复后的重复对照

## 冻结与范围

v1 单题归因发现工具 ID 混用；v2 的三次普通组诊断进一步发现“上一版实验被传给当前主张查询”。因此 v2 只作接口诊断。v3 在 Git `4950136` 冻结两类参数说明：`pin_object` 返回的 `source_id` 才能用于 `read_pinned_object`；`find_dependent_claims` 只接受当前 `experiment_id`。MCP 实际暴露的 JSON schema 包含说明和格式约束，普通组与 Motif 组一致。现有 5 项夹具测试通过。

v3 的 `family_shift`、`label_audit` 普通组轨迹用于参数边挖掘，`hardware_latency` 用于独立认证。三项训练/认证题未参与效果统计。前瞻效果题 `site_transfer`、`tail_terms`、`lot_stability` 在编译和本地相似度门槛 0.30 固定后各跑一对。运行顺序事先固定为普通→Motif、Motif→普通、普通→Motif。所有来源均为**合成** WPS 可打开表格和模拟 Obsidian/Zotero 对象；不代表真实应用现场成绩。六次效果运行均为 DeepSeek Flash 高推理档、相同工具与交付格式，且全部得到完整答案。原始任务预览、授权依据、API 账本、轨迹和在线跳过审计保存在 `.local/benchmarks/meeting-decision-chain-v3/`，不提交 Git。

新版两个训练任务共有三条精确参数边，独立第三题认证了三条；在线版本/参数守卫允许其中一条 `pin_object.source_id → read_pinned_object.source_id` 自动执行。它由新版真实轨迹编译，不是场景专用手写 DAG。其余分组统计和科学判断仍由模型选择。

## 逐题结果

费用依据 API usage 和本地 Flash 峰时估价，**尚未与控制台账单核对**。`verified skips` 是 Motif 审计确认的替代模型轮次；相对普通组的真实请求差须另看请求列。

| --- | ---: | ---: | ---: | ---: | ---: |
| 外站迁移 | 7 → 5 | 2 | $0.006857 → $0.007890 | 893 → 2,153 | 24.829 → 27.363 |
| 低频术语 | 6 → 5 | 2 | $0.007621 → $0.007361 | 1,940 → 2,754 | 24.489 → 26.155 |

Motif 在三题均有两次经工具结果验证的跳过，但相对普通组分别少 2、1、1 次请求。总模型请求少 4 次（约 21%），估算 API 费只少 $0.000104（约 0.48%），累计耗时反而多 1.089 秒。此样本不能证明实用净收益。

## 推理是否后移

三题在最终写稿**之前**的估算费用，普通组共 $0.012163，Motif 共 $0.009008，减少 $0.003155；最后一次写稿费用，普通组共 $0.009527，Motif 共 $0.012578，增加 $0.003051。两者几乎抵消。最终写稿推理 token 在每题均增加，总计 4,469 → 6,812；前几轮推理 token 则 2,469 → 1,157。全程推理 token 6,938 → 7,969，增加 1,031。全程输出 token 13,247 → 13,306，基本不变；非推理输出更少。

这是**推理可能被后移并放大**的可观察迹象，而非因果证明。每题的两次调用是独立随机会话，后续检索路线和答案内容并不相同。不能把前段少一次请求等同于删除了同一段认知工作。三题仍小且相似，需更广泛、真实的研究决定重复。工具错误方面，三个 Motif 效果运行均无失败；普通组仅 `tail_terms` 有一次把无效站点标识传给当前依赖查询。原先的对象 ID 与来源 ID 混用未再出现，但通用格式约束仍无法阻止编造一个**格式合法、对象不存在**的 ID。

## 质量闸门

六份答案都覆盖主要数字和方向，但开发者的非盲核对发现两处值得独立复核的表述：外站迁移普通组把均衡的内外站样本说成“高内站占比”；测量批次 Motif 组在表头说“每格 n=240”，实际逐批次每格是 120，只有整体是 240。前者影响聚合原因解释，后者是分母错误。匿名 A/B 答稿已保存于 `.local/benchmarks/meeting-decision-chain-v3/blind-review/`，身份映射另存；尚无研究者独立盲评及修订分钟数。**因此目前只能报告请求、token 和估算费用，不把 0.48% 的差额称作合格交付收益。**

v3 另三项训练/认证普通组和 v2 三次诊断也均计入本机账本；v2 三次诊断估算 $0.02385，v3 九次正式运行估算 $0.06663，合计约 $0.09048，远低于各次硬上限。完整核算可运行 `scripts/analyze-meeting-decision-v3.py`；该脚本核对账本、模型轮次、推理 token 和 Motif 结果审计，输出私有 `ANALYSIS.json`。

下一步先完成盲评。若质量不合格，需计入人工修订或重新生成的模型费用和时间；随后才能判断结构机制是否比同工具普通 Harness 和“版本检查脚本＋一次模型判断”有额外价值。真实 WPS/Obsidian/Zotero 接入仍需单独验证。
