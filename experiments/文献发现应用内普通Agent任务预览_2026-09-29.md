# 文献发现应用内普通 Agent：公开版本核查预览

状态：**已冻结预览，本轮首次付费试跑已完成**。结果和质量审计见[六类应用内实测总判断](六类MCP应用内实测总判断_2026-09-29.md)。以下保留运行前的预览条件。本题是 AIDD 同一来源簇的开发例，不算新独立研究决定或留出成绩。精确提示、工具配置及来源代码哈希保存在 `.local/benchmarks/mcp-app-internal-v2/literature/{PROMPT.txt,patch.yml,PREVIEW.json}`，入口为 `scripts/run-literature-internal-baseline.py`。

真实请求是核查 *Investigating the volume and diversity of data needed for generalizable antibody–antigen ΔΔG prediction* 的 2023 预印本与 2025 期刊记录：能否视为同一研究工作的两个出版版本，当前文献卡优先引用哪条；仅凭题录无法确定的正文、实验或结果差异须明确留待核对。普通 Agent 仅能使用文献发现 MCP 的 11 个公开只读工具，自行选择检索路线；不访问 Zotero、Obsidian、Gmail、日历或本地私人文件，不写入应用。每次公开接口调用须在轨迹中保留提供者、查询及结果状态。文献题录只作为候选，不能当成论文结果证据。

预检证据：本机 arXiv 题名搜索返回服务不可用，OpenAlex 检索返回 HTTP 429；新增的 Crossref 题名搜索返回 3 个候选，前两项分别是期刊与预印本 DOI。两条 DOI 元数据现各自给出指向对方的 `has-preprint`／`is-preprint-of` 关系，且注明关系断言来源；这一字段已加入只读 MCP 的核对结果。Crossref 的[公开 REST API 文档](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)说明 `/works` 可检索成员存入的书目元数据，其[预印本关系说明](https://www.crossref.org/blog/discovering-relationships-between-preprints-and-journal-articles/)解释了这两种关系。它们不能代替论文正文或收录所有无 DOI 预印本。这些人工发起的预检不计作 Agent 轨迹或任务质量；两条原始元数据及检索时间封存在 `.local` 供事后核对。

本题拟用 DeepSeek Flash、`reasoning_effort="off"`，最多 **12 次模型请求**、单次输出最多 **2500 token**，独立费用闸门 **US$0.50**；这是上限，不是预计费用。只读、无外发邮件或日程动作。运行前必须由本题批准记录绑定冻结预览哈希，且实际费用闸门不得高于 US$0.50；脚本对同一首次尝试排他，失败不覆写。原始事件、答案和逐请求账本只写在 `.local`，公开报告只列匿名化指标与证据限制。

本题完成后先核对 Agent 是否实际使用公开文献 MCP、是否在提供者故障时合理回退、是否把同题名和不同 DOI 解释得过满。即使合格，它也只是普通 Agent 自然轨迹；Motif 效果需另有独立训练与留出决定、同题对照和盲评。
