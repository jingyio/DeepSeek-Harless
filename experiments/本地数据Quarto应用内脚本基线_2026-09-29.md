# 本地数据／Quarto 应用内脚本基线（2026-09-29）

任务是把 PBCNet2.0 作者固定版本的八个真实公开突变预测 CSV 逐项复算为可审阅的一页材料。输入来自[公开文件清单](../benchmarks/research_weekly_loop_v1/pbcnet_mutation_public_manifest.json)所列仓库 commit 和 SHA-256，原始文件留在 `.local/benchmarks/research-weekly-loop/aidd-next-preflight/public-data-preflight/mutation/`。脚本入口为 `scripts/run-local-data-script-baseline.py`，通过**真实本地研究 MCP** 调用 `list_research_sources`，再对每份文件调用 `pin_source → inspect_records → aggregate_records`，最后用同一 MCP 的 `write_workspace_text → preview_quarto → render_quarto` 生成 HTML。不是直接读取私有缓存后假称 MCP 试跑。

运行共 **28 次 MCP 调用、0 次模型请求**；首次用时 1.776 秒，补充逐目标独立核对后的复跑用时 1.612 秒，模型费用为零。八个目标共 65 对 `Label`／`pre`，目标等权宏平均 Pearson **0.545008267951**、Spearman **0.529680735931**；八组的分母、Pearson、Spearman 和文件哈希均与先前独立复算逐项一致。每个工具读取都带文件哈希，逐目标统计的分母与 `inspect_records` 行数一致。渲染页面位于[本机 Quarto 报告](/Users/apple/Desktop/SSS/.local/python-workspace/rendered/pbcnet-mutation-statistics.html)，最新一次逐项结果和调用状态保存在 `.local/benchmarks/mcp-app-internal-v2/local-data-script/result.json`。

这是**确定性脚本基线**，没有普通 Agent 自主选择轨迹，更没有 Motif 在线组或人工盲评。它证明对于固定文件和明确统计口径，普通脚本已经能快速、低费用地完成结构操作；后续若 Motif 只复刻这 28 次固定调用，不能声称额外价值。页面只核对公开预测值的汇总统计，不证明训练／测试生物学独立、零样本泛化或论文其余结论。旧 AIDD 跨应用试跑与此处同属一个研究决定，不可拆成多个独立留出任务。
