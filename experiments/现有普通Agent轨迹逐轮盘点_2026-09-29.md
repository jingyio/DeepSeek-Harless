# 现有普通 Agent 轨迹逐轮盘点（首轮，2026-09-29）

## 口径与范围

本轮只读盘点 **17 份普通 Agent 原始事件流**：8 份科研决定／开发题轨迹和 9 封不同 Gmail 提醒的普通组轨迹。它们不是 17 个独立研究决定：AIDD 的初始与增量属同一决定，serving 缓存多版本属同一决定，Gmail 提醒是同一任务类型的不同消息；AI4S 初筛任务设定后来判为无效。私有文件清单、事件 SHA-256、逐请求/工具轮次、严格结构边审计输出保存在 `.local/benchmarks/research-weekly-loop/stable-relation-inventory-20260929/`；原始正文与邮件不进入此报告。没有调用模型、修改应用或创建任何新 MCP 工具。

可复跑入口是 `scripts/inventory-existing-agent-turns.py --manifest .local/benchmarks/research-weekly-loop/stable-relation-inventory-20260929/baseline-manifest.json --out .local/benchmarks/research-weekly-loop/stable-relation-inventory-20260929/reproducible-inventory.json`；该入口复用 `scripts/audit-motif-turn-opportunities.py` 与 `scripts/summarize-dsh-step-cost.py`，并记录每份原始事件哈希。我另回看候选轮次的原始工具名、参数字段、相邻轮次和任务题面。机械审计只在成功只读结果中寻找**先前工具返回的不透明 ID → 后续工具必填参数**，再要求目标轮次的全部调用都由安全边绑定、可选参数为契约默认值。该标记只是**可移走轮次的宽松上界**：它不证明该轮没有必要的语义选择，也不计算跳轮后历史和缓存变化。PDF 页码、笔记行段、统计 `group_by/measures` 不能因为 `source_id` 已知就自动推断。价格列如需复算仍采用旧脚本冻结的 2026-09-27 DeepSeek Flash 非高峰价，仅供直接请求价格上界，不是供应商账单或净节省。

总计观察 **185 次模型请求、317 次工具调用**；严格机械检查标出 **11 个完整绑定的只读目标轮次**。其中 6 个来自 Gmail 的单步 `search→read`，5 个来自三个科研开发题；数字不能合并称为“11 次可省请求”。其余结构边常与语义参数、其他工具或失败恢复同轮出现。

## 稳定关系的实际级别

1. **已重复且可执行的短边**：Gmail 唯一 ID → 读取；Zotero 已固定且同版、同类型的来源 ID → 读取。前者在多封邮件跨轮出现并有线上跳轮记录；后者跨科研题出现，但普通 Agent 往往把它与其他读操作合轮，整题不一定省钱。
2. **单题候选，尚非跨任务稳定 Motif**：AIDD 第 34 轮 `pin_source → inspect_records` 有清楚的数据集句柄；serving 第 3 轮一批已固定来源读取也可绑定。它们目前短、直接价格低，且没有在合格的独立研究决定中形成长的连续结构段。
3. **不能自动化的选择**：看摘要后决定下一篇、选 PDF 页或摘录、为统计指定分组和指标、判断新来源是否推翻旧结论，均留给模型/人。`source_id` 复制成功只解决身份，不解决这些选择。

## 本轮结论与下一步入口

**从现有普通轨迹尚未找到“跨独立科研决定重复、连续多轮、交付合格且净省费”的长关系。** 但这不是下一步的必要成功条件。用户已将目标收窄为**找到一个适配的场景**；据此优先选择[候选论文摘要初筛](单场景聚焦_候选论文初筛_2026-09-29.md)，只验证该场景里模型定候选后的受控条目读取能否跳过一轮，并在答案合格时净省费。继续堆批注或为 `locate→read` 人造串行工具只会改变基线。若简单批量读取脚本同样好，应据实缩小 Motif 的额外价值主张。
