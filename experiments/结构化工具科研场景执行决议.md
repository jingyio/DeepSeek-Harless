# 结构化工具科研场景：下一轮执行决议

> 2026-09-27。依据研究者要求，后续主线聚焦真实跨应用科研决定。本文确定任务选择和对照口径；后续 Model RSI 只读付费试跑结果另见 [Model RSI 跨应用 MCP 模型轮次诊断](Model-RSI跨应用MCP模型轮次诊断.md)。该试跑尚未证明 Motif 收益。

## 实验场景边界

TauBench Figure 7、AppWorld 图表等本地冻结文件核查保留为解析、数值计算、轨迹记录和费用账本的**开发诊断**。它们的来源几乎都在同一目录，原生命令即可解题，不能作为 Zotero／Obsidian／文献发现等结构化工具主线的代表，也不能据其 token 比例推断多应用 Motif 收益。

官方 AppWorld 的真实多应用交互任务是另一项可用的**机制基准**：它允许对比直接 MCP 与代码批量调用，并在代码强基线上测试是否仍能安全跳过模型轮次；实验设计见 [AppWorld 真实跨应用任务的模型轮次实验](AppWorld真实跨应用任务的模型轮次实验.md)。它的结果也须与科研主线分开报告。

主线从研究者**当前确实要作的决定**开始：旧主张和否决在 Obsidian，已收藏论文及批注在 Zotero，新论文从文献发现入口定位；若有与决定相关的原始数据，用 Python 或结构化统计工具复算；用 Quarto 生成带来源定位的审阅材料。Gmail／日历只在真实澄清和讨论需要出现时使用。应用材料保持在原位置，执行包只给经圈定的范围、目标和预算，不拼成一个命令行可独立完成的大文本包，也不规定调用顺序或最低调用次数。

首轮可用更窄的[论文影响卡任务族](../benchmarks/research_weekly_loop_v1/mcp_paper_impact_cards.md)做工具与质量预检：一篇论文、一个既有主张，让 Zotero 批注、Obsidian 状态和论文版本通过 MCP 形成可观察的依赖。**初次影响判断仍需模型，不能预设该任务族能省掉整轮请求。** 只有真实轨迹出现可分离的确定性轮次，且后续真实事件给出明确入口绑定，才升级为模型跳过实验；否则转选更合适的任务。它与完整科研决定分开评分，不要求每题凑齐数值复算、邮件和日历。若普通缓存或代码已达到相同效果，不能把收益归给 Motif。

## 当前可用实例与缺口

| 实例 | 当前用途 | 缺口 |
| --- | --- | --- |
| Model RSI：内部可更新能力状态的最小反证实验 | 第一项开发实例；已有多 MCP 真实调用 | 科学决定未过质量门；需核对来源覆盖、对照公平性和研究者真正采纳的行动 |
| AIDD：首个应用与泛化划分 | 第二项开发实例；已有 Zotero／Obsidian 参数链和真实公开数值增量 | 旧答案仍待质量审核；已有基线禁用了原生命令，须与后续自由 Harness 基线区分 |
| 第三个不同项目的科研决定 | 编译前封存的留出候选 | **尚未选定**；不能用 SSS 自身方法题、AIDD 增量轮次或本地图表核查替代 |

三题不齐时可以继续修工具、审轨迹和质量门，但不能报告跨任务 Motif 有效。没有真实邮件、会议、数据或增量事件的实例要标注局部范围，不能制造这些输入以提高工具覆盖。

## 两种工具环境必须分开

1. **自由普通 Harness 基线**：给相同授权来源与可用工具，保留合法命令行和 Python，让 Agent 自选路径。记录它何时用 MCP、何时用命令读取本地数据、何时遗漏必要应用证据。不能在基线禁用命令后说 Motif 让 Agent “更会用 MCP”。
2. **受限结构化工具诊断**：可像已有 AIDD scoped 配置那样只暴露经过版本绑定的 MCP，用于检查 `source_id → 读取 → 下游参数` 是否可观察、可失效。该配置单独计分，不能与自由基线混报质量、费用或工具偏好。

外部应用读取、对象定位、批注／笔记状态与待审协作动作优先通过有对象 ID、版本和权限守卫的工具；批量统计、探索和渲染可以由代码或命令完成。命令路径记录输入哈希、代码版本、输出和来源关系。对两种形式均统计 `可用 → 暴露 → 调用 → 成功 → 被研究决定使用`；多调用本身不是收益。

## 进入付费对照前的可检查动作

1. 从现有 Model RSI、AIDD 轨迹逐条复核重要主张与实际读取的页／行／批注，修正错误样本；先由研究者判交付是否可用。两项已发生的费用和失败不能删除。
2. 为 AIDD 和第三题分别冻结 Agent 可见任务包、来源及权限快照、隐藏评审包和事件释放时间。第三题须来自另一个正在推进的项目；只做元数据预检后由研究者圈定内容范围。
3. 冻结同题的自由 Harness、静态相关工具预选、简单脚本／缓存、`research-workflow + 同一模型` 和 Motif 配置；各组固定模型路由、预算、来源快照与评分口径。已有受限 AIDD 试跑仅作诊断参考。
4. 先判断重要证据、反证、数字、Idea Delta 和下一步行动是否合格，再比较请求、缓存命中／未命中／输出 token、实际账单、人工修订分钟与端到端时间。Motif 候选只从**两个独立任务的真实调用依赖**编译，在第三题及真实变化上验证正确复用与正确打断。

2026-09-27 的无模型工具清单检查显示六个默认连接器均可列工具，共 **87 个**。检查未读取应用内容、未调用付费模型；连接成功和工具数量均不等于 87 项功能逐项可用或科研决定合格。完整任务生成和三例门槛仍以[任务协议](../benchmarks/research_weekly_loop_v1/task_generation_protocol.md)及[候选册](../benchmarks/research_weekly_loop_v1/task_family_candidates.md)为准。
