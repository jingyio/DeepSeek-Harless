# 组会决定链：跨任务跳过模型请求与强脚本基线

## 结论边界

在三项**独立、合成**的科研组会决定中，SSS 从历史工具轨迹编译的只读 Motif 在线接管了跨应用读取，**每题有 3 轮完整 DSH 模型请求被结构执行替代**。相对普通 DeepSeek Harness，三题的实际付费请求分别由 9→4、6→4、7→3；合计 22→11。交付均通过版本、完整逐行证据和声明分组的机械检查，并生成 Markdown 与 Quarto 页面；逐稿检查发现显微镜题 Motif 把全表分母写为 240，实际应为 480，需要一处人工更正。尚无独立研究者盲评。

**这不是相对简单程序的成本优势。** 同题的通用版本取证脚本可以在无模型阶段取得事件、两版记录、聚合结果、笔记与批注，再各用 1 次 Flash 写决定。它三题合计只发 3 次模型请求，估算费用和耗时均低于 Motif；答案也有应删的内部状态描述与个别过度解释，未做盲评。当前能成立的主张只限于“Motif 比普通 Harness 稳定少发了部分模型请求”，不能称为“本任务族最便宜”或“Motif 优于脚本”。

## 机制与冻结方式

第一阶段用 `family_shift`、`label_audit` 训练、`hardware_latency` 留出认证，得出 5 条可在线执行的只读参数边；在 v2 的 `model_rsi_state`、`aidd_mutation`、`agent_tool_transfer` 三项新决定中，请求差为 6→6、6→5、7→5。第一题揭示上一版实验分支没有被认证。

第二阶段仅取 v2 **普通 Harness** 的 `aidd_mutation`、`agent_tool_transfer` 轨迹为训练，`model_rsi_state` 为结构留出校验；得到 8 条通过参数见证的边，其中 6 条满足在线版本守卫，新增 `read_change.previous_experiment_id → pin_object.object_id`。这不是手写的场景 DAG；边的实际参数、来源、目标工具、历史任务和留出见证均在私有认证产物中。v3、v4、v5 的研究决定均未参与这次编译，也未用于调相似度阈值，阈值保持既有的 0.3。运行时核对当前任务允许的对象与哈希；模糊匹配只能排序，不能编造对象 ID。最新三题的 Motif 轨迹均显示 3 个结构接管轮：事件结果引出当前/上一版固定与依赖索引，随后固定相关笔记/批注并读取已固定来源。之后的分组复算与研究判断仍由模型完成。

新任务先冻结问题和文件 SHA-256，再生成每组的独立预览与 US$1 上限授权记录。三题均用 `deepseek-flash`、关闭思考模式、同一只读 MCP 夹具、同一提示与工具合同；Motif 组额外加载认证产物。完整私人轨迹、逐请求代理账本和交付在 `.local/benchmarks/meeting-v5-eval-20260928/`。v5 数据与任务文件的提交用 `benchmarks/meeting_decision_chain_v5/fixtures.lock.json` 验证。所有应用对象都是模拟 WPS、Obsidian、Zotero 的本机 MCP 夹具，不代表真实桌面应用授权与部署已通过。

## 前瞻三题：普通 Harness、Motif 和通用脚本

表内费用是本机预算代理从 API `usage` 按配置价格算出的**估算值**，尚未与 DeepSeek 控制台账单核对。耗时含本地 MCP/DSH 执行，脚本组另有本地取证时间；此处列的是付费生成器运行时长，不应误称完整人工交付时间。

| 决定（16 行、4 seed） | 普通 Harness 请求／估费／秒 | Motif 请求／估费／秒 | 脚本＋Flash 请求／估费／秒 |
| --- | --- | --- | --- |
| 跨显微镜厂商分割 | 9／$0.005511／17.6 | 4／$0.004814／13.7 | 1／$0.002821／7.8 |
| 新底物反应预测 | 6／$0.004717／14.8 | 4／$0.004124／12.4 | 1／$0.002616／7.9 |
| 材料合成放大批次 | 7／$0.004489／14.7 | 3／$0.003814／10.6 | 1／$0.002651／7.8 |
| **合计** | **22／$0.014717／47.0** | **11／$0.012752／36.6** | **3／$0.008088／23.5** |

Motif 相对普通 Harness 的请求数降低 50%，估算代理费用降低约 13.3%，该组三题的本地计时降低约 22.1%。费用降幅小于请求降幅，因为少发请求后缓存命中、未命中输入和输出 token 的构成也变了：普通组合计未命中输入 19,040、缓存命中 69,760、输出 7,155；Motif 为 19,709／28,288／5,558；脚本＋Flash 为 9,559／0／4,350。不能用总 token 或“接管次数”替代实际请求及缓存计价费用。

## 交付质量与负结果

- 机械守卫核对事件中的旧版哈希、两版完整逐行记录、声明的聚合分组、显式逐 seed 序列、可从原始行得出的分子/分母及若干统计术语。它不证明科学判断正确。显微镜 Motif 稿有“每格 120，全表 240”一处错误：四格的全表分母是 480。该稿只可作为待审材料，需研究者改这一行；一处小错误恰与用户允许的轻微质量下降相符，但应计人工修订成本，不能算无人审核即合格。
- 新底物和材料放大两份 Motif 稿的分组算术、旧主张处理与“原因待核实”的界限在本次逐稿核查中未见同等级事实错误；这是开发者非盲审阅，不能替代研究者盲评。早期 v3 的 RNA Motif 曾因事实冲突触发一次付费修复，4 次请求虽低于普通组 6 次，估费却高于普通组；该失败成本保留，不能从效果叙述中删除。
- 强脚本 `script_baseline.py` 对所有题使用同一版本取证程序，预先串联整个任务族的事件、当前/旧版表格、主张与批注，再让模型一次写稿。它的三个答案可审阅，但把 `semantic_review_required`、`model_requests=0` 等内部元数据写进了正文；显微镜题还把“核对复核规则”说得过于像已证实原因。它仍表明此任务族可被固定脚本覆盖，Motif 没有成本独占性。
- 后续必须用真实研究者的应用数据和盲评判断质量；估算代理费用不等于实际账单，合成夹具也不代表真实 WPS/Obsidian/Zotero 的权限、网络、延迟与版本变化。

## 下一步任务结构

下一类测试不应继续复制“事件→两版统一表格→固定笔记→一次报告”的同形题。应让研究者问题先要求**一个有边界的语义选择**（例如从多个冲突主张或附件中选需核查的一个），该选择的结果才提供后续版本对象与参数；另设至少一处新证据可打断旧路径。普通脚本可以实现同样的访问和缓存，但需完整地实现这些分支并保持同样的授权、版本检查，才能公平比较维护与运行成本。若脚本仍以更低合格总成本完成，则进一步收窄 Motif 的适用范围。
