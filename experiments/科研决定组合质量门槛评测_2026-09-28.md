# 科研决定组合的质量门槛评测（2026-09-28）

## 结论

在六类合成科研决定的十五项配对任务中，在线 Motif 将 DeepSeek Flash 请求从 **129 降到 74**，本机逐请求 usage 的缓存计价费用代理从 **$0.059466 降到 $0.046033**。按匿名答案逐题核对后，两组**同时可用的九题**为 77→45 次请求、$0.034618→$0.027504，费用代理下降 **20.5%**。这证明当前原型在部分任务中可以安全接管工具间的参数传递，并在答案仍可用时减少模型参与。

这不是完整产品收益：Motif 有一题出现普通组没有的材料错误；三题两组都不合格；质量审阅由本项目 Agent 完成，**不是独立研究者盲评**；资料和 MCP 返回均为合成模拟；费用代理未与 DeepSeek 控制台账单核对。失败答案的修订成本未知，因此不能把 20.5% 当成全部十五题的合格交付成本降幅。

## 冻结范围与执行

- v1 六题来自三类任务，是开发性留出，题目选择有偏倚；v2 九题来自另外三类，整版纳入，在运行前固定工具、阈值和任务包。每题一组普通 DeepSeek Harness、一组在线 Motif，均为 Flash、`reasoning_effort="off"`、相同提示和八个只读 MCP 工具。Motif 候选来自先前轨迹编译的四条只读参数边，不是本次手写逐题流程。详见[跨类型试跑记录](六类科研决定任务与在线Motif跨类型试跑_2026-09-28.md)。
- 每题的源、任务、必要点与 A/B 隐名答案冻结在 `.local/benchmarks/research-portfolio-blind-v{1,2}/`。先写入不含组别身份的 `agent-blind-review.json`，再读取 `_sealed/` 身份映射。评审 Agent 已知项目和部分风险点，故这里只能称为**匿名答案核查**，不能称为独立双盲。
- 另用 DeepSeek v4 Pro、思考关闭对十五份 A/B 包各做一次匿名评审，共 15 次请求、费用代理约 **$0.099933**，此为一次性评测费用，未并入 serving 成本。五份返回 JSON 格式错误或结论与自述的材料错误冲突；其余评审也漏掉关键数字和科学错误。因此 Pro 评审仅作诊断，不作为最终标签。
- Agent 核查规则：严格合格需覆盖所有 `rubric.must`，且无影响决定的事实、数字、来源或因果错误；“可用”允许一项轻微缺口，但不允许材料错误。以下严格与可用标签在本轮相同。原始审阅判断、逐题身份解封和 usage 汇总只存于 `.local/benchmarks/research-portfolio-judge-v1/`，不提交个人或运行数据。

## 归因与局限

在线审计记录了八十批由 Motif 代替模型生成的只读工具调用；实际净少五十五次模型请求，说明接管后路线会变化，不能把每批接管都算作一整次净节省。相同工具和提示下，已验证的参数边对请求下降有贡献。账本使用逐请求 `observed_peak_usd` 汇总缓存命中、未命中和输出 usage；它是官方价格的本机估计，不是银行或控制台账单。评测 Pro 的费用也表明：在如此短的小题上，实验审阅成本高于单次 serving 节省；只有在任务重复或真实工作量足够大时，才有产品经济意义。

这些任务由项目围绕跨应用工具关系构造，只能证明**存在可工作的实例**，不能证明真实课题组任务、八十个工具或任意新任务均有效。还没有真实 Zotero／Obsidian／WPS 使用者交付、独立人工盲评、人工修订分钟数、实际账单核对，也没有无关变化可沿用及反证变化必须打断的前瞻增量测试。下一步先修 Motif 组的种子方向错误所暴露的数字一致性守卫，再冻结新题，由课题组研究者盲评实际资料上的可用性与修订成本；开发性 v1 不应再作为独立泛化证据。
