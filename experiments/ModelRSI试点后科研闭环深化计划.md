# Model RSI 试点后的科研闭环深化计划

> 2026-09-26。实施计划，不是新增效果成绩。依据：`benchmarks/research_weekly_loop_v1/` 的真实任务协议，以及私有 Model RSI 试点的 `continuation-01/RESULT.md`。优先证明研究者得到合格决定，再检验 MotifAgent 是否减少合格交付的总成本。

## 这次试点改变了什么判断

Model RSI 开发题累计 25 次 DeepSeek Flash 请求、62 次 MCP 调用（13 种工具）、852,886 token，最后形成候选决定材料；14 次 MCP 调用失败或超时。它证明受限文献／笔记 MCP 在普通 Harness 中确实会被调用，但交付存在已读取来源被误报为未读、实验对照不公平等问题，**未通过内部质量审查**。试点只向 Agent 暴露 15 个相关 MCP 工具；本机六个连接器当前可枚举 87 个工具，不等于一次任务需要调用 87 个。

所以接下来的问题按顺序是：①怎样让来源与决定可信；②怎样获得真实跨应用任务，而非工具演示；③相同质量下，Motif 的结构执行是否比普通 Agent、脚本和缓存额外省时省钱。不能先从调用次数或单次 token 下降宣布成功。

## 五个工作包与进入门

| 顺序 | 要做的事 | 可检查产物 | 通过后才进入下一步的条件 |
| --- | --- | --- | --- |
| 1. 关闭质量与账单缺口 | 固定这次原始轨迹、两段模型原文及人工拼接记录；把 `max-tokens` 截断判为未完成；逐条核对中心引文是否由实际读到的版本／页码支持；将 Model RSI 中“未读行段”和 E0 不公平对照列为错误样本；按供应商用量核对账单 | 私有质量审查表、来源到主张定位表、模型请求／缓存／费用表；审查器的正反例 | 审查器能识别“未读却声称已读”“已读却声称未读”、无版本支持、输出截断；研究者知道本次为何不合格。自动检查只验证可机械核对的事实，不代替科学判断 |
| 2. 补可编译的参数流 | 先给来源身份、版本、权限和有限片段读取建立不透明 `source_id`；覆盖 Obsidian 笔记、Zotero 条目／批注、公开 PDF 和本地数据。消费句柄时重验来源，轨迹记录返回值进入哪个下游参数；失败、歧义和权限变动都阻断候选片段 | 工具契约、真实 DSH 事件上的 `source_id → read → evidence` 轨迹、失效测试 | 至少有两种应用的真实调用产生可复核的两步以上参数依赖；`infer_dsh_provenance` 能从工具结果而非任务文字识别它；不得把手写场景 DAG 当作挖出的 Motif |
| 3. 冻结同类真实任务 | 用[任务生成协议](../benchmarks/research_weekly_loop_v1/task_generation_protocol.md)选至少三个**不同研究决定**。Model RSI 是已开发实例；优先核对 AIDD 是否仍在推进，再找一个与 SSS 方法开发无关的研究问题作为留出候选。每题分 Agent 可见包与隐藏评审包，先登记资料版本、质量门和工具机会 | 三份独立任务卡、来源／权限快照、预登记评审表、真实后续事件时间线；不合条件的题标为局部实例 | 至少两个任务有合格初始交付及可验证参数链，第三题在 Motif 编译前封存。若没有真实数值、邮件或会议，记录不适用，不制造材料来凑工具 |
| 4. 跑同题强基线 | 每题先运行普通 DSH 的自由工具选择；再比较相关连接器静态预选、`research-workflow + 同一模型`、简单脚本／缓存。所有组用同一资料范围、模型路由、事件切点和质量门。Flash 负责调查，Pro 仅处理预登记的高价值语义缺口，且路由规则各组相同 | 原始轨迹、工具机会表、盲评、人工修订分钟数、请求／token／账单／耗时 | 至少两名评审先判重要主张、引文、对照设计和下一步是否合格；不合格任务只报告诊断与全额成本，不进入节省率分母 |
| 5. 评 Motif 的独立增益 | 只从前两题成功轨迹挖有来源、参数流和守卫的局部子图；第三题留出执行。真实新批注／论文版本／实验数据到来时，分别检验正确沿用、正确打断和局部重算。与脚本／缓存及静态工具预选分别对照 | Motif 来源轨迹、编译产物、执行／handoff／reentry 日志、失效案例、同题质量与成本表 | 留出题质量不低于强基线、无严重错误跳过，且合格交付的总费用或人工时间有可重复优势。若简单脚本等效，就缩小 Motif 主张 |

## 工具覆盖怎样变成真实闭环

下一题首选 **AIDD 的“首个应用与泛化划分”决定**，因为已有公开 Idea State、真实 Zotero 批注和 Obsidian 项目状态。先做无模型元数据预检，再由研究者圈定实际条目、笔记、对外摘录和本周仍需作出的决定。Agent 自选文献路线；论文原文与人的批注分别定位。若研究者能提供相关原始表格／运行日志，Python 复算 split、分母和指标；Quarto 生成可复核简报，研究者确认后再更新 Idea State。

要检验 Gmail／日历，须另选**确实有合作者澄清和组会安排**的一题：Agent 先根据证据形成具体待问问题，再读被圈定的邮件线程、生成待审草稿；真实回复到来后更新决定，最后查询空闲时间并准备待审会议。实际发送与建会只由研究者审核后执行一次，各对照组不重复联系他人。Zotero 当前只读，不能把“准备导入清单”写成已归档到 Zotero。这样七类常用科研能力都有自然机会，但每个任务仍允许跳过不适用工具。

工具轨迹逐项记录 `可用 → 暴露 → 调用 → 成功 → 被最终决定使用`。普通 DSH 既要有可访问的真实应用资料，也保留合法的本地工具；若它选择命令而非 MCP，应记录原因和等价性。静态相关工具预选只是工具发现／上下文基线，不能算 Motif 的动态控制收益。

## 结构—语义分离、局部重复性和有界惯性的验收点

- **结构—语义分离**：来源身份／版本、权限、行页定位、数值复算和文件渲染可以由有守卫的工具节点执行。论文是否做了等价实验、批注是否推翻主张、是否该停搜或转实验是有边界的语义交接；记录交接的输入、候选、答案、验证与回退。
- **局部重复性**：寻找跨论文／跨任务真实重现的来源固定、版本识别、批注／引文定位、数值定义核对与报告重验子图。必须观察到参数重新绑定与至少两个独立任务支持；同一决定的增量轮次只算一个任务实例。
- **有界惯性**：保留一类只需重验后可沿用的真实变化，以及一类新反证或问题改变而必须打断旧路径的真实变化。历史顺序只能提出候选，不能凭频率跳过科研判断。错误沿用与无谓重算都计入结果。

## 下一次付费运行的准备边界

先完成工作包 1–2 的无模型检查和 AIDD 只读范围预览。下一次原生 DSH 试点建议以 Flash 为主，**每任务最多 30 次请求、US$2 本机费用门**，把最终综合输出上限与探索步分开设置；若需 Pro 判断，再单独给出输入、最多请求数和费用上限。每个任务的具体资料摘录、收件对象、模型预算与交付位置须在启动前另做预览和确认。本文件不是新的私人资料外发或付费授权。

2026-09-26 的 AIDD 准备产生了[只读试点提示词](../benchmarks/research_weekly_loop_v1/aidd_baseline_prompt.md)、[限定工具配置](../config/aidd-scoped-baseline.patch.yml)和[预览／付费守卫入口](../scripts/run-aidd-initial-pilot.py)。启动前的审阅范围保存在 `.local/benchmarks/research-weekly-loop/aidd-next-preflight/PREVIEW.md`：4 份冻结的公开 Idea State、2 段 Obsidian 行段、2 个 Zotero 条目、6 条批注及 2 份论文 PDF 的指定页段。运行入口要求经研究者同意后的逐来源开关、与预览一致的范围和提示词哈希、独立批准记录，以及本机 US$2 费用门。20 个相关 MCP 工具已枚举；该配置**禁用原生命令与文件工具**，因此只能作为受限 MCP 诊断，不能与保留命令的自由 Harness 基线混报。实际运行状态见下方，不能把 AIDD 称为合格交付或完整闭环成绩。

此阶段不因一次 Model RSI 试点的约 US$0.033 用量估算而假定其他任务同价；每次记录缓存命中／未命中 token、输出 token、费用门预留、供应商实际扣费和人工介入。若原生 DSH 连续两题仍无法交出合格科研决定，先解决工具可用性、搜索停止与证据核验，再考虑 Motif 成本对照。

## 2026-09-26 执行状态（试点成绩尚未验收）

- 工作包 1：Model RSI 的截断状态、实际行页覆盖和错误“未读”主张已经由私有原始轨迹重验；关键科学推断仍需研究者／盲评核对，DeepSeek 控制台实际扣费尚未对账。
- 工作包 2：Obsidian／本地来源与 Zotero 条目／批注有版本绑定的 `source_id`，来源和权限变化会使旧句柄失效。AIDD 真实 DSH 轨迹中，审计器识别 26 条 `pin → read` 参数边，覆盖两类应用。这满足**单任务、双应用的参数流可观测性**；仍未挖到跨任务 Motif，也未证明复用收益。
- AIDD 初始决定局部试点：受限的三组 MCP 共 20 个可用工具，Agent 实际调用 90 次、19 种，其中 15 次失败／不可用。20 次成功 Flash 请求共 1,080,255 token；费用门保守预留 US$1.4930529（包含一次 HTTP 502 尝试），实际扣费未核。首段 `max-tokens` 截断，在同一批准额度内一次续写后正常结束。私有原始记录与候选材料在 `.local/benchmarks/research-weekly-loop/aidd-next-preflight/paid-run-01/`。
- 逐步成本审计：首轮 prompt 从第 1 步 5,229 token 增到第 19 步 110,009；第 16–19 步只有 12 次工具调用，却消费 407,088 prompt token（389,504 为缓存命中）。最后一轮无工具调用仍因 8,000 输出 token 截断，续写又提交 97,760 prompt token，全部记为缓存未命中。仅自动化 `pin → read` 未必解决主要上下文与续写开销；后续需给普通窄上下文／摘要恢复基线公平对照。逐步私有数据在 `paid-run-01/step-cost-audit.json`。
- 初步质量审查发现把特定论文基于合成数据的训练规模估计用作普遍实验标签硬门槛、把抗体数据集的接触数基线数值移植到蛋白–配体实验等问题。**交付仅为候选材料，未通过研究者／双人盲评质量门**；本题不得进入合格成本节省分母。
接下来先修正并盲评 AIDD 决定材料的关键主张，核对补充材料和数据可得性；再找第二个独立研究决定取得同类真实参数链。不能把本题的多次批注或续写当作第二个任务，也不能因为这次 90 次 MCP 调用就宣布机制有效。
