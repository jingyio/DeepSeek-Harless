# 文件管理种子 file-v4

当前跨平台路径/UTF-8/PDF-OCR兼容实现下重新独立认证的集合读取策略。公开内容仅含 IR、源码锁及脱敏见证，原生认证和两次实际认证均使用新材料；不导入旧授权，不修改旧证书。早期 file-v1/v2/v3 保留其原始源码和认证定位，版本不匹配时停用。各账号继续独立学习；依赖或目录不兼容时保留拒绝回执并走普通 Harness。

PDF/OCR 缺少默认外部命令时使用 main 已有的 PyMuPDF 与固定 OCR 语言数据，实际读取后端与覆盖记录绑定。Windows/Linux 的免费 CI 结果不代表真实账号部署或稳定净收益；未知目标仍须复核。
