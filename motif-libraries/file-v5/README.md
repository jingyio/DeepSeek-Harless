# 文件管理种子 file-v5

当前通用工具目录、请求、回执UTF-8及下游Python UTF-8实现下重新独立认证的策略；包括集合/单文件读取和预览计划到受控执行。以entry.json的实际条目为准，不把同结构策略版本当作不同工作流。每项保留原生认证与两次独立实际认证的脱敏摘要，不导入旧授权。高风险计划仍由原生逐计划确认，Motif不授予新权限。

旧file-v1/v2/v3/v4保留。各账号独立积累经验，当前目标、schema、权限、状态或版本失配即回普通Harness。原始资料、轨迹、失败、恢复文件和完整账本留在私有目录。独立认证和请求跳过不代表任意目标均可严格验收或稳定净收益。
