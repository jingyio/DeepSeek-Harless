# paper-web-v24

基于 paper-web-v23 的公开上下文与宿主生命周期兼容版本。仅更新已审阅的任务宿主与网关源码锁：同宿主读者先校验会话归属，再提供用户原文及公开最终助手文本，排除工具参数、结果和附件解析记录；独立执行器已启动的父会话继续通过新私有 Chat scope 承接，原生轮次未闭合时仍拒绝新的并发发送。网关移除跨用户首次启动总数闸门，保留同用户启动去重、凭证、路由归属及通信检查。不宣称已测更大容量。MCP、工具 schema、来源边界及模型权限不变。原 IR、manifest、任务、工具 schema 和来源证据字节不变。旧库保留，无新训练、私有轨迹重放或模型调用，不代表质量或成本效果晋级。File SDK 源码由其独立真实认证负责，不通过本兼容库替代。验证与限制见 [docs/experiments/five-user-stress-20261020.md](../../docs/experiments/five-user-stress-20261020.md)。
