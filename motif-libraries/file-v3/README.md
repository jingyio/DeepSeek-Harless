# 文件管理种子 file-v3

当前集成源码下通过独立认证的3 项认证策略（单文件 pin/read，以及集合 select/pin/read/collect 的两个独立版本）。集合图来自新材料的两次普通 Harness 轨迹，另用原生认证及两次独立实际复用认证，不用最终留出集学习。

file-v1 保留旧源码锁与失败历史定位；file-v2 是本轮单文件图的中间发布快照，当前安装选择相同源码下最新的 file-v3。公开内容仅含 IR、摘要和脱敏见证，不含原始资料、轨迹、恢复信息、私有证书或旧权限。各账号独立运行和持续学习；每次复用仍核验当前 schema、权限、状态和参数，失配回普通 Harness。这些证据不等于所有自然语言目标均可严格验收，也不证明稳定净收益。
