# 一页摘要

**研究问题。** 科研 Agent 在跨资料任务中，是否能从过去的工具轨迹学到局部、可核验的参数关系，在后续任务中自行执行这些步骤，减少完整大模型请求，同时把证据判断和科研决定留给模型或研究者？SSS 以 MotifAgent 为运行内核，DeepSeek Harness（DSH）为本轮语义执行器。

**目前最强的正结果。** 在六类、十八项独立的**合成**科研决定中，已有十五项完成普通 DSH 与在线 Motif 同题配对。实际模型请求合计 **129→74**；Motif 审计记录 **80 个结果经验证的接管轮次**，但净请求差是 **55 次**，不能把接管数直接当节省数。按 API usage 和缓存命中计价的本机费用代理为 **$0.059466→$0.046033**，下降约 **22.6%**。在事后核查发现**两组答案都可用的九题**中，请求 **77→45**，费用代理 **$0.034618→$0.027504**，下降约 **20.5%**。这些数字来自[跨类型试跑](../experiments/六类科研决定任务与在线Motif跨类型试跑_2026-09-28.md)与[逐题质量核查](../experiments/科研决定组合质量门槛评测_2026-09-28.md)。

**结论边界。** 来源和应用返回由隔离 MCP 模拟，不是实际 Zotero、WPS、Gmail 或课题组资料；九题是事后按答案质量选出的可用交集，不是预注册的主要终点。质量核查由项目 Agent 完成，缺独立研究者盲评和人工修订时间。费用是本机计价代理，尚未与 DeepSeek 控制台账单核对。当前可以说“在这些合成任务中，已认证的局部工具链确实替代了部分模型请求”；**不能说 SSS 已降低真实科研合格交付的总成本**。

# 1. 为什么研究这个问题

课题组的日常工作反复出现“收到变化 → 找到具体资料 → 核对版本 → 读取关联证据 → 重算或定位 → 判断是否修订主张 → 交付待审材料”。其中来源 ID、版本、表格范围和已授权依赖可以由工具与规则核验；论文是否支持主张、结果为何变化、下一步实验是否值得做，需要语义判断。若每个可核验的中间步骤都重新请求模型，Agent 的重复决策会累积费用与等待时间。

SSS 的假设不是“整条科研流程可写成固定脚本”，而是**不同问题中有可迁移的局部结构**：例如上一步返回的来源 ID 是下一步读取的唯一必填参数。运行时只在参数、版本、权限和已认证工具边均满足时接管；遇到口径变化、冲突或无法唯一确定的目标时回到模型。这同时检验结构—语义分离、局部重复性和有界惯性。

一个可复述的接管例子：

```text
模型已选择要核查的对象
  → MCP 返回对象 ID、来源版本
  → Motif 核对已认证的“对象 ID → 固定来源”参数边
  → MCP 返回固定来源 ID、哈希
  → Motif 核对“固定来源 ID → 读取”参数边并执行读取
  → 发现新证据的科学含义仍交给模型判断
```

这段结构来自独立任务中的真实工具调用轨迹及 schema，运行时还检查当前对象版本。它并不预写“哪篇论文重要”或“结论应如何改”。普通 DSH 同轮若已并行完成全部读取，就没有可节省的后续模型请求；所以评价必须看**实际上游请求**，不能只看工具数量。

# 2. 任务设计与实验方法

## 六类任务、十八项独立决定

[任务集 v1](../benchmarks/research_decision_portfolio_v1/README.md)与[任务集 v2](../benchmarks/research_decision_portfolio_v2/README.md)各有三类、每类三题。题卡、来源对象、隐藏评审标准和哈希锁分开保存；同一决定的旧版与新版资料只算一题。

| 类型 | 日常科研问题的示例 | 结构步骤与必须保留的判断 |
| --- | --- | --- |
| 文献证据修订主张 | 新方法或批注到来，旧研究主张是否要改？ | 定位来源、引文和依赖可核验；方法与评估单位的含义需判断。 |
| 实验结果可比性 | 新底物批次成功率能否直接和旧试点比较？ | 读取两版记录、复算分组；口径变更时要停止旧解释。 |
| 协作反馈 | 审稿人要求负对照后，怎样更新证据并拟回复？ | 邮件线索指向数据和待办；回复承诺与实验充分性需判断。 |
| 交付物来源链 | Model RSI 组会图能否继续使用“持久状态优于检索”的标题？ | 从图卡追到数据、脚本、批注；图题是否成立需判断。 |
| 复现结项 | 两个种子的提升是否足以宣布复现通过？ | 读取运行记录和预登记条件；证据不足时不能结项。 |
| 下一实验选择 | 证据冲突且资源有限，应先做哪项区分性实验？ | 找出相关来源和资源窗口；实验选择与理由需判断。 |

两组使用同一题面、DeepSeek Flash、`reasoning_effort="off"`、八个只读 MCP 工具及固定顺序。工具为 `read_event`、`pin_resource`、`read_pinned`、`read_rows`、`aggregate_rate`、`compare_tables`、`find_dependents`、`locate_excerpt`。模拟对象可代表文献、笔记、表格、邮件、日历等，但**对象出现不等于真实桌面软件接口已受测**；邮件和日历无写入口。

从两项 v1 普通 Agent 轨迹训练，并用第三项独立轨迹认证后，编译出四条可在线执行的只读参数边。v2 九题在编译和阈值设定时均未见过，整版纳入评测；v1 对照六题则是在看过普通组答案后选择，有选择偏倚。Motif 组在模型请求前检查参数见证、来源版本、工具 schema 和匹配阈值，通过后才替代该轮请求；失败则回到模型。每题有预算闸门、逐请求 usage、工具轨迹、接管审计与 A/B 隐名答案。

# 3. 结果：请求减少已观察到，合格交付收益尚未证实

| 配对范围 | 题数 | 普通 DSH 请求 | Motif 请求 | 经验证接管轮次 | 普通费用代理 | Motif 费用代理 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| v1 选择的六题 | 6 | 55 | 29 | 30 | $0.024752 | $0.018883 |
| v2 全部九题 | 9 | 74 | 45 | 50 | $0.034714 | $0.027150 |
| **全部配对** | **15** | **129** | **74** | **80** | **$0.059466** | **$0.046033** |

两组的缓存命中输入为 379,520→206,592 token，非缓存输入为 73,671→74,711，输出为 29,240→18,650；按各自计价，费用代理降幅约 22.6%，小于请求降幅 42.6%。逐题运行用时之和为 197.2→143.6 秒；不含开发、服务启动和人工审阅。

质量必须和价格一起看。项目 Agent 对十五份隐名 A/B 答案按必要点和材料错误做事后核查：普通组可用 **10/15**、Motif 组 **11/15**；**九题两组都可用**，另有仅普通可用一题、仅 Motif 可用两题、两组都不可用三题。共同可用九题的请求为 **77→45**，费用代理为 **$0.034618→$0.027504**。这只是同等可用条件下的描述；九题交集是事后筛选，不能替代全部任务的质量调整成本。

典型错误说明为何不能只报请求数：一题中 Motif 把两个种子的方向误写为“不一致”；显微镜组会题把四格全表分母写成 240，实为 480。分组数字、主张方向与来源支持必须先过质量门，再计算人工修订后的成本。Pro 模型的匿名评审也出现格式和事实遗漏，因此本轮没有把模型裁判当作独立质量标签。

# 4. 与简单方法及真实任务的关系

在三项更同形的合成组会决定中，Motif 相对普通 DSH 把请求 **22→11**，但一份可复用的固定取证脚本加一次 Flash 写稿合计只需 **3 次请求**，费用代理也更低。[该对照](../experiments/组会决定链跨任务模型跳过与强脚本基线_2026-09-28.md)说明：对结构几乎固定的任务族，脚本可能更合适。脚本本身的编写、维护和适配新任务成本当时没有计入，故不应将它的 3 次请求解释为零成本产品方案；同样也不能隐去它比 Motif 更便宜的运行结果。

最近的[真实 PBCNet2.0 增量题诊断](../experiments/AIDD突变增量真实MCP同题诊断_2026-09-28.md)进一步限定了迁移主张：原 Motif 运行没有经验证的跳过；修复 Zotero 来源类型守卫后，诊断复跑安全跳过 **1 次**，但整题 52 次请求，高于普通 DSH 的 45 次，且工具错误恢复较多，答案未获研究者质量判定。这不是合成任务结果的反证，也**不是**真实科研成本增益。它指出当前认证边覆盖的只是该任务很小的一段，工具类型和错误语义也影响执行路线。

# 5. 当前能够向导师主张什么

1. **机制存在性已验证。** 在多种合成科研决定中，SSS 从跨任务轨迹编译局部参数边，并在真实 DSH 模型请求前执行、核验结果，观察到请求减少；v2 九题是未参与编译的新任务类型。
2. **收益有适用条件。** 来源对象明确、版本可核验、后续参数能从工具结果绑定、普通 Agent 会为该中间步骤另发模型请求时，Motif 最可能有用。多分支的科学取舍和统计口径选择仍需语义层。
3. **产品收益尚未证明。** 合成来源、非独立质量审阅、费用代理、未计人工修订与开发成本，以及真实题上缺少净收益，均阻止我们声称“已让课题组科研交付更便宜”。

下一道可检验的里程碑是：冻结一个**新的独立真实科研决定**及两组相同工具合同，先修笔记／本地文件的类型读取错误；让研究者盲评可用性并记录修订分钟数，再比较完整请求、缓存计价费用与总耗时。若真实任务仍主要由一次开放式复算和判断构成，就应把 SSS 的目标收窄到有反复跨应用对象依赖的任务，继续保留强脚本作为对照。

**答辩时的一句话：** 我们已经在多类型合成科研任务中验证“经过认证的工具依赖可以替代部分模型决策请求”；尚未证明这种结构复用能在真实科研资料上降低每份合格交付的总成本。

详细数值、失败案例与历史诊断的去向见[实验资料归档索引](archive/实验资料归档索引.md)。
