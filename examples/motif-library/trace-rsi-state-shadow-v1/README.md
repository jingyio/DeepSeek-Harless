# Motif 如何学会“这次不要再检查”

这是可读摘要，不包含私有论文、Session、来源或请求见证，不能加载为执行库。

上一版学到了“读报告后检查”。但报告已经检查过，模型再读一次准备总结时，这条边仍预测检查。本轮让编译器同时看正常续接和正常不续接。

```text
读报告，当前版本 h1 → 检查 h1
再读 h1 → 已有本会话成功检查记录 → 不预测重复检查
模型修订，得到 h2 → 没有 h2 的检查记录 → 可预测检查 h2
```

“不预测”表示交还原生模型请求，不自动结束任务。模型仍可修订、说明结果或选择其他操作。这里的 h1/h2 表示当前输入、报告、来源、目录及生成工具的摘要组合，不是历史论文 ID。

工程提供状态特征 `prior_same_input_check`；编译器从2个正常正例、2个正常负例学出 `== false` 的条件。不是手写“所有读操作都必须先检查”，也不是模型自行创造了完整状态学习器。原生成工具与任务提示不变。

两条历史反例回放中，原来的2次结束误预测均被拒绝，4次正确预测保留；这是免费回归验证。本轮三条真实Shadow共15请求、5次完整工具调度匹配，严格整请求0、实际跳过0。新任务没有末尾单独重读分支，因此不能认定该结束分支已通过前瞻认证。

另一个边界：主稿把“检查 + 再读”放在同一模型请求里，图只预测“检查”，不能替代整次请求。下一步需要学习完整批次及控制文字交接。
