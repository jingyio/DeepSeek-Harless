# 科研文献与知识管理：40 个任务流程与结构候选

2026-10-13进展：多窗口pin/read候选已用新普通轨迹学习与独立认证，复用旧核心在线批量读取，见[正式记录](../../docs/experiments/window-continuation-20261012-0bc4ddc5.md)。同窗口组件6包一致且读取模型请求减少；完整任务一题小幅改善、一题费用变差，默认不推广。下表仍是40个候选任务，并非全部已实验或有效。

2026-10-12。按用户目标扩大任务覆盖，暂缓目录标题等细小修补。40 是本轮列出的消费任务数，不是已实现能力数、不同算法数或已学会的 Motif 数。任务可以组合；同一种结构在不同任务中复用仍有价值，但不得改名后重复计算机制创新或省请求。

状态：**现有**=已有入口/实验；**可试**=现有三篇普通 PDF 或真实派生笔记可做开发实验；**工具**=需要适配器/工具；**材料**=需要不同材料才能有意义地验证。优先级是本轮开发判断，不是已测效率排行。工具本身的批处理、缓存、文件 diff、正则和引用校验都是共同基线，不能归为 Motif 的新增收益。

## 优先学习的结构族

1. **语义计划后的映射/搜索网格**：模型选择检索词及论文集合后，参数从明确计划中来，Runtime遍历并汇总。与已有任务入口逐paper_id读取不同；须保留查询选择和命中解释的模型边界。R02/R07优先。
2. **真实工作数组的逐项读取与结果汇合**：引用、批注、资源、失效笔记属于不同业务对象，但共享数组读取模式；已有foreach入口可以作为基础。W01的多引用→一论断join需单独检查覆盖，不能把旧source_id直接移植到新会话。
3. **结果驱动的条件分支**：找到/找不到、正常/低文本、当前/失效、可达/限流→不同续接。只学习可检验工具状态的分支；语义“不相关”不是可直接缓存的条件。C06/C07/X01的失败材料目前不足。
4. **依赖差异驱动的局部工作集**：来源/批注/引用变化→受影响对象→重新组包，U01/U02/K05可共用机制。新反证的语义影响检测尚未自动解决。
5. **实际收据后的交付结束**：文件摘要、完整目标和状态满足契约后替代纯状态说明/stop；已有窄范围实现，不能替代新的分析结果或自动覆盖缺口。

这一分类是研究者提出的候选空间，还不是轨迹学习产物。固定哈希、排序、正则抽URL、BibTeX格式化、未变结果缓存适合普通程序；不为增加Motif数量拆成更多模型步骤。相同功能的工具能力必须同时给Harness和Motif两组。

## 本轮最小实测与接口边界

`workflow_probe_tools.py`在原PdfScene上增加三个窄任务，`explore-workflows.py`调用原生`run-scenario.py`、SDK与预算代理；没有新模型循环、模型参数训练、前端或共享核心修改。每个任务独立Session，两种问题/范围分别运行。只读原PDF；报告写私有.local，无需人工审批。

- 主题检索：模型选词、逐篇搜索、选择并读取窗口、交付针对问题的证据摘要。没有预设查询词/搜索网格答案。
- 引用核查：输入来自以前真实模型笔记；旧PDF摘要、物理页/偏移、窗口版本和原句摘要完整冻结；重放真实窗口后逐项检查。只验证来源可定位，不宣称引文支持原断言。
- 资源清单：原文URL与上下文→模型分类/选择→受限HEAD→报告；不猜断行URL，不下载外部代码。只允许github.com/huggingface.co/zenodo.org/osf.io的无认证HTTPS链接，最多8次、单次5秒、不追随重定向。403/429/超时均不宣布资源不存在；HEAD成功也不证明维护或复现成功。

来源/任务/实现变化拒绝发布；报告要求完整覆盖，引用与资源ID来自本次真实工具，保留未命中和不确定状态。科学支持未独立验收，探针不是完整产品交付能力。

新工具仅进入这个探针的场景配置，不进入现有正式Agent默认工具集合，不改变旧Motif认证版本。若接管“模型已选查询后的网格遍历”，共享接口还需要：多参数/整数常量绑定、模型实际计划的身份与来源证明、非入口事件前沿、分支终止与结果汇合、工具失败后的原Harness交接。**本轮只记录候选需求，不实施核心变化，不声称现有标量paper_id入口已支持网格。**先从普通轨迹筛出实际请求最多且守卫清晰的部分，再列逐字段协议变化。

## 复现

先准备并预览（evidence须是以前真实模型笔记的私有工件，旁边有source-snapshot.json）：

```sh
node scripts/project.mjs python scenarios/literature-notes/explore-workflows.py --evidence .local/<真实任务>/evidence.json
node scripts/project.mjs python scenarios/literature-notes/explore-workflows.py --experiment .local/literature-notes/<返回ID> --call-model
```

第二条仅在已授权付费实验时执行。每任务预算保护上限0.25美元，6任务合计上限1.50美元；不是预期费用。可加`--case topic-methods`单独执行；旧attempt拒绝覆盖，失败留账。记录原始工具schema、输入/来源/实现/题面/运行配置、实际原生事件和决策分析。请求重复只是候选；真正学习、独立认证和在线H/M对照需后续实施，不能从本轮基线省多少的反事实推算宣称已节省。

借鉴依据沿用[参考设计](reference-design.md)：AutoTool的操作/参数来源、G-Agent的局部复用、Structure–Semantic Separation的守卫/交接、Stagehand的探索后版本化重放。采用机制不等于照搬其经验收益；当前三篇开发PDF不代表新语料泛化。
