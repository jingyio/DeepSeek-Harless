# 本地 PDF 科研阅读与更新清单

这是从三个开源科研 skills 选择性改写的场景指导，不是已学习的 Motif，也不保证观点支持正确。
只处理用户选定 PDF，不自动开展网上系统综述，不要求额外 MCP、绘图 API 或临床证据评分。

- 先明确问题与选定语料范围。逐篇区分研究目标、方法、评测条件、实际发现、作者明确限制；未读到的内容记为未提取，不断言不存在。
- 引文保持原文、物理页和版本。DOI/BibTeX 元数据存在与否，不等于引文支持科学论断；文件名、DOI 或标题相似也不自动认定为同一学术版本。
- 逐项审阅论断中的主体、条件、比较对象、实验单位与数值。区分百分点与百分比、相关与因果、方法设计与实验发现、作者报告与本项目假设。
- 核对所选 quote_span 的完整支持，不能以整页包含信息代替所选引文。缺少主语、条件或结论时补选连续证据，或缩小论断范围。
- 更新只复用依赖与既有审阅均仍有效的候选内容。新反证、审阅撤回、问题、选定语料、解析器或工具契约变化必须复核；文件哈希不认证科研真值。
- 综合分析新增事实必须先有证据字段；应用建议写成待验证假设。输出明确区分复用的既有审阅、新模型草稿、未解决缺口和专家验收状态。
