# GeneLoop 文件管理命令 /management

以main `2a03e22`为基线，文件管理复用平台已有Files场景，公开入口改为`/management`，内部scene ID保持`files`。原`/files`继续可解析为同一场景；会话设置与文件授权不因快捷命令命名而迁移。

注册登录后，新建并命名工作区，再创建会话。输入`/management`选择文件管理，上传文件后描述盘点、读取、查重、索引检索或整理需求。例如：`/management 盘点这些文件并找出内容重复项`。菜单和场景标记采用服务器返回的`shortcut=management`，直接输入中文紧随命令也能解析。路径`/management/report.txt`或正文中出现该词仍作为普通文本处理。

默认只读。需要复制、移动/重命名或隔离时，在场景菜单开启“允许整理任务副本”；服务只授予当前批准上传的副本、指定目标前缀及最多6步，仍须预览、授权和真实收据，不能访问其它账号/会话或修改上传原件。该命令选择本身不调用模型，也不改变预算、邀请注册或工作区所有权逻辑。

此改动接通现有GeneLoop Files的13工具入口。独立`feature/rsi-research-agent`分支另含17工具的文件操作v2/持续学习/恢复及4份原始公开学习策略（`f397645`）。改快捷命令不是跨工具契约迁移或新的独立认证；不能直接给这套旧13工具服务宣称已激活那4份v2库。原始证据及费用记录保留。

验证：快捷命令及原生任务分发的52项确定性检查通过，覆盖选择零模型调用、剥离控制前缀、旧命令兼容、默认原任务写授权为空及原data/ppt/paper/chat入口。完整本地`npm test`：889 Python、578 Node通过，3可选跳过；18无模型smoke通过。macOS临时目录别名的权限测试改为核对真实目录，保留所有路径/所有权守卫。CI按主线要求执行。这些检查不代替真实模型文件任务效果验收；本次不新增付费模型请求，也未部署线上平台。
