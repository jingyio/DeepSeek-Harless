# PDF读取计划与论断支持复核：GitHub提交说明

新增论文曾出现评测/发现缺口、选中引文不覆盖算法或基线名、token比率混称时间加速等问题。部分双栏页面还被原解析器交错读取，导致限制的条件归给另一栏的算法。此次优先修复输入与交付质量，再减少机械读取步骤；实验事实和失败见[实验记录](../experiments/read-plan-20261011.md)。

## 场景变化

- `pdf_read_plan.py`、`read_pdf_evidence_plan`：模型选择有界物理页窗口，服务先验证完整计划、PDF/解析器版本，再批量pin/read。最多8窗/36000请求字符，每窗最多12000；重复计划内窗口拒绝。既有解析缓存仍重查源版本。窗口选择、科研支持与下一项研究判断由模型承担，不是learned Motif。
- `read_claim_evidence_plan`：补读同一论断的至多3个6000字符窗口，与单窗共享原额度。重复批量窗口重查版本后复用；新读取失败仍扣额度。不能借另一论断的引文权限。离线恢复可重放真实批量工具事件，不补造事件。
- `claim_coverage.py`：提交时检查最终选中引文中的缩写/驼峰技术名称，提示缺失算法、模型或基线。与原数字检查一样，它是必要字面条件，不认证语义支持、比较关系、单位或完整否定。
- `support_audit`：supported/revised须提交30–1600字符support_anchor，程序只接纳最终选中连续引文内的实际原文。它不认证中文语义。正常运行默认至多两轮，第二轮只补缺口，已通过字段保持不变；无缺口为0次新增调用。默认正常工作流从独立重提取改为对当前论断及选中引文进行支持复核；此模式最多80字符，要求缩成一个事实，不自动截断。`--audit-all`仍可显式盲重提取，120字符上限保留；缺口续修与其原范围不变。支持复核有修改时，重新读整份当前表综合，直接交付，无Human审批。
- `pdf_layout.py`：对明确宽幅双栏散文块按几何位置重排；数字表格、窄栏、跨栏歧义保守不修。修复页使用bbox词元生成文本，保留词元和断行连字符，不能冒充旧plain-text偏移。解析profile升级v3并绑定实现摘要，旧引文、缓存依赖与对应旧Motif认证需失效/重新认证。该规则不是通用PDF布局正确性保证，不做OCR。
- 可选bbox提取崩溃时保留成功的普通文本，返回`bbox_unavailable_original_text_retained_layout_unverified`。普通提取、页数对齐和资源上限仍失败关闭；fallback策略进入解析版本，旧句柄不能强制复用。
- 批量读取在完整校验后用请求隔离的`ContextVar`复用该次已验证来源，仅执行内存pin/read，结束恢复上下文并再次检查真实文件。解析/缓存发布不能进入免重复校验范围；读取中源变化和另一线程均有回归。修复批量仍在成功返回后才授予本论断引文权限，失败已用额度不回滚。
- `check-read-plan.py --job <UUID>`从实际原生模型调用取得同一多窗计划，比较并行pin/read与批量MCP，暖机后交替四轮，要求所有上下文完全一致。0付费请求、0验证跳过；它测量MCP读取成本，不能当作整Agent、质量或Motif收益。首版批量反而慢的结果保留，最终实测另录。
- 支持anchor增加真实句末边界（policy v9）：来源中连续原句必须有句末标点，截断则补实际相邻引用、改为更短事实或留缺口，不能人工/模型补句号。当前三论文15字段/19引文通过精确重放；该规则仍不认证中文含义。最终测试342 Python+44共享Node，场景21 Node包含在Python包装。
- 阅读/增量/修复配置新增工具；契约及工作流摘要包含新模块和场景配置。实际模型、80/120限制、版本、参数与原生费用收据保存在私有运行区。默认复核仍用Flash；Pro仅作可显式选择的候选，实验不支持它必然更可靠。

## 唯一新增共享入口变化

`scripts/run-scenario.py --model`新增官方ID `deepseek-v4-pro`，原 `deepseek-pro`别名在启动前归一到该ID。预览增加`requested_model`，`model`记录实际ID。旧别名此前通过CLI却被已有预算代理拒绝；修补不修改价格表、预算、Harness SDK、上游或共享Motif规则。Flash默认不变，无模型预览仍不读取Key、不发付费请求。

官方名称依据：[DeepSeek模型列表](https://api-docs.deepseek.com/api/list-models/)。兼容代价是旧Pro别名现在产生真实官方模型调用，历史失败记录不改写；旧工具轨迹/认证不因此自动升级。

## 验证与范围

新增原子计划校验、跨论断拒绝、额度共享、版本失效、读取中变更/线程隔离、技术名漏引、数字同名不证明支持、80字符不截断、最终连续引文anchor、几何重排词元守恒/数字表格保持/bbox崩溃回退、官方Pro/旧别名免费预览回归；真实stdio MCP调用批量工具。完整测试与真实质量结果见实验记录。

本次除上述共享启动入口及对应测试外，只修改文献场景、相关测试与文档。之前工作区的共享改动保留；未commit/push/PR。原论文、Key、轨迹、失败和费用均不提交或删除。没有新增已学习Motif、没有把普通批量工具/依赖缓存计为验证跳过，也没有同质量端到端降本结论。
