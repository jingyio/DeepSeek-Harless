# GeneLoop 文件管理与持续 RSI 接口

本次开发和发布仅在 `feature/rsi-research-agent`。将 GeneLoop 前端依赖从 main 引入本分支；不把本分支合入 main。旧 SDK 文件场景与实验记录保留。

`npm run management -- --real-model` 使用原生 GeneLoop 会话、同一 Agent 工具生命周期及持久化 `daily-management-real-v3` 经验库。`/management` 和旧 `/files` 均进入文件管理。默认允许在服务端为当前用户、工作区创建的任务副本内复制、移动、重命名、创建目录和可恢复隔离。只读模式继续可选。用户原件的上传回执与副本版本逐项核对。

覆盖、永久删除及登记在当前用户名下的外部目录操作，需要 Harness 原生的一次性确认。确认绑定实际任务、计划摘要、调用 ID 和真实 `approval/asked` / `approval/decided` 事件，无法由模型生成批准令牌。高风险恢复另行确认；拒绝及相同影响的重复请求保留。未登记的外部路径直接拒绝。可信外部根可通过 `--management-external-roots` 提供私有 JSON：根 ID 必须以 `external-` 开头，包含 `path` 和与当前服务用户一致的 `owner`。

共享接口变更：

- `management_tools.py` / `management_native.py` 提供相同的 17 个 MCP 工具与 `sss-management-v3` 范围。前端包装器保留 Annotated 数组约束；免费检查逐项比较完整 SDK / 原生 MCP catalog。
- `management_contract.py` 的 `sss-management-quality-v3` 冻结任务身份、原始文件和目录、逐步影响范围、当前文件身份、实际确认与恢复链。可在任务开始前增加明确目标谓词。缺少目标谓词时，仅验证效果和交付完整性，不能宣称任意业务目标都已完成。
- 原任务持久化账本约束每任务最高 USD5、96 步和请求、4000 输出 token、2 次验收修复及总共 2 次服务商瞬时错误重试。更低的入口限制继续生效。全系列 USD1000、共享学习 USD25 的已用和保守预留费用不重置。
- 每个原生会话的新任务拥有独立账本；原生会话 ID 仅映射到当前活动任务。旧任务关闭并结算后才可重新绑定。服务输出、DSH 历史及全局账本默认持续使用固定目录，重启不创建新预算。
- 操作逐边界记录，先落盘意图，再执行原子文件操作，保存备份及目录状态。跨卷发布先登记目标目录的私有暂存路径、完整复制并 fsync / 校验摘要，再在目标卷原子发布；仅登记的暂存文件暂时从用户快照排除，未知文件和符号链接仍拒绝。中断可继续复制或清理未发布暂存后恢复，撤销目录前先清理登记暂存。恢复校验原代码、权限、文件版本、原预算及所有已完成边界；不重复已有效果。永久删除明确不可恢复。当前跨任务自动撤销仍需另行适配；本次认证覆盖原任务的恢复链。
- `harless_management.ts` 在真实工具结果后匹配当前库，用相同工具执行结构续接，语义选择仍由普通 Harness 完成。匹配、作用域、schema、版本或验收失败时回到普通 Harness，沿用原预算和修复次数。RSI Off 不执行、选择或学习候选。
- `continuous_rsi.py` / `continuous_motif_learning.py` 统一封存原生轨迹、费用及失败，使用已登记的 `management_v3` 材料与质量适配器发现图、学习、独立认证、激活和停用。不使用 `profile_id` 指定正确模板。实际效益持续记录，稳定净收益不作激活条件。留出集禁学，失败候选不修改标准使其通过。
- 前端显示当前兼容库、学习认证、复用与估费状态；整理报告及文件副本输出到本会话目录。报告下载校验所属任务与文件摘要。原始轨迹、凭证、恢复备份及认证证据仍在私有 `.local/`。

对持久化任务的付费 SSE 完成，代理先提交原账本结算与日志，再将完整响应交给下一 Agent 步骤，避免账本写入竞争；其它普通服务的流式显示保留。费用仍是代理估费，未核对服务商账单。

本次只接通已登记的文件管理 MCP；其它 MCP 的权限、独立材料生成器和验收适配器需要单独登记。公开经验包保留原政策字节和认证摘要，不能把公开摘要当作私有执行授权。
