# 阅读计划归一化与决策记录：提交说明

此前阅读预算按请求长度计费范围检查，即使窗口超出物理页尾仍全额计算；重复窗口拒绝、重叠窗口重复返回。现有解析缓存继续使用。本轮将机械执行改为完整保留已选原文范围的归一化，并记录整个工作台流程的实际选择、失败与费用。没有新增 learned Motif，没有修改共享 Harness、预算代理、Motif IR 或在线插件，也没有修改原论文。

## 场景接口变化

- `pdf_read_plan.py`：`exact-selected-coverage-v2`。完整验证输入后按实际页尾计算长度，合并同页重复/重叠范围；合并范围超过单窗上限时仅分块，保持所选位置集合完全相同。真正超过总预算仍拒绝，不能静默删掉内容。普通阅读保持最多8个输入窗口/36000实际字符/单窗12000，修复保持最多3个输入窗口/18000实际字符/单窗6000。
- `read_pdf_evidence_plan` 参数不变。返回 `contexts` 对应归一化后的窗口，数量可能小于输入；新增 `normalization`，包含请求与实际字符数、输入到返回上下文的映射、策略版本和非语义执行声明。调用者不能再假设一项输入对应一个新凭证，必须使用实际返回的 `source_id`、`quote_spans`。
- `read_claim_evidence_plan` 仍按论断隔离权限、与单窗共享原额度；按归一化的新窗口扣额度，重复已成功的批量窗口重核版本后复用。失败尝试仍保留消耗。内部直接执行已校验的键，避免普通阅读的不同单窗上限再次合并、破坏额度与凭证对应关系。没有改变单窗修复工具的失败尝试扣额规则。
- 版本化原文上下文增加会话内缓存，原PDF、页面文本和解析profile检查仍先执行；返回深拷贝，调用者修改不能污染缓存。`prepare_pdf.cache_stats` 增加 `context_cache_hits`。已有按PDF内容/profile分区的磁盘解析缓存不改键；`off`仍关闭磁盘缓存，同会话内存复用仍存在。
- `literature_evidence.list_pdfs` 增加 `reading_budget`。`register_reading_plan` 按同论文、同purpose归一化；不同用途保持独立，不编造/合并研究理由。返回 `requested_plan_sha256` 和归一化 `plan_sha256`；批准凭证绑定实际执行计划。参数、许可字段和schema v1形状不变。空白页保留供原低文本检查报告缺口，不能忽略它后认证其他窗口。
- Evidence执行版本摘要新增 `pdf_read_plan.py`；改变执行代码会使旧包/许可失效，历史认证不能直接沿用。`compare-evidence.py` 用当前服务归一化原生批准参数，再核对批准摘要与最终包；保留当前源/版本检查及真实模型来源要求。`run-evidence.py` 的固定计划按同规则执行，各组保持相同归一化输入。
- 提示与工具契约描述同步更新；公共工具名、参数和共享接口不变。原来的36000/12000检查从请求字符改为实际归一化字符，实际内容上限没有提高。

## 决策记录

新增场景 TypeScript `decision-log.ts`，工作台结束时自动写私有 `decision-log.json`。记录程序为何选择全量/增量、复用/拒绝缓存、补证据、综合、交付或停止；从原生事件按callId配对工具选择、成功/失败和可确定的耗时，引用原始事件序号与文件SHA。保留模型显式可见文字、窗口purpose、搜索词和实际usage；没有明确说明的理由不推断。

逐请求费用来自原始 `cost-ledger.jsonl`，工具与费用仅按所在run关联，不伪造每个工具的模型费用。日志完整性与交付科学质量分开；缺少原始日志会明确报告不完整，不改变原生记账。派生诊断标明不能直接作Motif训练数据，不补造工具事件或跳过计数。没有额外模型请求、没有用户人工审批。

免费重建已有任务诊断：

```sh
node scenarios/literature-notes/agent.ts decisions --job <已有任务UUID>
```

文件只在 `.local/`，含研究问题/选页和运行记录，不提交Git。自动工作流与工作台frame摘要包含新模块，防止配置变化后直接沿用结果。日志不能重建未记录的模型思考，也不能证明原文支持中文论断。

## 验证与回退

新增所选位置集合守恒、真正超限拒绝、重叠/重复与页尾、空白页、缓存副本隔离/源变更、跨论断权限、额度复用、原生事件callId配对、数字时间戳和失败费用保留回归。完整测试与真实开发任务、失败、追加费用和限制见 [实验记录](../experiments/plan-efficiency-20261011-4ebe9910.md)。

回退需恢复本轮场景模块、提示/契约和相关测试，旧运行产物保留。需要旧执行版本的包/认证须在对应代码下重核，不能强制升级句柄。当前结果缓存也依赖工作流frame；复核轮数等配置不一致可能触发新模型任务，不能把重复输入本身当作必然0费用。

本轮新增共享核心/SDK/预算/Motif协议接口变化：**无**。既有工作区共享改动保留，未commit/push/PR，原PDF、密钥及私有日志不入提交。
