## 目标与当前事实

当前 `auto_rsi.cycle` 在候选独立认证通过后激活，没有以净收益判断激活。此前严格成本门槛约束的是实验结论，而非在线候选准入。原始实验的失败、完整成本、预先冻结门槛和最终留出不变，不追改结果。

新的阶段目标是普通Agent持续运行时能产出新Motif、独立认证、自动激活并供后续任务使用。稳定净收益改为观测项：请求、token、实际端到端耗时、学习/认证/失败/修复费用连续记录，正负结果均保留。无需每轮学习先完成H/S/F/R全基准；周期性抽样对照可用于解释收益，但不作为执行主线的先决条件。

当前自动更新主路径 `auto_rsi.learn_candidate/cycle` 学习并发布 `script_v2`；Motif的edge/collection/plan挖掘、编译、独立见证认证位于 `workflow_learning.py` 等独立模块。TS `dsh_experience` 已能复用集合/再入/计划等兼容经验，但日常CLI/SDK/Web还未统一接上持续学习触发。现阶段不能称普通Agent已持续自主生成任意新Motif。

## 实施顺序

1. 将Motif发现、编译和认证整理为可由任务事件调用的Python服务。使用真实普通模型决定、MCP schema和参数来源学习图与集合结构；脚本保留并行通道，不能只用新增脚本别名代替新Motif。无法表达的分支、循环及恢复结构保留候选/拒绝理由，逐步扩展有证据的编译能力。
2. 将采集与调度接入普通Agent生命周期。TypeScript在线模块在任务结束/失败后提交持久化轨迹与学习机会；Python离线服务消费队列。调度依据实际重复结构、高请求成本、失配和失败，不由预定业务题号或正确候选ID触发。支持幂等入队、去重、重启续接与并发互斥。
3. 候选先冻结，再在权限内的新副本上独立认证；通过后发布不可变库版本。当前任务保持原绑定，后续任务取新库；执行失效停用相关候选并回普通Harness。学习与认证费用均纳入原系列预算，任务自身权限、预算和修复次数不因学习/重启重置。
4. 使用新的日常任务流验证两轮以上的完整链：运行触发学习、新Motif实际参与下一任务、后续新轨迹继续触发升级。无需预先满足稳定净收益；报告真实交付结果、来源证据及完整费用。以前的最终留出封存，不能用于候选学习或修改认证标准。
