# 通用 Agent 工具接入与文件管理阅读 v6

2026-10-19 用户明确：普通 Agent 基于 DeepSeek Harness 按任务调度工具；文件管理是持续学习 Motif、认证、复用和观测成本的重点场景。普通工具使用不要求先有 Motif。仅本地 `feature/rsi-research-agent`，不推送、不合入 main。

## 接口

- `src/adapters/general_tools.py`：共用注册、发现、实际 schema 检查、调用与收据层。公开默认配置 `config/general-tools.json`，私有扩展 `.local/general-tools/providers.json`（`sss-general-tools-v1`）；支持 stdio / streamable-http MCP。模型不能注册命令、凭证或扩大权限。外部工具的凭证通过 `from_env` 引用；额外计费服务需预算适配，不能伪报免费。
- `discover_tools` / `describe_tool` / `prepare_tool_call` / `execute_tool_call` / `inspect_tool_result`：模型选择服务、工具和实际参数；普通 Harness 继续执行原生 MCP 生命周期。准备与执行分离，schema/权限/任务摘要绑定。重复执行同一 ID 返回原收据；进程中断的未知效果及相同参数的新准备不自动重放。底层 MCP 会话由一个长期任务持有，跨原生工具轮次保留真实句柄。
- 同一入口接入管理场景和普通聊天。普通聊天的 `general_tools_v1` 使用普通 Harness，可使用工具而不依赖认证库；没有 Motif 时记录普通回退。当前默认服务为受控编辑/隔离代码、论文检查、已有数据报告与 PPT。服务具体执行仍受原后端输入及产物契约约束，目录可见不等于业务交付已通过。
- `management_reading.py`：`open_document`、`read_document_chunk`、`document_coverage`、`search_document` 和 `view_document_page`。PDF 可连续读取全部物理页；每次返回至多 6000 字符，真实后续句柄继续读取。缓存不计作已返回覆盖。空文本、文字层、OCR 和视觉图像输入分别标记；全文阅读不等于已理解图表。
- `open_document(mode=ocr)` 使用实际本地 Tesseract；扫描 PDF 先用 Poppler 渲染。原始身份、每页范围、文本摘要、解析器/语言指纹和中断后的进度保留；独立验收从原始字节重算页数、每块与连续性。`read_file` 的 PDF 结果明确是首页预览、始终标记 partial，旧实验 `FileScene` 的前两页契约不被追改。
- 视觉复用当前 Harness 附件链路和 `deepseek-flash`，无需另建视觉 Agent。管理上传同时保留原始文件回执与原生图像部分；`view_document_page` 返回任意 PDF 页或获准图片的真实 MCP ImageContent。解析字节、渲染像素摘要、页码和原始来源均保留，像素送入模型不被当作自动语义判断。
- 受控文本编辑按精确匹配次数产生新输出版本；代码执行复用项目原有 Docker + 上游 worker，TypeScript/JavaScript、无网络、只读宿主依赖、256MiB、计算 10 秒/墙钟 60 秒。仅经获准输入回调读取文件，产物通过有界的新文件回调写入；不因启用代码而获得主机路径或原件覆盖权限。代码本身、真实错误、输出及原始输入摘要由 MCP 收据保留。
- 管理产物导出增加 `general/` 工具输出，和原文件的整理结果分别记录；这些产物标注尚未独立认证其业务质量。文件管理的冻结验收升级 `sss-management-quality-v6`；新文档和视觉轨迹接入原独立重放、真实 MCP 结果核验与同一长期库。通用工具目前标记语义边界，不把任意代码或外部业务判断当作已认证的自动续接。
- 离线发现保留分别有两次独立真实见证的短图，不再因存在更长候选而提前丢弃；优先尝试长图，失败仍保留，短图需独立认证。不凭长图人工截取没有真实证据的前缀，认证标准不变。
- `harless_status_cache.ts` 仅合并同配置的状态读取并短时缓存；GET 设置不占用任务变更串行锁，POST、执行与权限准入继续保持原串行顺序。界面状态不作为执行授权。免费 Files API 传输单列，真实模型的未知用量仍保留原预留上界；已封存错误判定仅追加对账回执，不覆盖原记录。

## 兼容、权限和费用

工作区任务副本内原有低风险整理权限不变；覆盖、不可恢复删除及外部目录仍逐计划确认。工具的通用接入不授予任意外部写权限。显式只读任务不能经通用入口生成产物。旧库、旧证书、失败和最终留出保留；新的源码、catalog 和质量版本需要重新认证，不能修改旧证书使其适配。

共享学习、迁移和旧适配器写出的新证明改用 v6 标识。同一 `daily-management-real-v3` 原账本、任务/系列预算和未知预留均继续使用。MCP 自身没有模型调用的本地操作记作本地计算；代码耗时与后台学习费用不冒充零总成本或稳定净收益。

公开 PPT 的原训练证书保持不变；共享任务输入文件增加独立 `general-task.json` 权限记录和管理专用图像旁路修复。只更新当前兼容锁及其入口摘要，旧兼容文件在私有实验目录封存，不重新声称训练或质量收益。
