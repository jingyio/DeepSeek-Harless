# 文献目录的日期类型与作者覆盖：实施前接口记录

2026-10-12，用户授权继续修补上一轮作者遗漏和日期支持错误，再验证对 Motif 效率的影响。

本轮共享 Harness/Motif/预算接口变化：**无**。只改变文献目录场景 MCP 数据契约和相关测试，保留所有旧实验。源码/提示及 packet 变化使旧目录复用和旧认证库按执行版本失效；新版本必须采集新的普通原生轨迹并独立认证。

`read_catalog_packet` 新增有来源位置/摘要绑定的 `date_candidates` 和 `author_regions`。日期用显式出版标签、arXiv 页脚日期及接收/接受/版权标签做有界结构解析；无法识别的日期不推断。候选的类型不是学术身份认证。

`submit_catalog` 的 year 改为 `{candidate_id: string|null}`，不能再用自由数字/原文锚点指定年份。选中的候选必须属于当前已读 packet，并且属于 publication/preprint；accepted/received/copyright 候选不能写入引用年份。未指定时，同一明确年份自动投影，多年份冲突保留缺口。该投影是普通程序，两组共用，不计 Motif 收益。

新增必填 `author_coverage={status,region_ids,reason}`，status 为 covered/partial/unavailable。作者仍由模型解释、逐人抄录并通过原文校验；covered 必须覆盖所有工具候选区域中的姓名词元，未覆盖时反馈具体缺失词元。partial 必须给出原因，作为真实缺口交付；有候选区域时不能声称 unavailable。候选探测仅覆盖部分署名格式，不把词元覆盖认证成完整作者表，不为凑齐候选强行添加作者。

记录实际提交和 Runtime 日期投影来源，已保留记录按新 source packet 重新核验。首次目录/增量/不变路径与 CLI 不变；正式 Web 不在本轮范围，依然无人工批准才能交付的流程。新 API 比较保留所有失败/缺口/费用，先验证已知反例被拒绝再跑训练与对照。
