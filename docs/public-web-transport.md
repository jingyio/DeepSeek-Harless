# 公网连接心跳配置

公网入口在原 `host.patch.yml` 后叠加 `config/public-web-transport.patch.json`；多账号网关需把同一条目合入 owner patch 与 `memberPatch`，按插件 id 替换，不能重复注册服务。

固定版本 DSH 0.1.5-rc.3 的公开配置 `websocketHeartbeatIntervalMs` 默认 2000 ms；原生连接连续两次未收到 Pong 后终止。2026-10-17 公网验收中，两次约 1 MB 合成 PDF 上传均出现重连，但 HTTP 上传最终完成；小附件与模型回复正常。上传与实时连接分开传输，不能把重连直接认作文件解析失败。

公网配置改为 30000 ms，保留原生 Ping/Pong、断线重连、鉴权和取消，不更改消息或模型请求。此调整用于容忍公网短时拥塞；浏览器主动关闭、网络明确断开仍可立即被传输层处理。实际静默失联检测会更慢，约 60–90 秒，不代表保证网络永不断线。

发布前保留配置字节备份、确认无活动任务，重启 owner/member 服务后验证同大小上传、来源标识及连续追加附件。验收结果记录在主线交接与私有发布回执中。
