# GeneLoop 连续场景、分支与工作区验收

- 日期：2026-10-15；基于 main `e90e358`，开发分支 `codex/conversation-workflow`。
- 目标：在同一可见对话中先分析数据再做 PPT；恢复工作区管理；展示真实增量文字和工具状态；从选定回复分支并按 `（1）（2）` 命名。
- 数据与方法：专用隔离账号、合成资料、真实 DeepSeek Flash，`reasoning_effort=off`、每次输出上限 1000 tokens；复用三个现有库，不重训。确定性回归与真实模型验收分开记录。
- 预算变更：用户在本轮明确取消请求次数限制。最终配置以 JSON `null` / CLI `0` 表示不限任务及累计请求次数；累计 1 美元费用上限、每任务费用上限、历史用量和未知用量预约额仍保留。正整数次数限制仍可显式配置。

## 实现范围

- 可见父会话保持不变；场景、来源或工具范围变化创建私有执行子会话。Baseline 与 Motif 各自承接近期上下文及通过归属、大小、哈希校验的可用资料，复制至新任务范围。
- `/chat` 使用单栏回复；场景使用双栏。SSE 推送真实文字增量和工具生命周期，带单调快照版本。断线只重读状态，不自动重发付费任务；网关释放断开的上游订阅。
- 分支保留所选完成轮次之前的历史，独立预算、文件和后续任务，不复用原评分引用。编号持久化；再次从继承历史较早位置分支时也按截止事件过滤。
- 工作区恢复文件夹、展开按钮、概览、置顶、设置改名、删除入口；删除分组保留聊天和文件并归入未分组。

## 验证与限制

验证结果与发布信息在完成服务器验收后补充。原始日志、有效配置、账号与成品只保存在受保护的 `.local/`。

本记录验证产品流程，不代表科研结论正确、Motif 普遍降本、供应商长期稳定或大规模并发容量。论文场景仍为既有 Shadow 模式。
