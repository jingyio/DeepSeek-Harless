# PPT 统计来源补检与回归

## 触发与修复

PR #41 的 `d2871f5` 已上线；PNG/JPG 三场景及图片表格逐格复核通过。随后在公网五格式混合 `/ppt` 复测中，Motif 虽交付可下载且排版正常的文件，却添加了附件没有给出的均值、相关系数、对数回归斜率和置信区间。此次是内容负例，不能因文件检查通过而称质量合格。原文件、轨迹、费用保留在私有 `scene-public-image-regression-web-20261016`；此前机械检查未包含这些数字的依据，人工逐页复核发现问题后补记，未删除或覆盖失败。

`numeric_evidence.py` 在渲染前检查常见统计量的指标与数值是否在本页已读取、已授权、当前版本的引用页中出现；支持忠实减少小数位，区分 p 值比较符和置信水平。正文、表格、证据说明和备注都纳入检查。原始表格中恰巧有相同数字不算对应指标的结果。拒绝时返回 `unsupported_statistics`，模型在原任务、原权限与剩余预算内移除无依据统计量并继续交付。

PPT 没有统计复算工具。提示词明确：只有原始资料时完成设计、数据说明和局限汇报，标注统计尚未计算；引用已提供分析报告时保留方法、单位和条件，不能自行改为对数回归。完整新分析应先通过 `/data` 生成可引用报告。来源读取工具及原 Motif 证书/库不变，只复核当前实现绑定。

该检查是常见统计表达的来源摘录守卫，不是通用语义支持、因果、方法适用性或科学正确性认证。图片只有视觉证据时保留 `visual_review_required`，不拿空文本证明图片没有数值，也不冒充 OCR。未匹配的统计写法、上下文条件及研究判断仍须人工审阅。

首次补检复测又发现 Motif 沿用测试稿故意写错的 39 例。增加有条件的完整案例计数：仅当唯一 CSV/TSV、唯一 JSON 明确给出分析变量和完整案例规则，且所选列为空白或有限数字时逐行计数；多表、元数据歧义、非数字缺失标记等情况不猜口径。备注等无关列的空白不影响有效样本。与已知计数冲突的声明在渲染前拒绝，显式标为原文错误的引用可保留以说明问题。最终两侧均使用 38 例并指出原稿 39 有误。
