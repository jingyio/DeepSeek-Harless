# GeneLoop 用户工作区与无附件场景问答

## 范围与配置

基于 main `8325cb5`，分支 `codex/user-scene-workspace-flow`。修复内部 preset 展示、目录 hover、UUID 空会话标题、工作区选择归属、场景选择视觉延迟及无附件消息被拒绝。复用既有三场景库，不重新训练，不修改上游 Harness。

真实验收在服务器独立测试网关和两个已有诊断账号运行。模型为 `deepseek-flash`，`reasoning_effort=off`，输出上限 1000；累计预算保持 1000 次 / $1。开始为 447 次、$0.291552966 保守预约估值，官方余额查询为 CNY 56.96、可调用；代理估值不等于账单。私有任务配置、原始模型输出、凭证与诊断脚本留在 `.local/paired-stage`，不提交。

## 开发诊断与界面

- 服务器根 `npm test`：Python 861 通过；最终 Node 506 通过、3 Docker 条件跳过。`npm run smoke`：18 题、83 来源，无付费请求。
- 首次 root Python 因测试 Poppler 包装器未进入 PATH 跳过 193 项，补齐测试 PATH 后完整复跑；直接运行 Node 时遗漏 `SSS_PURE_CODE_PYTHON` 导致纯代码节点单项失败，按统一入口的有效环境补齐后全通过。未删除测试或放宽断言。
- 两账号同名工作区、幂等创建、他人 workspace ID / path 拒绝、主机目录浏览拒绝均通过。工作区 API 投影不含部署路径，底层真实目录不改写。
- 浏览器通过命名创建、点击工作区后顶端新会话创建第二条聊天、无 UUID 的空会话名称、`/d` 候选及点击后即时蓝色 `/data`。移除 hero/header 的内部 preset 组件。补测后台延迟时继续输入，保留正文与附件，绝不自动发送。
- 确定性检查覆盖五个资料适配器无附件三轮与重启、通用工作区保留工具、首次上传讨论上下文隔离、历史子会话保护与旧评分保留。它们不是模型质量验收。

## 真实模型进展与负例

两账号、三场景各两轮的验收使用不同合成研究主题，检查第二轮记忆、零文件工具调用和跨账号 404。无附件的两侧均为普通模型问答，不宣称 Motif 优化。

已观察到 HTTP 503（服务商繁忙）及长时间无响应；取消后显式只重试失败侧，保留成功输出和全部累计支出，不重置预算。取消完成到执行器退出有一个短暂窗口，验收脚本对 `comparison_busy` 做有界等待，避免重复创建任务。完整矩阵及首次上传真实 MCP 的最终结果在发布前补记；此处不把部分成功写为全部通过。

## 发布与边界

计划沿用现有公网地址及端口，保留账号、Home、输出、历史与预算。旧独立论文修订悬浮入口从部署插件配置移除，`/paper` 的结构修订工具保留。正式部署状态以本记录后续补记和 PR 为准。

外部模型繁忙与临时 Cloudflare 隧道稳定性不由这些修改保证。本轮是功能及权限验收，不是大规模容量压测、科研正确性评审或 Motif 净降本实验。
