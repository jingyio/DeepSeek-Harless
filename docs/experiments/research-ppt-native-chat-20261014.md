# Harness 主聊天科研 PPT 真实验收（2026-10-14）

## 问题与假设

验证科研 PPT 是否可以直接挂到官方 Harness 主聊天：用户在主聊天选择 PPT、上传论文、确认预算后，后台完成普通 DSH 与优化 Agent 两路生成，聊天返回优化成品；后续消息可以继续询问或指定页面修改。假设是主聊天接缝不会绕过既有来源、版本、权限和交付守卫，并且优化路径在相同输入下保持交付质量的同时减少请求和 token。

## 任务、对照与配置

- 类型：真实前瞻任务，输入为论文 *Attention Is All You Need*，用户未指定页数。
- 入口：Harness 官方浏览器主聊天；`/ppt` 仅作为备用入口。
- 组别：普通 DSH（baseline）与宿主控制的优化 Agent。普通组未加载优化组合工具；优化组沿用已认证的固定交付路径。本轮没有生成或学习新工具。
- 统一配置：DeepSeek Flash，`reasoning_effort=off`，压缩关闭；默认 15 页；每组最多 60 步、8000 输出 token，双路总预算上限 `$3`。源码和契约版本以本次提交前工作区为准，私有 API key、论文、原始账本和逐决策日志仅在 `.local/` 与服务器保存。
- 复现入口：`npm run web:real -- --scenario ppt --ppt-run-budget-usd 3`；按 `scenarios/research_ppt/frontend-integration.md` 选择“PPT”、上传、确认，再从同一聊天发送页码反馈。

## 运行结果

两路均完成 15 页可编辑 PPTX、PDF 和逐页 PNG 交付。主聊天上传回执、预算预览、确认、进度事件、结果卡片和下载链路全部走真实 HTTP；共下载 34 个文件并核验鉴权与 SHA。浏览器刷新后同一 Session 仍能看到任务。随后从同一聊天提交“第 4 页”反馈，生成新版本并通过非目标页保持、来源/版本和渲染交付检查。

| 指标 | 普通 DSH | 优化 Agent | 相对变化 |
|---|---:|---:|---:|
| 模型请求数 | 19 | 16 | -15.8% |
| 总 token（输入/缓存/输出账本合计） | 707,922 | 410,206 | -42.1% |
| 代理估费 | $0.03116531 | $0.01853018 | -40.5% |
| 任务完成 | 通过 | 通过 | 相同 |
| verified skip | 0 | 0 | 无新增 RSI 旁路证据 |

两路合计代理估费为 `$0.04969549`。以上是代理账本估算，不等同于供应商最终账单；人工修订分钟和科学/审美盲评本轮未收集，不能据此宣称端到端质量优势。普通与优化成品均保留在服务器私有实验目录，公开仓库只保留本匿名记录。

## 实现与验证证据

- `scenarios/research_ppt/ts/native-chat.ts`：把官方 Session、上传回执、预算确认、后台状态、下载和反馈映射到主聊天卡片。
- `src/adapters/dsh_web_tasks.ts`：只在显式选择 PPT 且满足 `local-operator` 单用户准入时接管；其他场景维持原生 Harness。
- `scenarios/research_ppt/ts/feedback-runner.ts` 与 `feedback-mcp.ts`：按父稿版本、页码范围和稿件 SHA 执行反馈，并重新渲染验收。
- `scenarios/research_ppt/tests/native-chat.test.mjs`、`feedback.test.mjs`、`web-session.test.mjs`：覆盖预览不付费、重复确认幂等、外来回执拒绝、版本冲突、同稿反馈和失败/取消恢复。
- 免费检查：`npm run smoke` 通过；PPT TypeScript 构建通过；主聊天相关定向测试 53/53 通过。仓库全量 `npm test` 163 项通过，2 项环境相关失败（Windows 符号链接权限、本地 runtime 初始化超时）。

## 结论与边界

本次真实运行证明主聊天交互组件和 `/ppt` 备用链路可以复用同一 PPT 后台，上传、确认、生成、下载和同稿反馈均可追溯；在这一个任务和固定宿主策略下，优化 Agent 的请求数、token 和代理估费低于普通 DSH，且两路机械交付均通过。`verifiedskip=0`，因此节省不能归因于本轮新 RSI 发现；它主要来自宿主控制的执行路径和上下文策略。尚未证明任意 PDF 都能成功生成、科学内容正确、审美相同或每个任务都降本。多账号、完整重启后主聊天自动续接、图片插入和无计划外部 PPTX 保真改页仍需后续工程工作。
