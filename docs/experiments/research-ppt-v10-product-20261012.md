## 2 / 让模型在结果出现之后做决定

本轮未生成或启用新 RSI 候选。先让普通排版与明确字段编辑发挥作用，只有默认规则仍留下真实重复失败，才启动模型提炼。DoRA 曾出现第 5 页 `comparison.right` 文本溢出；模型读错误后修改计划并完成，但一次失败不足以证明可泛化修复结构。

只读诊断发现七参数全局策略 right/.64/20pt/.08gap 会把尚未修复的 LoftQ 原图面积从 3.3326 提高到 19.2573 平方英寸，同时使 PiSSA 从 33.0364 降到 28.8834（−12.6%）。这是同版本静态几何诊断，不是真实渲染认证或学得策略。跨案例平均面积可能掩盖单稿退化，因此本轮采用逐页普通规则，不晋级该全局策略。

后续 RSI 的最小触发条件是：新默认规则仍有重复失败；模型从真实轨迹提出带适用条件的有界修复；独立新稿逐页无回归且真实渲染通过；再由另一个新任务调用，证明少修复请求或同预算交付改善。生成成功、合法参数、工具可调用均不单独算收益。

用户补充的更强递归闭环作为可选方法论：新结构还应改变下一轮的结构发现、候选生成、验证或选择，并有实际继承使用的记录；仅将已认证工具加入执行库不证明这一层递归。若以后推进，应另外比较发现/认证成本、候选有效率及认证质量，仍以 PPT 质量与后续总成本为取舍依据。本轮没有实现或验证该层，不追加无目的的候选生成。

## 3 / 与普通 DSH 的流程对比

两组从同一 job、同一 starting deck SHA、同一更新 JSON 开始，共享后端工具/渲染器/质量检查。正常 Harness 保留原工具集合与提示，自行选择所需读取和修订；直接入口以明确 page/changes 省去模型决策。PiSSA 的正常路径额外选择来源页读取和检查，不能将这些次数解释为通用模型必然开销。

直接入口复用 `DeliveryAdapter.reviseDelivery` 与真实 MCP：读计划预览 → 核验版本及输出授权 → 修订/渲染 → 再读原稿和新稿核验 → SHA 复制交付。没有另写 Agent 循环，也没有模拟工具。仅适用于当前版本、同 job、有完整生成计划的稿，不处理任意外部 PPT 或自然语言反馈。它属于 B1 工程对照，而非 B3 RSI。

## 8 / 学习成本、复现与适用范围

RSI 测评同时计算两层：**冻结工具在新任务上的边际收益**，以及**加入学习投入后的累计净收益**。一次性成本包括轨迹采集、提炼/生成、认证、失败候选和发现过程的恢复；使用成本包括正常执行、重试、回退、版本失效重认证、耗时和人工修订。

令 `L` 为学习与认证投入，同质量任务 baseline 成本为 `B_i`，启用工具后的完整成本为 `R_i`，累计节省为 `Σ(B_i−R_i)−L`。只有为正才支持净收益；平均单任务省 `s>0` 时，粗略回本任务量为 `ceil(L/s)`，还须报告跨任务波动和维护开销。生成当轮更贵不自动否定长期价值，新任务 token 下降也不自动证明总体划算。任务质量未审或组间不等价时不计算这个结论。

当前直接编辑工具为人工工程实现，没有模型生成/认证成本，但开发维护和明确字段输入的人工成本仍未知，不能把它混入 RSI 回本结论。布局学习新任务应使用 `--layout-baseline-mode renderer-default`，与当前自动排版比较；旧 `fixed-policy` 保留用于历史复现，不能拿较弱旧默认作为新产品收益基线。
