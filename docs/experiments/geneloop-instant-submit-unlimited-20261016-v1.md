# 即时发送与不限费用修复

用户于 2026-10-16 明确要求点击发送立即反馈，并取消所有平台费用/次数额度，修复 Pro 与推理 On。此前线上累计费用、请求次数和输出 token 已不限，但每任务仍为 0.23 美元，对照每侧仅 0.115 美元。Pro On 原生默认输出预约至少 0.259523 美元，会在模型请求前被阻止；Pro Off 输入较大时也可能触发单侧预算。

## 实现

- 场景指令回车不再先等待 settings GET/POST；原生 `beginSubmission` 立即建立用户消息与发送状态，服务端在同一提交中解析场景前缀。保留真实附件回执和服务端所有权校验。
- 模型选择队列仍按顺序保存，发送等待其实际选择；选择失败时撤销原生待发送消息并恢复草稿，不能悄悄换模型发送。
- Web 默认任务、累计费用均为 `null`。账号网关、请求归一化、任务预算注册和双侧分配一致接受 `null`，避免 `null / 2` 变成零预算。数值 `0` 仍禁止付费；CLI `0` 表示不限。
- 有限管理员上限、请求身份、权限、取消、账本累计和已存在任务账本不可重置的检查保留。工作台正确显示“不限”。
- PPT `ppt-web-v2-r5` 用同一冻结的两训练决定/一留出决定重新运行现有编译器，认证当前入口代码与完整工具 schema。未新增模型训练样本；原始日志继续私有，r4 保留。报告中的 `new_training` 描述 v2 数据集相对旧 v1 的来源，`new_collection_tasks_for_recompilation: 0` 描述本次重编译，不能作为新的质量或成本收益证据。

## 验证

服务器完整 `npm test`：Python 797 通过、193 跳过；Node 746 通过、3 跳过。`npm run smoke` 通过，无付费调用。新增覆盖不限任务与有限上限拒绝、零预算语义、双侧并发注册、账号隔离、失败模型选择恢复草稿、场景发送不等待设置请求。

真实网页在隔离账号执行 Flash/Pro 与 Off/On，使用真实 DeepSeek，不额外设置费用/次数/输出上限。人为暂扣真实 `/api/session/prompt` 请求时，已确认用户消息先出现、输入框先清空；后台接收前不显示虚假的模型完成状态。完整网页结果和费用由后续验收补充，未完成项目不计为通过。

## 部署约束

上线先确认无活动/待确认任务，再停止入口和旧预算服务；原位置原 checkpoint、累计请求数、费用与账本文件必须逐项一致，不能以新建账本、清零或恢复旧快照实现不限。更新 owner/member 的五个额度字段、模型目录和新控制端点。历史会话、附件、结果、评分保持；失败回滚也不得回滚已产生的费用记录。
