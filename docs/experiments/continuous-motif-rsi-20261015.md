# 普通运行持续学习 Motif：2026-10-15

已接通显式启用的普通 CLI 任务结束 → 封存 → 自动发现 → Python 编译 → 新材料独立认证 → 发布库 → 后续任务复用。真实任务流曾完成两代升级和六份交付。当前增加的并发队列追赶、证据修订与防重复认证通过免费检查；最终云端复验遇到 DeepSeek 503，未完整重现两代升级，已停止进一步付费诊断。稳定净收益按用户要求仅观测。

## 问题、范围与任务

验证学习是否由普通任务生命周期触发，而非实验题号直接调用学习器，是否能从使用第一版后的新模型决定学习第二版。首版只接入 `report_tools.py` 的只读文件报告；支持集合 pin/read/gather 和认证的第二次模型选择，最多 32 成员、每批 8 个、两段。其它图结构记为未支持，不能称为任意 MCP/控制流学习或生产前端已接通。

新普通任务流包括三/五类来源完整读取、第一版复用、两种两阶段读取、按实际说明过滤第二阶段。PDF 来自三篇原论文副本，Word/Excel/图片为此前合成资产副本，文本新建。所有内容操作限于新 `testpdf/file-management-experiment/<id>/`；原论文不改。前瞻调用真实模型，但任务和材料是定向开发诊断，非真实办公盲评或公平成本基准。没有设置人工时薪。

六个任务均是普通运行材料，不是最终留出。至少两份不同来源的真实普通模型决定才编译；每个候选冻结后，用一份新原生图见证和两份新实际候选执行认证。认证材料不训练，历史最终留出不训练、不改验收、不读取其内容用于发现。语义选择和摘要仍由模型生成，框架不传 `profile_id` 或正确模板 ID。
