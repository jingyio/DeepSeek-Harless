# Script Motif 自动学习与后续真实复用

本轮已跑通两个自动版本交接：A2 自动发布，B 加载该精确版本并执行；代码冻结后，C 自动发布，D 加载该精确版本并执行。B、C、D 各有一次回执校验通过的模型请求边界接管，C 另复用了五个从 B 原生轨迹挖出的脚本。**支持受限 RSI 链路已运行，不支持完整论文核验已合格或稳定净降本。**

## 修改与验收范围

上一轮四项检索缓存实验没有启用学习链。本轮关闭检索实验，不重跑完整 Baseline；所有任务使用相同自然语言题面，检查 BibTeX 数量、重复键/著录和明显格式问题，只读、不联网、不导出。不手填算子 ID、预置语义选择或修改原件。

- 统一 worker 发布目录与 sidecar 加载目录；冲突在付费启动前拒绝。保存有效配置副本、owner/路径/摘要/代码锁检查、逐任务加载收据，任务中不换库。没有新库就正常冷启动。
- 发布保留父摘要、触发任务、固定留出与训练事件摘要。无合格产物不覆盖父指针；子进程启动/异常退出写失败状态，学习等待超时记未结算。
- 真实 A 暴露“保存脚本在执行前尚不存在”和函数/循环切片缺口。编译器现识别本命令创建的程序，已有文件仍检查一致性；支持顶层无装饰器/默认参数的函数及循环后值切片。原副作用、绑定、跨输入重放和输出上限不放宽。
- Frontier 原来只提供多节点片段。现也可选择独立认证单算子，不虚构后继；多节点仍要求历史关系和相同输入契约。本轮实际接管均为单节点，未验证新增连续多步收益。

通用 Bash 组合、跨脚本中间文件自动生产、一般 Negative Motif 自动原因学习未在本轮完成。结构认证不等于算法或最终科研判断正确。

## 真实执行与版本链

私有根 `.local/paper-rsi-live-loop-20261020-v1/`，逐运行配置在 `.local/script-motif-experiments/<run>/`，原事件/账本在对应 Web 任务。`aggregate.json`、`acceptance.json` 保存关联和精确摘要。

1. 初始化独立 store，只登记一项历史真实任务作固定留出，不复制旧库。该旧任务支出已在历史累计中。
2. A：GELU 原始源码包完整 BibTeX，26条，输入 `1142caced119…`。自动学习确实触发，但零算子通过。主要拒绝为留出输入没有当前中间 JSON、任务特定文本、无效或过大输出。失败保留。
3. A2：同输入修复复测，execute 冷启动，无可加载库；结束后自动发布3算子，均来源于 A2 原生代码。学习1.94秒、模型请求0。A/A2不算两篇独立论文。
4. B：RMSNorm 源包完整 BibTeX，39条，`35505e73e1a7…`，本轮此前未进入训练/认证。精确加载 A2 的 `8fc7c378…`，自然选择统计算子，Runtime 绑定 B 字节并校验执行。结束后自动发布12算子、1原生契约。
5. 全量回归发现新提取分支绕过了已有保存文件不一致拒绝，修复后定向33检查通过。开发中做两次显式免费兼容重认证，原 B 自动状态另存 `B-original-auto-learning-status.json`，旧轮不改、不只重算哈希。**B→C包含人工触发的代码兼容重认证，不算全无人干预。**
6. C：历史另一真实书目前100条子集，`4005000c6d65…`，本轮此前未作训练/认证；不是新完整论文。加载 B 兼容库 `88ae77e5…`，Runtime执行1次、B来源缓存算子5次均通过。结束后自动发布 `da38bf96…`。
7. D：回到26条输入作后继版本传递诊断，不算独立新论文。无再编译或手动切库，精确加载 C 的 `da38bf96…`，复用从 B 学到的解析/缺项程序；当前数据仍是26条。结束后再次自动发布。C→D是最终冻结代码上的自动交接。

加载、当前输入 SHA、一次性授权、执行回执和成功审计均对应。合成 `sss-script-` / `sss-reuse-` 调用继续排除出独立学习见证。库从3到12，之后达到既有容量上限；更新摘要不等于覆盖一定增长。新函数切片确实在 B 发布，但未用于声称额外接管收益。

## 配置与复现

分支 `codex/paper-rsi-loop-20261020`，基点 `d52db4f`（继承隔离检索代码，本轮关闭）；最新 main 核对为 `f3c175e`。生产、公共认证库、全局配置、私人原件、上游 Harness 未改。各 run 保存源码/题面/输入/工具顺序/effective config 摘要。

macOS 隔离实验；真实 DeepSeek Flash、reasoning off、输出8192、费用/请求不限、压缩关闭、reset_history:false。实际 Node/Python/SDK 版本在 `environment.json`；这是显式有限输出诊断配置，不改正式 Web 容量。当前模型填选择，本轮不调用 embedding。所有选择/恢复费均累计。

项目 Python 配置后，macOS 另设 `SSS_LOCAL_SCRIPT_EXPERIMENT=1`，入口如下：

```sh
node scripts/project.mjs python scripts/run-script-motif-experiment.py \
  --real-model --source .local/<当前输入>.bib \
  --prompt .local/<实验>/task.prompt.md --mode execute \
  --script-config .local/<实验>/execute-config.json \
  --learning-store .local/<实验>/store --user-id <同一账号> \
  --budget-usd 0 --max-output-tokens 8192 \
  --evaluation-scope local_bibliography_validation --no-output
```

sidecar 配置 `mode:"execute",catalog:true,executionFrontier:true` 和现有本地 embedding endpoint/model 字段（此路径不请求该服务）。下一任务沿用 store、换实际输入；空 store 第一任务只收集，认证需不同字节输入。

## 验证与结论

首次全量Python1325通过/1失败/213跳过，失败是已有保存文件变更检查。修复后完整 `npm test`：Python1326通过/213跳过、Node1194通过/5跳过；后补 worker 发布/失败保留父指针检查等另跑6通过。`npm run smoke`、`npm run motif:check`通过。确定性检查仅作开发诊断，模型证据来自上述五项真实任务。

已排除本轮“自动学习没开”“新版没加载”“始终零接管”。剩余主要缺口：中间文件生产链、过期选择恢复、重复后续检查、目录容量/费用权衡及最终文字质量。下一步应按这些轨迹减少控制与恢复开销，再扩大可认证片段；不以改 embedding 代替控制链改进。当前可进入受控局部业务测试，不能据此宣称完整论文场景稳定降本或生产上线。本地提交未推送，暂不 PR。
