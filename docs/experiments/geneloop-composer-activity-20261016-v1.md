# GeneLoop 输入菜单与工作状态验收

## 问题与范围

用户要求默认 Chat 不占底部标签，移除 Files/Chat 候选，场景随草稿立即改变；加号支持照片/文件及功能图标；Chat、Baseline、Motif 统一真实工作提示和 GeneLooping；工作区操作菜单移到最右。实现基于 `3f9df2f`，没有改变模型调度、权限、额度或文件传输协议。

## 实现与诊断

`HarlessStatus` 直接订阅原生输入状态，原生 chip 过渡阶段和延迟后台设置不能覆盖当前草稿。菜单仅装饰公开展示数据，仍由原生控制器管理键盘/焦点，上传沿用 `addFiles`。工作区删除新建按钮后同时删除旧网格空列。工作状态只来源于模型/工具生命周期；文档 subject 只保留允许的文件名，拒绝绝对路径和原始参数。运行中的评分/统计/交付占位隐藏，完成后恢复。

定向 Node 149 项通过；Linux 完整 Python 797 通过/193 跳过、Node 751 通过/3 跳过，无模型 smoke 通过。最终生成中 footer 与工作区网格补丁分别复跑 55/30 项通过；最终提交的完整 CI 以 PR #52 为准。

## 真实网页与模型

候选前端通过只替换已核对的当前正式 bundle/内联工作区源码，与正式后端通信，账号为隔离测试账号。明暗主题的三种场景手写/菜单选择、默认隐藏、照片与 PDF 原生上传、操作菜单通过，未出现 JS 异常。最终工作区菜单距行右边 6px，网格为 `220px 28px`；1440px 和 1024px 桌面截图检查通过。

真实 Flash + reasoning `high`（界面 On）运行普通 Chat 与 `/data` 两侧，共三项任务均完成。合成 TXT 含唯一标记，模型回复正确引用；观察到正在思考、正在回复、调用 `inspect_study` 等真实状态，GeneLooping 可见，旧文案未出现。Chat 3 请求、Baseline 2 请求、Motif 2 请求，合计 7 请求；代理估费 0.003906432 美元，实付未知，三项均无额度拒绝。每任务、单侧、累计费用/请求次数/输出上限继续 null；原累计账本不重置。

## 失败、边界与发布

最初浏览器诊断只替换脚本请求，漏掉 HTML 内联工作区脚本；修正后通过。原生 chip 清空使用真实键盘操作，候选菜单等待实际选项就绪后检查；失败日志保留。390px 动态缩窄后的原侧栏未按测试预期收起，没有将完整手机布局列为通过；本轮桌面控件验收不等于整站移动端验收。

这是界面和真实事件接入验收，不是报告/PPT 科研质量或 Motif 成本收益实验。本轮没有为追求进度文案伪造执行事件，也不展示私有推理内容。原始截图、任务记录和输入位于私有 `.local/composer-polish-*`。部署预检确认配置差异为空、预算进程保留；最终合并/上线 SHA、公网复验和回退回执在 [PR #52](https://github.com/jingyio/DeepSeek-Harless/pull/52) 更新，回退不得恢复旧用户数据或账本。
