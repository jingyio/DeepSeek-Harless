# 三场景 Motif 成本学习（2026-10-21）

状态：已完成本轮训练、认证和真实成本复测。最新三个匹配样例均降低总Token与代理估费；旧退化保留，不能宣称稳定泛化收益。未替换正式库，原服务和账本保持。

## 问题与可证伪假设

历史完整任务中 PPT / Paper 实际复用为零；Data 跳过 10 次决策后仍有 59 次真实请求，高于 Baseline 的 27 次。短读取边与当前原生 Bash 工作流失配，重复计算和恢复成本可能抵消收益。不能把历史 5.4% / 4.2% 的随机费用差归因为没有发生的复用。

本轮先审计真实调用及失败，再从正常成功轨迹提取可换输入的计算/渲染程序。复用范围由程序输入、输出、当前模型选择及版本守卫限定，科研内容和最终判断仍由模型完成。若新材料上重复工作、恢复或质量问题抵消费用收益，则拒绝晋级；不以跳过数、代码长度或 token 差替代合格成本。

## 已完成的实现

- `artifact_motif_compiler.py` 与 `learn-artifact-motifs.py` 从真实原生 Python 调用及其前后快照学习源码、输入形状／来源和位置参数流；不是手写业务 DAG，也没有微调大模型权重。
- `certify-artifact-motifs.mjs` 在不同输入上各运行两次，并与历史产物核对。三类候选分别覆盖配对证据复算、计算加多图输出、固定三页 SVG 排版。模型继续负责内容、适用性与最终判断。
- TypeScript runtime 支持原生 Python 路径、相对路径和完整字节相同的交付副本；在新隔离目录重算当前输入、禁网、只读原件，核对版本后发布产物与原样程序。修改过的程序只能走普通工具，不记认证复用。
- 独立 Web wrapper 保持原工具表、File SDK 和正常服务入口，记录目录在首请求是否可见及 selected/verified 回执。旧 `verified_skips` 不被伪造为程序复用次数。
- 修复了非 SVG 可选字段在 JSON 持久化后摘要不同、目录晚激活、相对路径和副本无法接入等实际联调问题。所有旧失败保留。
