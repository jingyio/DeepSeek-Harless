# 三场景 Motif 成本学习（2026-10-21）

状态：实验入口与三个候选程序已实现，完整真实对照观察到收益和退化；正在收口成本专项复测。未替换正式库，原服务和账本保持。

## 问题与可证伪假设

历史完整任务中 PPT / Paper 实际复用为零；Data 跳过 10 次决策后仍有 59 次真实请求，高于 Baseline 的 27 次。短读取边与当前原生 Bash 工作流失配，重复计算和恢复成本可能抵消收益。不能把历史 5.4% / 4.2% 的随机费用差归因为没有发生的复用。

本轮先审计真实调用及失败，再从正常成功轨迹提取可换输入的计算/渲染程序。复用范围由程序输入、输出、当前模型选择及版本守卫限定，科研内容和最终判断仍由模型完成。若新材料上重复工作、恢复或质量问题抵消费用收益，则拒绝晋级；不以跳过数、代码长度或 token 差替代合格成本。

## 任务、划分与配置

- 历史诊断：上一轮已封存的 PPT 与 Paper/Data 完整任务；这些已经看过的题目不能充当新候选独立测试。
- 训练、独立认证与后续评测分开冻结，所有输入/轨迹/候选放私有 `.local/`，公开记录仅匿名摘要。
- 执行在 Linux 隔离实验入口，原生 DSH 0.1.5-rc.3、DeepSeek Flash、off；实际 wire 输出 393216、应用费用/请求/步骤/输出额度 null。沿用原累计账本，不清账本。任何未采集配置标为未知。
- Baseline / Motif 使用同题、来源、工具顺序、模型和质量标准；共同工程改进不归因于 Motif。
- PPT 全部由 GeneLoop 制作；测试者只提供材料/要求和只读检查，不写/改生成代码、页面或成品。

## 已完成的实现

- `artifact_motif_compiler.py` 与 `learn-artifact-motifs.py` 从真实原生 Python 调用及其前后快照学习源码、输入形状／来源和位置参数流；不是手写业务 DAG，也没有微调大模型权重。
- `certify-artifact-motifs.mjs` 在不同输入上各运行两次，并与历史产物核对。三类候选分别覆盖配对证据复算、计算加多图输出、固定三页 SVG 排版。模型继续负责内容、适用性与最终判断。
- TypeScript runtime 支持原生 Python 路径、相对路径和完整字节相同的交付副本；在新隔离目录重算当前输入、禁网、只读原件，核对版本后发布产物与原样程序。修改过的程序只能走普通工具，不记认证复用。
- 独立 Web wrapper 保持原工具表、File SDK 和正常服务入口，记录目录在首请求是否可见及 selected/verified 回执。旧 `verified_skips` 不被伪造为程序复用次数。
- 修复了非 SVG 可选字段在 JSON 持久化后摘要不同、目录晚激活、相对路径和副本无法接入等实际联调问题。所有旧失败保留。

## 完整对照与反例

以下为每 Task 全部实际回执估费，含失败恢复及附件准备，不是服务商实付；每行两侧同输入、同提示、同工具／模型和风格要求。v10 为更换资料后的整任务观察，但该轮副本路径未接入认证回执；v12 已修复该入口。

v10 的费用差不能当作认证结构跳过模型的成绩。v12 Paper 真实复用一次，费用下降约30.5%；Data 虽然真实复用，随后多轮修图使费用上升约37.2%。PPT 在 v12 中把旧程序作为排版参考、再修改代码，没有触发整程序的认证执行，费用上升约2.7%。不能只选 v10 的正面数字宣称三个场景稳定省费。

Data 的后续候选从模型实际完成的标签、图表及配对处理修复继续学习；独立认证和新数据复测与来源任务分开。因报告后来加入原输出目录，直接把整个当前目录视作原程序产物的认证曾被拒绝；保留拒绝记录，另用原样程序的真实机械重放补精确参数流，不把该重放算作新的独立业务决定。
