# 批量邀请码与场景评分恢复（2026-10-20）

## 原因与范围

用户希望邀请码可批量、永久使用，修复复制/粘贴体验，并恢复曾有的 1–5 分评分。检查发现 `createInvites` 原本不设 TTL，服务器仅存哈希，注册成功后单码消耗；登录 session 的七天期限不是邀请码期限。线上只读元数据检查发现还有 10 月 13 日创建的未用码，没有过期字段。未取得用户当时的具体失败码/响应，不能断言其“过期”一定由某一原因造成。

此前两个 UI 固定传 `count: 1`，生成码放在无复制按钮的 output 内，关闭设置即丢失展示。当前改为默认 5、每批 1–20，逐个/全部复制，可选只读字段和拒绝剪贴板后的手动复制提示；后续生成失败保留已显示码。明确永久有效、每码可注册一个账号、使用后失效；离开前需复制保存。不储存明文到服务器或 localStorage。注册沿用原生粘贴，去首尾空白、关闭大小写自动更正。设置输入框停止冒泡 paste，保留默认输入行为。

PPT、Paper、Data 以及旧 File 对照恢复每侧 1–5 分。双方完成后可选，复用已有输出 SHA 与评分 revision，确认后显示已保存；失败/版本冲突保留已确认分数并重新读取，不自动重放写入。普通 Chat 与新版独立 SDK File 单栏没有原数值评分接口，本次未添加。
