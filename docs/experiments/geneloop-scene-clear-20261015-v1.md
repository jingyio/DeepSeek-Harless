# GeneLoop 场景删除与界面入口清理（2026-10-15）

## 问题与修改

用户删除输入框中的 `/ppt`、`/data` 后，编辑器已改变但后台仍保留场景。新增按会话观察的草稿取消同步：完整场景标记被删除或退格为未完成前缀时立即显示 `/chat`，等待既有绑定完成后更新后台；迟到请求不能恢复已取消的选择。发送成功后的自动清空不算删除，正常多轮场景保持。

已经开始执行的场景仍遵守不可变绑定：切换普通模式时创建普通会话，保留原历史，转移未发送文字与附件。后台完成不抢其他会话焦点；返回原会话后再转移，目标已有输入时不得覆盖。快速重选、继续打字、冷缓存及延迟返回均有回归覆盖。后台重置期间短暂禁止发送；网络失败保留输入并提示刷新恢复。

使用公开插槽移除上方重复的 preset 选择器和精确的 `welcome-notice` 内测声明，其他引导与审批保持。清理旧 `body > a[href="/paper-revision"]` 悬浮入口，聊天内链接保持；论文工具继续由 `/paper` 提供。工作区名称不再带 `title` 或悬停卡片，公共工作区路径投影仍使用账号内不透明标识。
