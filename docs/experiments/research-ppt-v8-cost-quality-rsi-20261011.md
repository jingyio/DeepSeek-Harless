## 1 / 问题、假设与否证

真实需求是生成含完整论文图、原生方法流程和带实验条件结果表的可编辑 PPT，跨 MCP 重启后只修订指定结论页，同时减少反复读全稿和交付失败。

普通有限组合能否降低实际错误/重试；模型明确选页后，可否从正常参数轨迹学习 `pin_deck_pages → read_pinned_deck_pages`，在新材料安全跳过调度；模型生成摘录工具能否通过真实执行、反例和独立认证，这些分别验证。普通脚本不能冒称 Motif，工具编译成功不能冒称功能晋级，局部旁路不能代替整任务成本证据。原图截断、数值错归、科研质量不合格、失败恢复成本增加或人评缺失，均不支持合格总成本下降。

## 3 / Graph、Code、模型与 RSI

有限渲染/检查/验收/交付组合、checkpoint、选页计划投影是普通 TypeScript/Python/MCP 功能。模型决定科研理解、选材、叙事、选图、明确选页与具体修订；这些语义工作没有蒸馏成结构。

新 Motif `edge_motif_91c3ce7f06f6` 来自 LoRA / QLoRA 两个正常修订决定的实际参数边：`pin_deck_pages → read_pinned_deck_pages`。冻结 digest `c7a9e8fc8d758934ba8e4cfc78e825b2fdd8a22d199c93495063a774eaaf5ec0`；Prefix-Tuning 独立轨迹认证通过。在线 manifest digest `299be29574ad20d34cd1d4d9f63b49200b9db4e0bf31cee192ab11c4c1f3dfe4`，`code_nodes=[]`。结构认证不保证科研内容正确。

版本守卫绑定同 job 输入 SHA 集、实际稿 SHA、来源和模型选页集合。`version_sha256` 是 job 输入 SHA 列表按冻结编码计算的摘要，不能误用某一个 PDF SHA。E2 C 修订有 2 个不同 verified batch，分别实际执行 `read_pinned_deck_pages` 并核验后跳过 1 整请求。E1 插入 `read_deck_plan` 等工具屏障，实际未旁路；没有为争取节省放宽守卫。

工具 RSI 为真实 DeepSeek 提案、受限 AST、`tsc` / Node、真实 PDF 训练、合成反例、结果后决定；两配置共 6 候选、6 请求 / 79,980 token / $0.023771460，全部未晋级。首配置前两候选因 `while` AST 拒绝，第三通过 PDF 训练但非 BMP/换行上下文漏字符；第二配置因动态属性访问、类型断言/任意调用或候选字段格式失败。BERT 未解析，没有手写工具替代失败，也没有把普通组合器称为模型生成的新工具。

## 7 / 真实交付与质量边界

训练、认证、两题三组共 9 个完整决定，初稿加修订共 18 份可编辑 PPT、120 页。真实 PDF/PNG、notes、来源、拼图及并排导航保存。服务器根 `npm test` 136 Python / 29 Node，`npm run smoke` 通过；后者是 18 合成工具诊断、0 API。TS 适配器真实 stdio 只读 27 项、写/重启 28 项通过，9 个决定的实际文件比较显示目标页变化、非目标 OOXML/notes/媒体/样式保持。它们不证明科学质量合格。

六份最终评测稿共 42 页均有完整页序的文字 AI 辅助意见，全部 `needs_revision`。补充 14 项可见版面/原文核对明确了以下问题：

- E1 B 第 5 页提取 PNG 已截断原 Figure 5 右列；实际原 PDF 完整。正文将 xformers 的 122 与 Triton 的 155 错归 FA / FA2，属于明确数值/图例错配。
- E1 C 第 4 页数值与原 Figure 4(b) 相符，不能泛称造数；实际可见轴单位/变量未完整显示，需修订。
- E2 C 漏列 MMLU 5-shot；GSM8K 仍为 8-shot `maj@8`，不能错误声称也漏掉或改成另一协议。

有原图、流程、表格/图和真实预览不等于图件完整、科学解释正确。辅助意见中的解释/多引文会令字面定位为 false，不能机械认定原文无证据。**独立人工盲评未完成、统一同质量合格门槛未建立。** 最终 37 页报告全部辅助排版核验通过，仅证明报告可读和文件完整。

## 8 / 结论、复现范围与下一步

在这些条件下支持有限交付、同 job 跨 MCP 重启修订及选页读取参数边的真实学习/认证/旁路；不支持把科研理解蒸馏成结构，也不支持本轮新生成工具闭环或整任务降本。两次局部节省未抵消其他生成、证据读取和重试开销。

每条件单次、混合训练配置、来源历史重用、A/B 工具集差异、模型/缓存/顺序变化、人评与账单缺失限制因果解释。跨 job 恢复、任意复杂外部 PPT 编辑、Windows 产品实验和独立无 Python 插件仍未验证。

下一步先按原文和实际图核准错误，另存真实修订、保留旧稿与费用，由研究同学盲评并记录修订分钟。质量合格后固定同条件，在新材料比较有限普通脚本/缓存与 Motif 的合格总成本。生成工具 RSI 必须另立 ID、使用新的独立留出，不泄漏 BERT、不放宽已失败 oracle，也不以手写工具冒充模型生成成功。
