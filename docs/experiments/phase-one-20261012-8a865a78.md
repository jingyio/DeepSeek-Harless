## 候选与下一步

目前已证实可用的是普通程序的逐字段增量和核源缓存；不是已学习的 RSI。瓶颈也包括语义审阅，不能将高费用阶段整体标成可跳过。

优先候选为缺口处理中的有界执行分支：目标集合/来源已绑定后，读取当前字段包、执行模型已经批准的补读窗口、校验新凭证及未受影响字段、按明确成功/失效/额度耗尽分支交接。问题/页窗相关性、论断支持和跨论文结论继续由模型判断。完整引用检查先做强脚本，不把关键词或标点启发式当作科学支持认证。

下一步先把该候选的普通脚本与完整任务 Code Mode 能力补齐，从多个正常训练轨迹确认它确实反复出现，再独立认证 Motif 和配对测评。若仅与脚本跳过相同请求或更贵，继续用脚本；本轮没有证明新Motif能胜出。
