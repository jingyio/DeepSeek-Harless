# GeneLoop 原生图片场景验收：2026-10-16

## 当前状态

图片接入修复候选，尚未发布。最终结果在本记录后续修订与 PR 中更新；不能把中间生成文件当成质量通过。

## 范围和配置

在既有五格式修复后，追加清晰 PNG/JPG 的 `/ppt`、`/data`、`/paper` 真实网页验收。原图来自合成说明、40 行数据表和含已知内部矛盾的论文片段；实际上传原图，不给模型隐藏的文字答案。Flash / Off，每对 $0.23、每侧 $0.115，累计费用/请求与额外输出上限 null；沿用共享账本，不清零。Chromium 141 原生上传、SSE、点击下载；公网复核使用 Edge 155。全部原始日志和失败产物留私有 `.local`。

## 接入缺口和修复

- 对照 Controller 原先拒绝原生 image；适配器未连接 durable attachment service。保留原生像素，并给两侧分别建立同字节、独立授权的文件来源。
- PPT parser/read_source 接受单页图片，checkpoint 同步允许图片格式且继续核对像素、来源及代码版本。仅更新兼容绑定，原学习库/认证不变，不声称新科学认证。
- 论文读取返回图片来源元数据，模型通过原生图片查看内容，再导出实际来源绑定的 PDF/Markdown。
- 数据增加逐格转录工具及 Web 白名单，原图与转录 CSV 摘要冻结后才进入原统计流程。图片网格可可靠定位时，检查行列及空白格，拒绝填补空值或把后续数字上移；不把网格几何检查称为 OCR 或数字认证。
- 数据表新增 `read_image_table`：按每组最多十行返回原像素条带，只有覆盖全部行后才允许冻结。使用 RGB 无损 WebP，并测试解码后与原裁片 RGB 字节逐一一致，保留真实像素；不修改预算门槛。分段显示避免整页缩小后小数末位难辨，仍不构成独立数字认证。
- 论文明确请求导出时，原生停止钩子检查真实 PDF 回执；已读来源但未导出则续接同任务、同来源和剩余预算。取消、权限失败和来源守卫继续生效，不把回复里的文件名当成已经交付。补充科学校对边界：模拟/真实、独立/随机化不是同一维度，不能凭措辞共存虚构矛盾。

## 必须保留的失败

1. 初次公网测试中两次提交拒绝；另一次自动化丢失图片预览，仅发送文本，不能算图片覆盖，8 次真实请求保留。新脚本必须在发送前确认实际图片预览。
2. 第一轮隔离测试因附件服务未接通，两个任务均在模型请求前失败。
3. 接通后模型读出正确独特标记，但 PPT checkpoint 拒绝图片来源，两侧零交付；修复恢复格式列表。
4. 数据转录工具漏在 Web 白名单之外，生成缺项报告或无文件，不能当成统计通过。
5. 接通工具后模型把空白单元格填为相邻数字、并出现行错位，虽然能生成 PDF/图表，仍判定质量失败。因此新增图像网格占用校验，并按同一原图重新逐格验收。
6. 一侧论文回复声称已经导出，实际未调用导出工具；零文件仍记失败。增加同任务交付续接后复测，PNG/JPG 四侧均得到真实 PDF/Markdown，检查未再把模拟与独立性列为矛盾。
7. 后续数据增量复测三侧把末行 43.06 误读成 43.05；空白格正确不能证明数字正确，因此这三侧仍判质量失败。新增原像素分段阅读，拒绝未经全部行查看的冻结操作。
8. 初版分段图片重复放大像素使请求体过大，四侧被原预算预留门槛拒绝；记录为 budget_exhausted，不扩预算、不重置账本。原分辨率灰度 PNG 又被附件层转码为较大的 JPEG，另四侧同样失败；最终使用附件层可原样保留的 sRGB 无损 WebP，再做独立增量复测。
9. 首次 Windows/Linux CI 暴露全新安装缺少 defusedxml，补到根依赖，并修复 Windows 失败诊断的 UTF-8 输出；修复后对应四项 CI 通过。

## 验收口径和边界

下载须从真实网页点击、比对服务回执 SHA256，再检查可编辑 PPT 页数、PDF 布局和正文。数据转录逐格比较原 CSV，40 行/2 缺失应得到 n=38、斜率 0.843814527976413、95% CI [0.7640458716556241,0.9235831842972019]、p=4.235211557068137e-22、R²=0.9274577485771388。论文需发现 40−2 与 39 矛盾、删除无依据的因果外推，不虚构文献真实性核查。

图像网格只适用于清晰、完整、规则的单表，不覆盖倾斜照片、合并单元格、多表、手写或低清晰度；模型视觉转录仍需数值复核。PPT/论文版式检查不等于语义与科学事实全部正确。未验证 Pro、WebP/GIF、扫描 PDF OCR 或真实长论文。所有费用为代理估算，账单实付未知，不作同质量收益结论。
