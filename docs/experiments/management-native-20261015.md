调试失败与修复没有回写历史成绩：

- 第一版集合读取与 pin 的路径版本编码不一致，12 次请求 / USD0.010290783，原任务暂停后归档失败。统一句柄版本及集合状态；持久化付费响应结算先于下一 Agent 步骤，避免账本并发写入。
- 前端上传 DTO 缺少完整源路径、会话账本没有映射原生会话 ID、已启动会话重复换 preset：均有私有失败记录；通过受验证的输入映射、独立任务预算别名和固定 MCP 热绑定修复。HTTP403 曾被上游 UI 描述为密钥问题，实际是本地预算路由拒绝，未发出付费请求。
- 前端包装器丢失 Annotated 数组长度约束，守卫回退且停用了相关候选；保留约束后做完整 catalog 等值诊断，用新版本材料重新认证，没有重签旧证据。
- 老快照接口把内部副本标记列为新增，真实报告保留了该缺口；新版按原始用户文件与目录比较并验证。
- 模型先用文字等待高风险确认、缺报告时验收调用传入 None：保留失败。明确调用 execute_plan / restore_plan 请求原生确认，缺报告现在返回可修复失败；后续真实确认、拒绝、恢复通过。
