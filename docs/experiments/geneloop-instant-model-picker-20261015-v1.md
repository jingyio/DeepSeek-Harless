# 网页输入栏与模型切换验收

- 实验 ID：`geneloop-instant-model-picker-20261015-v1`；代码基于 `4f54a13`，分支 `codex/instant-model-picker`。这是界面交互与真实链路检查，不评价科研质量或 Motif 成本收益。
- 问题：模型及推理选择等到 RPC 返回才更新，用户感觉卡顿；网页暴露五个不需要的通用命令与权限选择器。目标是选择立即反馈，实际发送仍使用正确模型。
- 实现：公开 slot 包装原生组件，保留编辑器、附件、键盘和菜单；公开 menu store 过滤五个指定命令，模型 directory 用每会话串行队列投影最新选择。发送与选择共用队列，失败保留草稿，旧响应不覆盖新选择。场景按钮在草稿开头插入/替换 chip，正文与附件保留。
