# Script Motif 真实闭环与原题对照（2026-10-18/19）

结论：**脚本参数化、沙箱认证、结构与本地语义匹配、跳过模型、自动发布/下一任务加载已观察到；没有观察到合格任务的净降本。** 最新完整题 Execute 实际跳过 4 次 provider 决策，但总请求 173 次、代理估费 $0.260957028，Baseline 为 88 次/$0.220640676；Execute 最终报告未交付合格。按用户要求不提 PR、不推送、不部署。

## 问题、假设与实现

假设：把正常 Agent 写过的脚本变为可重新绑定数据的算子，能省掉写脚本/选工具的完整模型请求；结构筛选后用本地 embedding 避免无关调用。否定条件包括重复工作、恢复开销超过跳过收益、交付不合格、语义误匹配。不能仅以候选命中、缓存代码字符数或 synthetic tool-call 数量判断收益。

独立分支 `codex/paper-script-motif`，起点为当时最新 `origin/main` **9f945a5**。生产文件、原桌面脏工作区、既有认证库和用户原件未修改。实现文件及协议见 [接口](../interfaces.md#script-motif-实验接口)。离线 Python 从真实 `bash` 事件中的 Python AST 提取参数，在线 TypeScript 使用原生 provider continuation/工具执行；没有复制 Agent 循环、为书目键写特定规则或新增模型可见工具。

当前自动生成范围为 Bash 包裹的单条 Python 程序，尚不支持一般 Bash 管道、动态拼接依赖、网络脚本或任意 MCP 轨迹编译。原有 MCP Motif 路径保留。认证的是不同输入上的确定性/来源等价，不是作者、年份、出版版本等结论正确性。一个历史错误算法也可能确定地复现。

已修复的实验问题：在生产入口直接接入会使旧源代码锁失效，改用独立 launcher/wrapper；拒绝包含来源特有条目常量的脚本；绑定发生变化或回执未验证时回退；一次性内部命令避免把脚本正文反复塞进模型上下文；将输出限制由 192 KB 收紧到 16 KB，阻止旧版 64 KB 脚本结果被原生 Bash 截断后无法验证。修复后重新实际沙箱认证，没有仅替换证书哈希。

## 数据、训练与冻结

全部使用真实 DeepSeek API，无模拟模型代替效果验收。训练和留出分别取同一私人真实论文书目库的两组各 100 条原始记录，不注入错误、不指定 Agent 必须写某个脚本。短任务仅检查条目盘点、重复与明显格式问题，不联网、不输出报告。两者是**同一论文派生输入，不是独立论文或科研决定**。留出用于认证与参数调整，不能再当完全未见测试集。

完整测试使用原来的 `scenarios/paper-submission/reference-audit.prompt.md`，题面字节 SHA256：`6199102371fc38c05912b76596bb6c48cbde4ee1eb157bafe0cae4eae0de4a89`。ZIP 未改，匿名来源版本 `7aafe2468ac50d69c23c3dab719213b47406b2c33efe55dc911c361f25360027`；书目 315 条记录/314 个唯一键，主论文 34 个引用键，独立扩展摘要另有 2 个。不能把未引用的库内记录都当成印在论文中的参考文献，也不能混合主稿/扩展摘要范围。

首轮 9 个可提取程序，经来源常量筛选后发布 3 个；输出预算收紧后旧来源留下 2 个。另一次真实正常任务自动进入学习历史，最终库有 **5 个**程序，涵盖条目/重复键、字段重复与格式检查等。新程序来自真实模型轨迹，不是人工补写的书目算法。程序间有功能重叠，当前没有自动合并覆盖或负收益降权。

自动学习由任务完成事件触发 `advance-script-motifs.py`，持久保存原始任务路径、固定首留出、不可变 round 和 owner；无付费编译请求。已实际验证下一任务冻结新的自动库并执行。最后兼容认证 round 为 `round-68b12be9b79b4ac8b106808bf1c87d47`，摘要 `232503be043a77f882960f23dedc8b0f65c0cce5d9786b35a27addb020c7d3ea`。此前 v3 三程序库摘要 `d95e9eac5ab53bf35238aacfbc7b955009ae60effd7c7be708ce99760895d5bd`，旧库保留。

## 质量检查与失败

没有开展人工盲评，也没有改写实验生成报告使其通过。只读提取文本并逐页渲染检查了 Baseline、Shadow 和最新占位 PDF；两份长报告未见明显重叠/裁切，但字号和浅灰色影响阅读，未按题目完整呈现表格。

- Baseline 混合主稿与独立摘要的 36 个引用；摘要范围又包含未被引库条目的严重风险判断，计数口径不一致。部分作者格式/信息缺失被提升到 P0/P1，与题面分级要求冲突。尚未逐项重新联网复核其外部断言。
- Shadow 的修改清单与逐条列表编号错位；书目“唯一键”算术与自身 314 个唯一键统计不一致；摘要、逐条优先级与最终数量也不一致。存在将非必填字段缺失列为问题的情况。不能把“找到来源链接”当作每项事实已核实。
- 两次完整 Execute 都在最后长报告工具调用中触及 8,000 输出限制，原生事件 `turn/end.reason.kind=max-tokens`；一次没有 PDF，一次仅先前导出测试的占位文件。原生状态却为 completed。新增独立核算保留原始状态、停止原因与输出文件，**文件存在不代表完成用户报告**；生产完成判定及长输出恢复尚未修复，不重锁生产库来掩盖问题。
- 初始完整 Baseline 未部署审核渲染器/字体，229 请求后报 `paper_pdf_not_delivered`。补齐环境后重新测试，失败费用保留。
- 本地网络部分域名解析触发 web_fetch 的非公网地址守卫；没有关闭该守卫。正常 Agent 的其他网络工具路径与失败、重试继续计费。结果不代表网络正常环境。

原题需要逐条来源判断，脚本计数/格式检查只覆盖一小段。多个功能相近的程序在不同前驱后仍被接入，模型随后重复检查或继续编写网络脚本。当前证据不支持“结构+语义相似度即可判断下一步必要工作”。需要更明确的产物契约、已完成 Evidence 和失效条件，避免高相似度但无新增信息的执行。
