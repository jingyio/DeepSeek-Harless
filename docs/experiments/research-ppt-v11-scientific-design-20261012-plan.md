# V11 科研视觉交付计划

- 实验ID：`research-ppt-v11-scientific-design-20261012`。
- 用户目标：科研稿更成熟、更清楚，交付仍可编辑、事实/条件/图件完整。本轮先提升工程质量；不把人工版式或Skill称为新Motif/RSI。
- 假设：受限证据聚焦/结果总结/方法机制页型比V10通用布局更适合科研证据；若同内容出现丢失、图片缩小不可读、非目标变化或用户更偏好旧稿，则不支持本次改进。

## 实施和对照

1. 在现有JSON→TypeScript/PptxGenJS→Python MCP→LibreOffice链路增加opt-in `archetype` 和有来源索引的`evidence_notes`；服务根据批准来源生成可见出处。旧计划几何与样式保持；不修改上游Harness。
2. 使用V10已核对的PiSSA/LoftQ/DoRA稿进行同内容重排。只改展示字段，对照标题、正文、表/图表数据、process、notes和来源，核验原图字节；证据重绑定必须根据原page/candidate/图字节验证，不能猜句柄。至少展示三种页型和一个完整稿；局部修订另检查非目标OOXML及PNG保持。
3. 在服务器跑新增协议/内容保留/来源索引/明确修订拒绝测试、场景回归、根npm test和smoke，所有日志保存。渲染所有交付页，辅助视觉检查文字、层级、图字、出处和遮挡；独立人评留给用户，不自行声称审美合格。
4. 用本机先下载再上传的VeRA公开论文进行一份新6页真实DeepSeek生成，关闭思考/压缩、现有19工具/相同顺序、无新RSI候选，串行。它检验模型是否实际选择并交付新页型；不与不同输入的历史费用做降本归因。

## 验收与回退

- 正文、数值、条件、来源和原图完整保留；图片等比未裁剪，文字/表/数据图/过程形状可编辑。
- 所有新页型通过PPTX/PDF/PNG真实渲染、文字保留、源图/表/图表数据检查；来源索引错误、隐式重绑定和越界拒绝。
- 旧plan无新字段时不触发视觉重排；明确修订仅目标页变化，重新验收新版本。
- 审美效果先由用户对照判断，人工分钟未获得则标未知。若新页型无法容纳完整内容则具体报错，回到旧页型/语义调整，不静默删内容或缩到不可读字号。
- 后续仅从真实重复排版失败中尝试学习适用条件/修复；独立认证与新任务额外收益未取得前，不报告RSI晋级。
