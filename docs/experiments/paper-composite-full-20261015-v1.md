# 新论文 Motif 库全流程复测（2026-10-15）

## 问题与可比范围

先前新库的 4 请求 / 1 Verified Skip 是一段引用读取链的真实联调，不是完整论文任务。旧 `paper-full-rsi-integration-20261012-v3/baseline-01` 完整任务有 164 次请求，使用的是另一套工具、提示和工作目录；不能把 4 与 164 相减宣称节省。此实验用新 Web 论文场景的同一份输入、同一说明和同一 17 工具配置对照 Origin / Shadow / Execute，观察真实完成质量、候选、跳过、回退、请求、费用和 PDF。

历史私有归档有 78 个名称含 `baseline` 的运行记录，70 个标记完成，其中含重复变体、续跑和失败。扫描其事件中出现的工具名，只有 13 个记录出现新库四个读工具中的至少一个；这是静态名称兼容性盘点，**不是** Motif 命中率或请求节省。当前复合库只有两条经现行契约绑定的可执行只读局部图；旧 9 图 Shadow 库尚未整体迁入生产执行协议。

## 结论与下一步

已完成同配置三臂真实运行，**没有观察到完整任务的 RSI 自动跳过或可归因的净降本**。局部认证链可在定向输入下触发跳过，但不能替代完整任务质量与收益对照。下一步先解决全稿相对路径、补齐旧库中经新协议认证的局部图，并在独立论文、来源和人工质量门槛下复测。外部元数据查询超时、句柄错误与 PDF 逐页视觉质量须单独处理；未完成这些工作前，不把旧 160→20 请求结果迁移为新 Web 库的效果声明。

后续定位了只读工具穿插的 manifest 屏障以及长 `.bib` 读取上限不一致，修复与新旧配置分开的真实结果见[前沿复测](paper-composite-frontier-20261015-v2.md)。v9 全任务有 2 次真实跳过但整体请求/错误更多；v10 的完整三模式任务均被 DeepSeek 503 中断，不能回写为本轮 v8 的成功结果。
