# 导出收据与最终答复成本优化（V6）

在同论文三个既有范围上，新版execute代理估费比V5 execute低21.55%；新版同工具原生与execute对照低12.75%。前者含工程协议和模型输出变化，不能全部算成Motif贡献；后者也有一次原生额外无变化写入造成的路线差异。没有账单核对、跨论文或人工盲评。

## 问题与改动

免费拆解V5每次请求：execute最后请求占各任务费用42%–53%。模型已收到完整检查，导出又重复返回它；最后答复还重复抄写引用键、编号和检查说明。即使Runtime接管了检查/导出调度，工具结果仍进入模型上下文。

本轮不重新生成算法、不手改原DeepSeek AST。新增工程协议`revision_receipt_v2`：成功导出返回`structural_check_passed=true`和完整检查的`audit_sha256`，仍携带原来源/版本收据和真实文件摘要；失败、未知字段、计数类型异常、原字段不保留或当前重复非零时，返回完整原输出。完整检查、全部原字段/来源、修订前后报告仍在当前私有`revision-report.md`。原只读检查结果保持完整，未删除科研问题。

各组同提示增加最终答复150个中文字的软约束，保留标识修正/去重/补缺三类实际依据及未核验真实性/正式版本的限制；实质冲突与失败不受该字数约束。输出上限仍8192。模型没有完全遵守：execute-main为175个中文字；不能称强制限长或精确输出控制。

公开入口复用原控制器、预算代理、MCP和Harness插件；不修改上游、不另造Agent循环。检查/修订算法来自此前真实DeepSeek生成，两个调用图重新从本轮正常轨迹编译；收据投影、提示、文件守卫、排版属于工程。
