# 场景流式、推理切换与通用附件验收

## 问题与范围

用户反馈场景对照卡等到结束才显示全文、推理选择只有 Off、TXT/JSON/CSV 同传后两路零请求失败，并要求 PDF/Word 能被实际读取。生产失败记录确认：报告入口对第一个 TXT 附件执行 CSV/TSV 限定，在模型调用之前退出；不是 API 额度耗尽或 PDF 交付失败。

本轮使用正常 DSH/Motif 执行路径。接收附件与具体工具适用格式分开，文件原件、来源 SHA 和权限检查保留；提取内容传入原生模型请求，未新增另一套 Agent 循环。Web 连接打开不再被误当作流数据已到达；有效快照才标记在线，卡片保留只读轮询恢复。DeepSeek 原生 adapter 的模型目录公开 Off/On，On 对应官方 high；每轮冻结选择，不覆盖既有运行。

## 配置与证据

- 分支：`codex/scene-stream-thinking`，基于 main `2a03e22`；此前线上运行 `b4712d6`。
- 运行环境：Linux，Node 22.23.3，Python 3.10；原生 DeepSeek provider，`deepseek-flash`。合成附件，不使用私人论文。
- 实际预算：每对照任务 $0.23、每侧 $0.115；原生聊天每任务 $0.23。累计费用、累计/单次请求数及额外输出 token 上限均为 null；保留原共享账本。费用为代理保守估算，不是账单实付。
- 私有记录：stage `.local/attachment-documents-v2/`、`.local/attachment-report-v1/`、`.local/paired-stage/reasoning-tools-v1.json`。输入 manifest、实际配置、SSE 帧、最终响应、文件 SHA 与失败记录均保留。stage 的旧 Git HEAD 不是本次代码身份，实际工作树另以文件摘要核对。

## 真实结果

1. Word/PDF 混合附件：`research_requirements.docx`、`study_reference.pdf` 与未知二进制同时上传。提示词没有提供文件内部标识；两路均正确读出 DOCX/PDF 独有标识与具体正文要求，未知二进制明确未解析。同一会话 Off、On 两轮共 5 次真实请求，0 工具错误。SSE 在终态之前，Off 两路分别出现 5/8 个非空长度，On 分别 7/7 个；不是完成后拆字显示。
2. 截图同款三文件：按 TXT、JSON、CSV 顺序上传，简短指令生成报告；Baseline 19 请求、Motif 7 请求，两侧均交付报告 PDF，实际下载 SHA 与交付记录一致。Baseline 有一次工具错误后恢复，不能写成全程零错。两侧在终态前分别观察到 19/16 个非空文字长度（工具回合之间会重置当前段长度），另有真实工具状态。该用例只证明上传、执行、交付与流式链路；本轮未重新做科研质量盲评，不从一次合成任务宣称普遍降本。
3. 原生会话 Off → On → Off：同一会话三轮分别 2/2/1 次真实请求，工具调用 1/1/0；On 带着前轮 Off 工具历史正常继续。输入 5,322 tokens（缓存命中 2,944 / 未命中 2,378），输出 113，总计 5,435；代理估费 $0.000866664，0 额度拒绝、0 未知用量。
4. 浏览器实际选择 On、同一可见对话 `/data` → `/ppt` → `/paper` 成功；论文场景在“运行中 / 正在回复”时出现“以下继续”的部分正文，随后完成。论文仍为 Shadow，未宣称实际跳过模型。
5. Linux 隔离进程零模型读取：PDF 由 Poppler 提取，真实旧版 `.doc` 由 Antiword 提取 5,432 字符，DOCX 由 XML 提取。来源 SHA 一致，依赖只读、宿主私有配置不可见。PPT 65 项代码锁通过，5 种页数的真实 MCP 完整 schema 匹配。
6. 独立审查补齐 Strict OOXML 文档命名空间，并拒绝未知命名空间伪解析；Web 派生参考正文取消旧 1 MB 额外限制，benchmark 默认保持。大于 1 MB 的用户文字、TXT 与 JSON 完整性通过确定性回归，不通过额外付费长上下文调用替代。

## 负例、限制与回退

- 初次新代码验收因公开消息 metadata 含 `undefined` 而在模型之前失败；改为省略该字段，并补严格 JSON 回归。`attachment-documents-v1` 原失败记录保留，没有付费调用。
- 首轮 CI 暴露轻量环境没有统计依赖，以及 Windows 自带 Xpdf 不支持 PDF 标准输入的问题。准备入口改为不导入统计/MCP，独立 `python -S` 测试保持强制执行；完整 MCP 验收在已安装统计依赖的 Linux 实际运行。Windows PDF 使用已读字节的私有临时副本兼容 Xpdf，不降低 PDF 解析校验。
- 生产诊断账号旧凭据已失效，未重置密码或新增账号；不能将 stage 认证浏览器验收写成该生产账号已验收。
- 两个极小 LibreOffice 布局回归 `.doc` 未能产生正文，保留结果；后使用标准正文文档完成真实提取。未知/损坏文件保留原件和明确解析状态，不因一个辅助附件拒绝整轮。
- PDF 当前读取文字层；扫描图片需 OCR，文档图像和版式不作为已核查内容。接受任意文件类型不等于每种二进制都可解释。数据统计工具仍须真实、明确的数据表，不能从参考 PDF/Word 编造数据。
- 部署切换仅代码、解析器配置和应用进程；共享预算进程、账号、历史任务及用户文件保留。回滚仅恢复入口及配置，不回退账本或用户数据。
