# 文献 Agent 效率对照协议与当前验收边界

2026-10-12。当前真实Web接入验证提供普通Harness基线轨迹；它不是三组公平对照。已完成包含真正Code Mode的[四组证据准备组件对照](harness-strong-20261012-5da6ab9f.md)，全任务科研语义质量对照仍待运行。下一轮实验开始前确定新实验ID并冻结本协议的实际配置。

## 比较对象

1. 普通Harness：同一Web文献工具/来源/问题/模式baseline/自动支持检查/重试上限；批量Code Mode允许，不刻意禁用强基线能力。
2. 普通脚本：相同语义选择与质量条件，确定性证据准备/已批准计划/结果缓存允许；显式标明冷启动、解析缓存和完全同任务缓存。不能替新问题自动选页并算成学习所得结构。
3. learned Motif：从独立正常工具轨迹挖掘与认证的当前工具库，经来源/权限/版本/参数守卫后执行；失效/失败回到相同Harness，全部训练/认证/匹配/失败/恢复费用计入。旧evidence_preparation或literature_pdf库不能改工具名称直接用于literature_web。

先对已批准的完全相同计划做机械比较，要求原文位置与交付完全一致；再对不同研究问题做语义比较。不同问题、不同缺口或不同引文支持标准的结果不能直接排名。每组至少重复3次轮换顺序，模型前缀缓存无法完全控制，报告逐轮分布和失败，不只报最快一次。

## 质量与失败口径

每项任务完整覆盖所选论文五字段；当前来源与选中原文可重放，支持检查/字符/读取上限相同，正确完成当前问题的最后综合。自动检查为固定可复现门槛，不等于科学真值；用户当前要求直接交付、无人工审批。字段缺口/错误归因/不受引文支持的重大论断单列；仅在满足同一门槛的任务上比较费用，不能通过多撤回事实获胜。

成功率分母包括超时、429、工具拒绝、预算耗尽、无真实产物和不合格交付。失败已发生的费用仍计入，不隐去训练或恢复。不以内部step/tool数量、verified skip或Token数代替端到端收益。

## 指标与否定条件

记录代理估费与供应商实付（实付未知时明确未知）、cache hit/miss/output token、真实模型与embedding请求、总时延/启动/匹配/重试、领域覆盖与维护成本。开发/人工质量核验成本未量化时不能宣称总成本已下降。

如果Motif与强脚本跳过同样的模型调用，或相同质量下全成本更高/差异不稳定，保留脚本，缩小机制主张。手写Web流程、批量读与精确缓存不是learned RSI。优先考察不同问题/来源变化/证据缺口中的可验证重复分支，而非再包装一条固定工具链。

## 思考模式与材料

当前SDK/Web固定off。off/high后端参数、预算计价/usage、工具调用兼容与取消验收完成前，思考模式比较不启动。两模式必须用匹配模型、来源、问题、工具和质量标准；最终前端独立于该实验变量。

三篇已知论文足够接入与机械调试；跨语料泛化和领域效率结论需要独立留出论文/问题。20–30篇/8–12题只是小规模实验设计，不能承诺统计充分；当前每任务1–20篇，较大语料分组，记录批次而非偷偷截断。
