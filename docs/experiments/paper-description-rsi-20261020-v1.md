# 论文 RSI：仅更新 Positive Motif 描述

本轮完成一个受限更新对象：真实任务结束后，由模型根据已认证算子的代码与契约提出描述，另一独立请求审核，发布后供下一任务使用。最终 F→G 在冻结代码上自动完成；没有人工指定候选选择或填写正确答案。**默认关闭、未部署；证明描述更新闭环，不证明它单独降低费用或保持任意报告质量。**

## 范围与机制

分支 `codex/paper-description-rsi-20261020`，基于 PR100 的 `90c6912`，最终执行代码 `597d363b`。只修改已有私有 Script 学习入口；不更换 Harness、不新增模型可见工具，不修改生产配置或公共认证库。

- `script_description_learning.py` 接在现有结构编译之后。程序先选择已认证算子，最多三个、各模板最多6000字符；模型收到参数化代码、输入/输出接口、旧描述及来源摘要，不读取完整用户文档、历史 stdout 或整份轨迹。
- 每批最多一次生成、一次独立审核，无自动模型重试；响应严格限定 ID、描述与证据引用。只接受24–480字符的单行描述，而且必须短于编译器原描述。文本超预算只拒绝相应目标；未知目标、重复ID、额外字段或错误证据拒绝整份响应。
- 审核判断描述是否由源码支持，不是科研正确性认证。代码、输入、权限、参数流、执行规则、证书和代码锁逐项保持不变，只更新描述与库摘要；保留原语义选择和当前 Evidence 守卫。
- 相同证据、模型配置、提示词与学习器版本复用已审核结果，不重复付费；失败也不在相同条件下自动重试。代码或接口变化不得继承旧描述。新提议失败、被拒绝或比当前描述更长时，保留已审核的旧改进；运行中任务不切换库。
- 默认没有配置文件，描述学习不调用模型。结构编译仍为0模型请求；worker 的总请求另计描述学习。账本在每次真实网络请求前持久化预约，失败、未知使用量与重启后的余额保留。

本轮没有更新匹配谓词、拆分 Motif、生成 Negative Motif 或统一各 Harness。现有 frontier 展示新描述，仍由模型做当前语义选择；没有新 Embedding 调用，也不把已有接管能力算成描述更新带来的收益。
