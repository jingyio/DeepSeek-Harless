**机制判断。** 旧 160→20 来自模型采用冻结工具及提示变化；不是 Motif 自动匹配。当前 PDF-only 任务在正式 Web 中重现了同一输入、同一排版程序、相同 335 项字面覆盖，并以 3 次请求完成工具采用，说明核心接线可用；两次成功（3 与 5 请求，其中后一轮有 2 次工具错误）和三次被限流的无绑定失败不足以给出稳定降本比例。旧 32.5% 来自九图 Shadow 库，当前在线包只有两条重新认证的只读图，不能期待此 PDF 任务有 Motif 命中。全稿引用核验与 PDF-only 的请求数和质量范围不同，历史两张表不能相加。

**下一步。** 无用户绑定说明已有一次合格导出，但还需在同一提示/同一工具集下重复并降低导出后的冗余读取；随后用独立报告、相同提示/模型/工具条件复测内容和质量。旧九图可继续映射现行工具契约、认证 Shadow 候选，但写 PDF 不应未经授权变为自动 Execute。产品上线前还要把“要求 PDF 但没有新产物”接入任务终点判定，避免普通 completed 掩盖缺交付。
