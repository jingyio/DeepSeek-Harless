# 科研 PPT v2：完整交付与真实结构复用实验计划

- 实验 ID：`research-ppt-v2-20261010`。
- 状态：计划；真实运行结果另行记录。2026-10-10 用户授权本轮真实实验“不限制预算，开始做”。
- 目标：用户提供 1–8 份 PDF/PPTX、1–30 页要求和汇报说明，生成可编辑 PPTX；支持已有 PPTX 的学术风格修改，提供来源、真实预览、版面核验与交付清单。
- 授权与环境：全部测试和实验在 `/root/autodl-tmp/xjj`，每次保留 `test-logs/` 日志。本轮已获不限预算授权；仍按批次设置有限的运行守护上限，持续限流停止，不作无界重试。此前及本轮费用分别留存。不得提交或推送，提交前告知用户范围。

## 问题、假设与否定条件

服务的真实任务是将论文与已有报告变成可审阅、可修改的组会/会议 PPT。内容设计仍由 DeepSeek 判断，Runtime 接管已有充分执行依据的解析、素材绑定、生成与核验。

假设 H1：模型提交完整内容计划之后，连续的确定性生成和验收操作可以减少调度请求，且不漏掉必要工具执行。H2：从真实普通组轨迹学习并独立认证的 Motif，相对普通逐步调用能减少合格交付总成本。H3：RSI 根据真实反例提出有界准入调整，能减少错误复用，且学习与认证费用可被后续收益覆盖。

下列任一结果否定或缩小相应主张：相同质量门槛下请求/总成本没有改善；普通组合工具同样有效且更简单；输入变更、渲染失败或证据缺失仍继续交付；人工修订增加抵消 API 节省；规则仅在训练任务有效。不得把固定工作流、工具脚本或一次 bypass 当作 H2/H3 成果。

## 本轮功能与结构—语义边界

| 能力 | 确定性执行与证据 | 模型保留的判断 |
| --- | --- | --- |
| 文档解析与固定版本 | PDF/PPTX 解析、来源 SHA256、页码、可读文本与素材清单 | 哪些来源相关、需要补读哪些页 |
| 插图提取 | 嵌入图像或页区域渲染；页码、裁剪区域、图像 SHA256 | 选哪张图、如何解释、是否支持结论 |
| 学术/组会模板 | `academic` / `lab` 配色、字体层次与版式约束 | 汇报重点、叙事顺序和必要的版式取舍 |
| 生成与重风格 | 原生 PPTX 文本/表格；已有对象的受限样式变换；新产物版本 | 科学内容删改、复杂图表/布局改写 |
| 真实渲染与验收 | LibreOffice 生成 PDF、逐页预览、页数/来源/可编辑性/越界检查 | 内容是否完整、论点是否可靠、视觉表达是否合格 |
| 交付 | 经核验的 PPTX、PDF、预览、manifest 与验收摘要 | 是否需语义修订后重新生成 |

新增 MCP 接口为 `list_templates`、`extract_figure`、`restyle_deck`、`validate_deck`、`deliver_deck`、`build_delivery`；复用现有 `pin_source`、`read_source`、`read_page`、`render_deck`、`inspect_deck`。`build_delivery` 是普通组合工具对照：在单次调用里运行相同的真实生成/核验能力，不自动成为 Motif。

功能验收必须覆盖图片中的两种代表任务，但入口接受一般任务：三篇论文生成 15 页组会 PPT、现有 PPT 改学术会议风格，另覆盖不同页数、资料组合和明确内容要求。`restyle` 的首版以对象与内容保留为边界；任意动画、复杂母版和嵌入对象的完全无损编辑需要额外验证。

## 任务、训练、认证与评测划分

在付费前冻结私有 `tasks.json`、输入 SHA256、工具 schema/顺序、要求和验收表。公开记录使用匿名来源 ID；原始文件、计划和日志位于 `.local/research-ppt/experiments/research-ppt-v2-20261010/`。

- 训练：2 个独立真实任务，由普通 DeepSeek 通过真实 MCP 完成；保留正常轨迹后编译，禁止人工拼接事件或模拟工具输出。可复用已有真实公开论文输入，但未完成的 429 轨迹不能作为成功训练证据。
- 认证：1 个未参与训练的独立任务，验证参数绑定、前后置条件、工具结果与失败回退，不能仅用训练续写。
- 评测：5 个独立任务，来源与研究决定均与训练/认证分开；每题运行三组，共 15 次。任务模板如下，实际论文/现有 deck 在下载和冻结后确定。

| 任务 | 用户需求 | 必须覆盖的能力 |
| --- | --- | --- |
| E1 | 3 篇相关论文生成 15 页组会 PPT | 多文档整合、来源区分、至少两处原图或图表证据 |
| E2 | 多篇论文生成指定页数的方法比较 PPT | 共同条件、差异与局限，避免无依据优劣排名 |
| E3 | 1 篇独立论文生成简洁技术汇报 | 单文档、不同页数、图表解释和可编辑内容 |
| E4 | 一份独立已有 PPTX 改为学术会议风格 | 内容/图片/表格保留、新风格、真实渲染验收 |
| E5 | 独立 PDF 与 PPTX 混合资料生成指定汇报 | 混合输入、用户约束、资料版本和来源对应 |

E4 的输入 deck 必须在运行前单独冻结，不能使用刚从同一研究决定训练得到的产物冒充新任务。同一任务的重试与后续修订归属于原任务，不增加独立任务数。

## 三组对照与执行顺序

| 组 | CLI 模式 | 唯一处理差异 |
| --- | --- | --- |
| A：普通逐步调用 | `--mode baseline --execution steps` | 模型逐步发起生成、检查、验收和交付 |
| B：普通组合工具 | `--mode baseline --execution composed` | 内容计划后由 `build_delivery` 一次完成相同确定性工作 |
| C：认证 Motif | `--mode execute --execution steps --manifest ...` | 使用真实轨迹编译且认证通过的结构；失效回退模型 |

三组保持同一 DeepSeek 模型/配置、工具 schema 集合及顺序、输入、任务、模板、预算/步数上限与验收标准。使用统一提示前缀；组别执行指令是记录的必要差异。不能通过删工具、裁上下文或取消核验美化结果。默认关闭压缩，`reasoning_effort="off"`，DeepSeek 上游有效请求必须确认实际关闭思考并保存脱敏配置，不能只记录 CLI 声明。

第一轮按 E1 `A→B→C`、E2 `B→C→A`、E3 `C→A→B`、E4 `A→C→B`、E5 `C→B→A` 交错顺序串行执行。保存 cache hit/miss 与实际请求，不能假设顺序已经消除缓存偏差。第二轮反转顺序，按首轮质量与执行结果决定是否需要；不足重复时报告为小样本观察。

新增生成/核验链目前是候选结构，**当前公共 Runtime 的已验证 PPT 旁路主要是 `pin_source → read_source`**。新链需满足工具副作用授权、运行时支持、真实匹配/embedding、独立认证与结果守卫后才能计入 bypass；仅完成接口或编译不算在线闭环。若 C 仍只能使用旧短链，报告须明确库范围，不能宣称验证了完整交付段的 Motif 收益。

## 两个实验层次分别报告

1. **固定内容的调度诊断**：冻结同一份合格页面计划和素材，三组都完成相同操作。比较谁发起工具、实际执行序列、跳过请求、守卫与恢复。固定计划准备费用单列，不能当作零成本自由生成。
2. **自由生成的端到端评测**：三组接收相同资料和要求，各自通过真实 DeepSeek 形成内容。先盲评质量，再比较合格交付成本。内容长度、补读和叙事差异均是端到端观察，不能用固定内容诊断推断同等质量。

有限预算先跑端到端 5×3；固定内容诊断可先用真实文件/工具做零模型执行检查，需要模型调度的比较另受同一预算或新增授权限制。两个层次分别保存 run ID 与统计表。

## 质量门槛、失败与修订

盲评文件隐藏组别，以任务为单位看 PPTX 和真实预览，并检查原始来源。每份交付先满足以下硬门槛，再计入合格总成本：

- 页数和用户要求满足；已有 deck 重风格时内容、图片/表格及必要备注保持，变更有清单。
- 核心方法、主要结果和限制无重大科学错误；重要数字、结论与图表能定位到来源。页码合法不等于事实正确。
- 无不可接受的正文裁剪、明显重叠、不可读图表或缺失图片；PDF/PPTX 页数一致。渲染依赖缺失或转换失败必须报告未通过。
- 文字和表格可编辑；原图仍可为位图，不能将图片内文字/曲线称为原生可编辑。来源版本、产物哈希、预览与验收摘要齐备。

至少一位人工评审记录合格/不合格、重大错误和修订分钟数；AI/程序检查用于辅助，不替代人工盲评。专家尚未评审时明确写“质量未评审”。文本 bbox 在画布内只是一项检查，不证明框内无裁剪。

额外以真实输入变更、未知/无文字 PDF、越界内容、缺失素材、无输出授权和渲染失败进行安全验收，保留负面日志。需要语义删改的错误回交模型；有界机械修复须重新渲染并复核。失败任务不能从汇总删除，重试、恢复及人工修订计入原组成本。

## RSI 参与度与验证

首轮内容与工具能力先完整运行；“让模型自己生成工具”列为后续增强，不能在本轮用模拟工具替代真实工作。现有 RSI 为受限准入规则提案，模型可依据真实失败反馈提出格式、文字量、页数等候选。固定协议用例只是基础安全诊断；晋级还需独立来源任务上的正确拒绝、正确复用和质量验收。

RSI 轨迹记录：父版本/候选摘要、真实反馈来源、提案模型费用、认证结果、接受/拒绝原因和后续任务效果。认证失败保留旧规则；新反证触发局部失效或回退。不得让 RSI 任意执行生成代码、自行扩大权限或跳过质量门槛。不能宣称已实现自主工具生成或完整自我改进。
