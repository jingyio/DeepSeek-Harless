# GeneLoop 模型切换、每轮场景与设置加载验收

- 日期：2026-10-15；分支 `codex/settings-loading-model-fixes`，基线 `f27494c`。这是产品回归验收，不是 Motif 质量或成本收益实验。
- 问题：Flash On 直接切 Pro 报通用错误，场景延续到下一轮，设置模型页依赖浏览器未提供的服务，账户设置跳页，归档入口占侧栏，历史页面分块出现。
- 预期：目标模型使用可用默认推理配置；每轮无场景标记均为 Chat；设置面板内切换；当前页历史准备完成后整体显示，运行过程继续流式。

## 根因与实现

旧 stage 已真实复现：Flash On → Pro 报 `gateway/internal`，Flash Off → Pro 成功。模型切换省略推理参数时继承了旧 On，而 Pro On 原生预约超过现有每任务预算。修复为显式更换模型时默认 Off，保留显式选择与预算拒绝，错误使用安全、具体的文案。另补冷恢复时工具挂载场景与下一轮选择分离的回归。

原生场景 token、服务端 admission 与持久请求幂等性共同决定每轮场景；成功后只复位下一轮，失败保留输入。浏览器使用公开提交回调，不以清空输入框推断发送成功。

设置使用公开插槽与原生导航。工作区与首条会话增加 3px 间距。head 中的 GeneLoop 圆环等待会话历史与当前页卡片读取，错误有恢复路径，真实输出增量不受遮罩影响。模型目录最初的集成检查发现漏填公开 Fetch `requestBody` 导致 GET 400 空响应，已以真实 HTTP bridge 先失败后修复，并保留错误注入测试。

## 真实模型验收

独立合成会话连续执行 `/data`（Pro Off 双栏）、无命令消息（Pro Off 单路 Chat）、`/ppt`（Flash On 双栏）。只要求简短文字讨论，不生成文件；未评审科研内容质量，不用于估算普遍性能或 Motif 收益。每轮 $0.23、双栏每侧 $0.115；请求次数与额外输出上限均未设置。模型切换与真实请求配置核对一致。

五侧均 completed，结束前 SSE 正文增长分别观察到 30、24、24、24、23 次。每轮接受后、完成后均默认 Chat；接受后及终态各一次同请求重复提交均复用原任务，无新增执行。首次终态快照中一侧费用尚在结算，后续只读复核五侧均 `usage_complete=true`、pending/unknown 为 0，任务与对照统计一致。
