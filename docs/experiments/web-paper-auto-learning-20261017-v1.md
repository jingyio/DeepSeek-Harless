## 真实任务与运行条件

V100 隔离候选目录 `.local/integration/web-paper-auto-learning-20261017`。输入来自此前用户真实论文 ZIP，SHA256 `7aafe2468ac50d69c23c3dab719213b47406b2c33efe55dc911c361f25360027` 的原始 `references.bib`；顺序切成四份各三条原样记录，转为已支持的 TXT 文档上传。不是模型模拟请求，也不是全篇/全书目核验；四项是同一论文的不同局部题目，不能宣称跨论文泛化。

共同请求要求先固定附件版本，再调用普通文档读取工具读取第一页，只检查字面信息，不做外部真实性核验、不生成 PDF。四项分别检查 author/title/year 缺项、BibTeX 类型/年份/出版格式、重复键/空字段、题名/年份/卷页完整性。显式读取要求有助于形成被检验的局部边，不代表任意自然请求都触发该边。所有调用均为真实 DeepSeek Flash / Off，经正式 Web HTTP 任务 API 与 MCP；不是浏览器人工点击验收。

前三项新 Session、Baseline，最后一项新 Session、Execute。运行器只提交任务、等待状态与检查冻结配置，没有直接调用编译器、写图或发布指针。第一次合格轨迹永久留出，第二、三项训练；第四项不进入训练。模型仍选择文件并判断内容；只认证固定来源后读取同源第一页，不能据此复用科研结论。

预算授权为当前实验无限额：`cap_usd:null`、次数/输出配置 `null`、`budget_policy:uncapped_user_authorized`、`reset_history:false`。隔离启动新增账本，既有生产累计账本未清零、未替换；下表完整累计本次全部调用。API 凭证由私有环境读取；一次未正确加载 `.env` 的启动在模型调用前拒绝，0 请求，日志保留。

## 结论与限制

已观察到真实“正常轨迹→自动编译/验证→私有发布→下一任务受守卫复用”，结构与语义的职责未改变。只支持现有第一页读取协议，不自动吸收任意历史脚本/科研判断；新证据不一定增加覆盖率，重复生成同一窄图不代表越学越省。

尚未证明完整论文真实性质量、跨论文适用性或持续净降本；没有达到这些目标时不扩张主张。当前只为 Paper 接线；PPT/Data/Files 不自动学习。私有版本限当前账号运行目录，换新目录不会自动迁移。正式部署仍需同步代码和账本回执接口；本分支没有部署生产或重启共享预算服务。下一步可在真实业务小流量收集正常任务，保持质量/费用与失败记录，再评估更广脚本和结构的认证协议。
