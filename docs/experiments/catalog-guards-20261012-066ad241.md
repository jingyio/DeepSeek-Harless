## 修改与假设

用户授权继续窄修作者遗漏/日期类型，然后检验 Motif 效率。新 `catalog_metadata.py` 解析有限的显式出版/行政日期、arXiv 页脚日期及部分带标记 Latin 署名/姓名-机构-email 格式；候选绑定当前文档版本和原文位置。不猜 DOI 年份、不查询线上身份、不重建缺失数学标题字形。

`read_catalog_packet` 返回 `date_candidates`、`author_regions`。模型 year 仅选择候选 id；publication/preprint 可以用于年份，received/accepted/copyright 被拒绝。未选择时唯一明确年份由普通程序填入；冲突需选择或保留缺口。`author_coverage` 声明 covered/partial/unavailable；covered 需覆盖全部候选署名区域词元，partial 说明原因并保留缺口，有可见候选不能声明 unavailable。词元覆盖不能证明正确姓名分组、完整作者表或学术身份。

模型仍负责作者解释、题目/姓名/标识的原文选择及恢复；Runtime 记录原 submission、覆盖审计和日期投影来源。这些是两组共用的普通场景程序，**不是新学习的 Motif 收益**。Hypothesis 是原读取前沿在新契约下仍能跳过模型且在匹配质量时降本；无匹配、复用错记录、质量差或费用增加均需缩小结论。

仅场景/MCP契约、相关测试和文档变化，共享核心、原 Python compiler/TS controller、预算、上游无变化。实施前及 GitHub 说明见 [接口记录](../changes/catalog-metadata-guards.md)。旧执行版本失效，但 [上一轮失败及费用](catalog-work-20261012-f44dece1.md) 不改写。
