## 问题与方法

普通 Agent 应通过 DeepSeek Harness 调度已接入的工具，Motif 是可认证结构的复用层。新增工具不以学习 Motif 为先决条件；文件管理仍负责持续学习和成本观测。验证完整 PDF/OCR 阅读、图像输入、受控编辑、隔离代码，以及新阅读结构是否能从实际轨迹发现并独立认证。

材料为实验副本中的新合成 PDF、图片、CSV 和文本；真实 DeepSeek Flash/Off，保持原系列 USD1000、共享学习 USD25、任务 USD5/96步与请求/4000输出/2次验收修复。训练材料、源码、验收谓词、驱动和实际配置在调用前冻结；不用 `profile_id` 指定模板，不使用最终留出训练。来源新鲜但非真实科研业务，不把这些诊断视为全部任务或净收益证明。图像回答由明确图形逐项核对，未做人工盲评；其它质量由冻结检查重放。

独立认证沿用现有材料生成适配器：PDF 保持页面与文字语义、改变文档元数据，文本附加独立标记，图像只改变一个像素，从而生成独立字节和句柄。它验证参数流和守卫转移，不证明图像语义、复杂文档内容或任意规则的广泛泛化。后续普通 PDF 则重新生成页面内容，并在候选激活后才执行。

私有目录保存各阶段原始协议、冻结源码、所有模型记录、接口差异、失败、恢复、费用与旧 6366 项不可变文件摘要。阶段切换只在普通任务与认证子进程退出后发生；旧轨迹、证书和结论保持原样。

## 失败与修复

1. 首轮 PDF 交付通过，但独立重放因绝对缓存路径指向原交付目录而失败。改为交付内相对路径后以新材料再验；原失败不重签。
2. 原生视觉调用暴露 Web 自定义 DeepSeek adapter 未传入 Harness durable attachment service。保留 `UNSUPPORTED_CONTENT`，补原生附件访问，再经实际 SDK wire 诊断与真实浏览器新图片验证。
3. 实际 PDF 页图像上传的免费 Files API 记录混入模型费用完整性检查，误阻止下一任务。只修正类别统计，追加原记录对账，不改原模型账本、不豁免真实未知用量。零请求的已登记编辑/代码任务沿用原 job、权限和预算恢复。
4. 原学习解析器丢弃真实 JSON＋图像的工具结果，导致视觉来源核验失败。允许实际原生附件形式，仍拒绝模糊文本或未接纳的图像；原失败保留。
5. 四节点连续阅读候选未在独立执行中完整通过，保留拒绝记录。发现时保留有独立见证的较短候选，认证门槛保持不变。
6. 前端每4秒状态读取持有任务变更队列锁，原观测延迟持续增加至100秒以上。改为状态请求合并、短时缓存及队列外读取；新浏览器观察到合并请求返回并回到约0.1秒，不再不断积压。状态扫描自身仍可能耗时十余秒，不能称所有响应始终低延迟。
