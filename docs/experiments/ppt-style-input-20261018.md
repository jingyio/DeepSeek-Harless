# PPT/PPTX 视觉风格输入与原生模板复用验收

- 实验 ID：`ppt-style-input-20261018`；类型：既有 GeneLoop 产物作为参考的工程验收。输入来自前次 AdaLoRA Baseline 的六页成品，保留当时的版面缺陷；不修改参考稿或追改上轮质量结论。
- 目标：区分文字/主题声明与实际画面，让所有场景读取演示文稿风格，并由 GeneLoop 自己使用官方 ppt-master 做模板内容替换。测试者不写输出 SVG、不制作或修订输出幻灯片。
- 运行：Linux 独立验证目录，Python 3.10.21、Node 22.23.3、完整固定 ppt-master 6.6.0、现有 LibreOffice/字体。模型 Pro Off（Chat/PPT/Paper 和制作）、Flash Off（Data/Files），视觉辅助始终 Flash Off。任务、累计、请求和输出额度为 null，原生产累计账本不清零；估费不等于提供商账单。
- 公共实现：`geneloop_presentation.py` 提取原生声明；TypeScript 通过现有会话命令沙箱渲染，只对输入渲染增加无网络隔离。宏/链接更新关闭，原件只读、衍生物独立，按源 SHA 与页号校验模型 JSON。模型自行判断内容源/设计参考角色；无语义缓存或宿主选页制作。

## 已观察的输入结果与失败

1. 首轮 Chat 六页均渲染成功，但只有四页返回合格风格报告；七次实际请求，部分识别明确展示为未完成。没有以 HTTP 200 宣称六页全读。
2. 将论文页和演示文稿的视觉提示分开，后一轮 Chat、PPT、Paper、Data、Files 均六页识别通过，保存了 `style_observations`、来源 ID、页号和图像 SHA。共 35 次实际请求（30 次视觉 + 5 次最终回答），没有制作 PPT。每个场景实际回答保存在私有结果中，风格具体结论仍属模型观察。
3. 独立旧二进制 PPT 检查：将同一既有参考稿仅作格式转换后输入；确认 CFB 二进制头，隔离生成 PDF 和标准 PPTX，原件 SHA 不变。不是让测试者创作参考或输出页。旧格式、缺字体、动画/视频与复杂效果的保真不据此认证。
4. 普通独立 Harness 不允许已固定工具的 Chat 会话切换场景；跨场景探针被现有范围守卫拒绝，未发制作请求。该限制不能作为成员网页路径失败的证据；真实成员路径需独立验证。失败费用和轨迹保留。

## 制作、检查与发布记录

制作任务要求 GeneLoop 自主使用同一原生参考稿，替换为三页明确标注的合成材料实验（A=17、B=43、差值26），保留设计、备注、可编辑 PPTX、真实 PDF 与逐页预览。设计和内容映射由用户持续授权自主决定。制作结果与人工视觉复核在任务完成后补充，尚未据此宣称风格保留或交付合格。

原始材料、请求/回复、有效配置、失败轨迹、输出与运行脚本只保留在私有 `.local/ppt-style-input-20261018/`。PPT 原生声明和逐页像素本身不能证明新稿内容正确或精确复刻；检查器成功也不能替代人工质量判断。

## 兼容与回退

`ppt-master-v6` / `paper-web-v11` 使用原两项训练与一项独立留出证据进行兼容重编，校验原事件 SHA 和研究决定标识；没有新学习任务、编译模型请求或质量/降本推广。PDF 的两条转换结构保持，仅对本轮实际 PDF 来源版本允许转换，PPTX 模板固定不授权误入 PDF 转换。旧库、旧源码和部署快照留存。
