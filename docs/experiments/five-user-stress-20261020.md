## 已复现问题与修复

上轮自己的旧成员测试对话打开后退回首页。本轮通过同账号公开原生 API 确认 session/list 包含该记录、未进最近删除，空对话分页正常，目标 session/page 返回 gateway/internal。目标历史只有 11 条事件，排除大历史和压缩尾损坏。
