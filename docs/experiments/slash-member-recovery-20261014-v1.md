# 斜杠场景、历史续聊与成员文件边界验收

## 问题与判定

实验 ID：`slash-member-recovery-20261014-v1`。用户反馈少量早期聊天仍报 `Session is outside this Web run`，场景菜单间歇失败，选中 PPT 后输入框没有标识。目标是保留已核验的历史、每轮预算和账号边界，提供原生前缀候选与有色场景引用。出现跨账号内容、重启丢失上下文或选择结果未落入草稿，就否定本轮闭环。

检查发现：更早期聊天没有旧归属索引；原生会话创建曾同时传 `workspaceId` 和 `cwd`；已开始会话的 preset 已锁定，不能原地改场景。额外成员文件检查发现上游桌面预览允许工作区外读取，独立 Home 并不限制读取成员自身 config。后续两次并发启动出现 inotify `ENOSPC`。部署切换还观察到浏览器连接使旧网关 SIGTERM 退出超过短等待窗口。

更早的归属恢复实验见 [chat-session-recovery-20261014-v1](chat-session-recovery-20261014-v1.md)。本轮补充核验三条更早期所有者历史，排除实验/不明来源记录；没有自动认领全部 Home 历史。迁入的锁定历史仅文字续聊，新文件任务或更换场景需新会话。

成员文件守卫曾先用方法替换：单元夹具通过但真实 RPC 越界仍被允许，因而弃用该方案。最终使用公开精确 Fetch 路由和 `workspaceFileScope` Lookup；实测拒绝才作为通过依据。两次 `ENOSPC` 启动失败没有调用模型，失败日志保留。轮询改动后双成员并发与重启通过。未证明存在孤儿 Node 泄漏，不把退出补丁描述为修复已证实的进程泄漏。

## 费用、质量与限制

本轮真实合计 22 请求：三组双用户各三轮共 18 请求，PPT 两轮 2 请求，实际早期聊天 2 请求；各调用为一轮一次模型请求、0 工具执行。输入 26984 token（缓存命中 12544、未命中 14440），输出 85，代理估费 **0.004509264 美元**；最终双用户六请求部分为 0.000755652 美元。任务 elapsed 合计 21.779 秒，包含并行任务，不能当作端到端墙钟；整轮人工开发/等待时间没有完整采集。最终六请求完成时累计运行观察到 46 请求/0.008586282 美元，含其他在线活动；不是供应商账单，未核对实付。

质量标准是合成标记精确回忆、可见引用、隔离拒绝和文件字节恢复，已人工浏览器检查并以断言验证。没有审阅 PPT 生成成品，不宣称论文/PPT 业务质量或成本收益。两用户同时使用不等于容量压测，也不能证明所有数据路径永远无缺陷；临时 Cloudflare 隧道仍受进程与网络状态影响。已授权成员能力之外的工具接入需单独验证沙箱、预算与副作用确认。
