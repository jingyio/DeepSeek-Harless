# 文献 Agent 的对照与扩展验收方案

这是后续实验设计建议，不是已完成的跨语料实验，也不是样本量充分性的统计保证。已有三篇论文足够做来源守卫和执行接管的机制试验；不能证明科研理解、跨论文泛化或合格交付的总成本收益。对应已完成的固定计划试验见 [记录](frozen-evidence-20261010-997d9e47.md)。

## 三层问题分开验收

| 层次 | 实验问题 | 保持相同的条件 | 可以得出的结论 |
| --- | --- | --- | --- |
| 机械续接 | 已批准计划怎样执行更有效率？ | 任务、窗口计划、来源、工具 schema/顺序、原文证据包、解析缓存、模型配置 | 有界步骤的接管、失败回退、请求及运行成本 |
| 科研理解 | 新论文是否被正确阅读并支持交付论断？ | 来源、消费者任务、评审量表；允许模型合理选择不同窗口 | 相关性、覆盖、主体/条件、引文支持和修订负担 |
| 完整任务 | 用户在收集、比较、更新研究笔记时是否受益？ | 达到同一质量门槛，计入失败、训练、缓存、恢复、审阅及人工修订 | 特定工作负载下的合格总成本；不能由第一层代替 |

同一计划运行9次仍只有一个研究决定。三篇论文包含几十页，也不等于几十个独立样本。科研支持审阅目前仍未达到先前门槛；不能将证据包逐字一致称作科学质量通过。

## 必须保留的基线

1. **普通 Harness**：相同模型、工具和任务，保留正常选择、恢复与交付；不故意强制多余调用。
2. **普通缓存**：各组都可使用相同解析缓存；完整任务/计划/权限/来源未变时，另比较直接重放核验并复用最终工件。新问题或新窗口不能命中完整结果缓存。
3. **普通脚本**：手工实现当前合理的机械流程，使用与 Motif 相同校验，不跳过困难输入或来源守卫。当前内部 MCP 组合只代表程序组合，不代表真实生成式 Code Mode 的测试结果。
4. **learned Motif**：仅用训练资料挖掘/认证的库；首次任务和库未命中/失效的费用全部保留，不能只挑成功跳过的任务。

在以后衡量维护负担时，需记录脚本编写/适配时间与 Motif 编译/契约/故障诊断时间。若直接用现有 Code Mode 作为正式基线，要另外开放且冻结它实际需要的工具和权限，并确认各组任务能力等价；当前七工具白名单实验没有完成这一对照。

## 下一批材料与切分

作为可执行的小规模扩展建议，收集20–30篇论文、8–12个消费者研究问题；具体数量需根据试验方差、错误频率和希望检测的改善幅度再确定，不能宣称这个数量足以发表统计结论。

当前单次目录入口最多20篇，扩展材料应按任务分批，不为了凑总体论文数修改来源上限。

- 从用户实际研究主题取材，包含不同长度、双栏、图表较多、附录、重复文件、作者修订版，以及少量扫描件/损坏输入。扫描件现阶段预期正确行为是标记缺口并回退，不要求不存在的 OCR 成功。
- 按整篇论文或整个研究项目分训练、开发与留出测试，示例约5–10篇训练、5篇开发、10–15篇留出；具体配额依总数调整。同一论文的页面、近似副本和修订版不能分散后伪装为独立新语料。
- 训练/开发可用于调提示、Motif 和阈值；留出资料与问题开始评测后冻结。预留任务失败和库未命中，测试集不补进学习库再算作首次成功。
- 问题覆盖：单篇准确笔记、多篇方法/实验证据比较、找适用限制或冲突、引用定位、无变化复用、单篇作者修订后局部更新、撤回许可、阅读过程中来源变化。缺少可核实修订版时明确记录暂未开展。
- 效率重复测量在任务内配对，轮换各组顺序，记录 API 缓存命中/未命中和网络耗时；统计单位保持任务/项目，不能把重复运行当独立研究样本。

## 科研质量与成本判据

评测前固定逐字段量表：研究主体、方法、实验/发现与单位、适用条件、限制、出处、连续支持片段、未报告项的诚实缺口。独立审阅原文与工件，尽可能隐去执行路线；至少对重要论断做人工核对。模型打分、结构检查和 Codex 来源复核分别记录，不能充当领域专家盲评。

先明确可接受的重大错误和缺口规则，再比较通过该规则的交付；同时公开未通过率和修复成本，不能将失败任务从平均费用中删除。计费保持逐请求账本，学习/认证、首次使用、稳定使用、失败恢复、审阅和人工修订分别报告，再算实际任务分布下的总成本。代理固定价格与账单实付区分。

此阶段的推进门槛：来源与许可变化能正确失效；独立材料中科学支持误判能被发现；同质量下 Motif 相比缓存/脚本仍有可重复的收益或更低维护负担。若后一点不成立，产品优先采用缓存和脚本，缩小 Motif 的研究主张。
