# Script 回执传输：独立 main 修复

本改动只修复合法回执在原生 Bash 输出截断前丢失的问题，不包含对应关系学习、中间集合采集、解析器质量认证或防重写提示，不主张端到端降本。

## 问题与改动

stdout 的 16,000 字节上限不能保证整个 JSON 回执小于 Bash 结果限制：控制字符等会在 JSON 中扩张。原论文实验另有 78,862 字节回执被裁至 50,000 字节的真实失败；该次实验依赖尚未进入 main 的集合采集，本 PR 不把那些依赖一并带入。

基于 main `62cb9787`，新增 `bounded_zlib_v1` 认证标记。认证器在原来源及另一独立输入上分别执行明文和压缩协议，核对解码后的全部回执一致，才标记可用。当前 Runtime 仅在显式 `compactContext:true` 且标记有效时产生压缩信封；其余明文路径保留。旧冻结库的代码锁继续失效关闭，迁移须实际重认证，不能补 hash 绕过。

编码后 payload 至多48,000字符，解码至多256,000字节；校验 SHA256、UTF-8、确切信封字段和非嵌套收据。原 stdout16,000字节、输入版本、session/call/nonce、单次 grant、权限和沙箱守卫不变。解码后模型获得完整 stdout，即使可读结果比压缩信封更大，也不能把编码数据当作模型证据。显式 cache/network 参数路径保留原协议；HTTP 取证需求仍以原 demand 返回。

## 验证与边界

- OS 沙箱可复现：stdout约10KB的控制字符输出，明文 JSON 回执超过50KB，压缩信封低于48KB，解码与原回执逐值相等。此为合成传输诊断，不是论文或费用成绩。
- 定向覆盖损坏摘要/非法base64/解压扩张/嵌套信封、HTTP demand、可读投影变大、旧明文路径，以及既有版本/单次授权/失败回退检查。
- 沿原历史来源重认证冻结程序池，保留原ID、模板及描述；认证输出放私有同名.local，不更新生产或旧库。
- 定向40项通过；全量Python1519通过/235跳过，Node1372通过/15跳过/1失败。网关大上传ECONNRESET在原样main独立诊断亦8/9，同一错误，未修改网关或移除有效测试。smoke/motif:check通过、0模型。原始日志私有保存；跨平台行为由CI确认，不因本地通过宣称Windows支持。

本轮没有新增模型请求，没有重跑Baseline。沿用累计6,697请求/USD12.048783156保守代理估费（未知13、pending2保留）；本地计算和开发未货币量化。后续候选失效与净收益验证分开记录。
