# 跨部署会话恢复与双用户连续对话验证

- 日期：2026-10-14；代码分支：`codex/persistent-chat-recovery`。
- 基线：main `6ade286`；部署实现：`373eaddf333fbe88adb1b018581ff313aacfe527`（含 `5e1ecbe`）。后续文档提交不改变实现。
- 目的：修复升级后旧会话第二次发送报 `Session is outside this Web run`，验证独立账号并发、连续对话与后端重启恢复。

## 根因与修复

历史 DSH 会话保存在账号 Home，Web 归属记录却随部署 output 改变；因此界面能显示历史，而任务入口拒绝续聊。修复将归属绑定持久 Home 与可信 principal，并只从明确配置且匹配同一 Home 的旧目录导入。

首次旧会话实测还发现 Harness 在第一轮后锁定 preset，旧 preset 没有新版工作区工具，直接应用新版工具白名单会失败。最终实现为跨旧 output 迁入的会话保留上下文、限制为文字续聊并禁用工具；不修改锁定配置。当前目录内正常重启保留原工具能力。新文件或场景工具任务要求新会话。

成员不继承所有者迁移目录。归属迁移不迁移额度、不重放历史任务；既有预算后端一直运行，未因部署重新初始化累计支出。

## 部署与边界

正式隔离部署检出已更新到 `373eadd`，所有者前端仍为 33102、账号网关仍为 33101，公网入口维持原 workers.dev 地址。停止旧所有者进程后用保存的启动配置正常启动新进程；保留账号、DSH Home、工作区、任务 output 和持续运行的预算后端。网关运行的是同一最终版本脚本内容；最终提交相对上一提交未改变网关脚本。
