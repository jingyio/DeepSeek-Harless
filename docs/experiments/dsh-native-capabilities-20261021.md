- Native BasicCompactionEngine 保留压力选择、工具配对、原始日志与检查点；摘要经过原计量入口。公开 `/compact` 映射当前真实执行侧，并等待上一任务计量关闭。File SDK 自己已有压缩，公开投影仅在内容完全等价时接受替换。
