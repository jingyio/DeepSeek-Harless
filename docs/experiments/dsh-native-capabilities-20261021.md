## 实现与边界

- 原生 read/read_image/write/edit、glob/grep 使用本会话的逻辑 `/work`，输入原件只读；Linux逐级不跟随链接的文件描述符与原命令沙箱保持一致。实际模型工具仍是上游实现。
- Native BasicCompactionEngine 保留压力选择、工具配对、原始日志与检查点；摘要经过原计量入口。公开 `/compact` 映射当前真实执行侧，并等待上一任务计量关闭。File SDK 自己已有压缩，公开投影仅在内容完全等价时接受替换。
- 原生临时故障重试沿同一任务，不重跑工具副作用。区分提供商429与真实预算拒绝，保留未知用量。网络取消使用独立传输原因，避免 Undici 改写原生取消事件。
- 提问由真实用户回答；空白补充文本不会否决原生计划批准。任务清单、锁校验后的 ppt-master 技能与带SHA的原生 present 接入现有交付下载。
- 子 Agent 为同任务原生前台子进程内运行，继承模型、工作区、工具权限、计量与取消；不允许跨任务后台续跑。`/plan`、显式 `/goal --rounds N 目标` 走普通任务准入；不推断 Goal 授权或使用隐式轮数。File 独立SDK不假称支持主聊天模式命令。
- 原生 Workflow worker 明确不是安全隔离边界，未将模型JS开放到宿主机。File逐字流通知尚未安全接入；其SDK持久化事件继续展示，不能声称已实现逐字delta。
