# 科研数据分析与报告 Agent v3.1 实验记录

## 问题、数据与对照

本轮验证：LLM 批准统计方案后，统计执行、复核、证据整理能否像绘图及排版一样，由经过真实轨迹认证的 Motif 连续发起，从而减少模型请求。假如三条统计边缺少独立见证、绕过了语义判断或出现错误绑定，就不支持这个机制。

实验 ID 为 `research-report-agent-v31-20261010`。CSV 为脚本生成的合成数据；模型为真实 DeepSeek Flash，Harness 为真实 DSH，工具通过真实 stdio MCP 执行 pandas/SciPy/statsmodels、matplotlib、ReportLab/PyMuPDF。没有把合成数据解释为真实科研发现。

先用材料比较、算法配对比较收集两个正常 DSH 训练轨迹，再以环境关联任务独立认证。四个留出任务分别是生物量自动大纲、教育前后测指定大纲、能耗一页简报、环境技术分析，各做两组、各重复两次，共 16 次正式评测。独立任务数是 4，不是 16。实际种子、执行顺序、公共授权及命令见 [benchmark 说明](../../benchmarks/research_report_agent_v31/README.md)。

普通组与 Motif 组使用相同数据、题面、工具 schema、模型及上限；均关闭模型重试插件、压缩和工具结果裁剪。基线是相同实验配置的 DSH，不是出厂默认配置。两组自行选择统计方案、图表结构并写正文，故不是将同一份固定报告逐步回放。人工定义工具能力和权限边界；10 条入库边来自两训练、独立认证的真实成功调用。03–05 的 3 条统计边均获得所需见证，未手工补库。

## 配置、证据和复现

运行底座为提交 `2368235f274329be6227a8393b850633cb943da4` 加上本次提交的 benchmark；Linux Python 3.12.15、Node 22.23.3、DSH 0.1.5-rc.3。benchmark 依赖见 [锁定版本](../../benchmarks/research_report_agent_v1/requirements.txt)。模型 `deepseek-flash`，thinking 禁用，reasoning effort 为 off，单次最多 35 个请求、单次输出最多 6144 token，正式矩阵串行执行。旧 manifest 未能读取 SDK 发行包版本的字段保持 `unavailable`，不追改原证据。

输入与代码哈希、逐决策 HTTP/SSE、工具事件和凭证位于本机忽略目录 `.local/research-report-agent-v31-20261010/`；原始日志和密钥不公开。公开目录包含 [全部报告及 PDF 哈希清单](../../benchmarks/research_report_agent_v31/results/20261010/README.md)，保留失败及不合格结果。代码与原运行快照的发布核对见 [发布审计](../../benchmarks/research_report_agent_v31/PUBLICATION_AUDIT.md)。只靠公开的汇总和 PDF 不能独立重算全部 HTTP 级证据；新克隆可离线检查工具，若要重收真实轨迹，需要自己的密钥和费用授权。

## 结果与质量

| 指标 | 普通 DSH | DSH + Motif |
|---|---:|---:|
| 正式运行数 / PDF 交付数 | 8 / 8 | 8 / 8 |
| 真实 LLM 上游请求 | 143 | 62 |
| 工具调用尝试 | 135 | 134 |
| 成功 MCP 工具执行 | 112 | 112 |
| 业务拒绝 / schema 错误 | 21 / 2 | 19 / 3 |
| 经凭证核验的 LLM 绕过 | 0 | 80 |
| 高峰价估费（人民币） | 0.72016560 | 0.61217400 |
| 离峰价估费（人民币） | 0.36008280 | 0.30608700 |
| 科学文字评审合格 | 7 / 8 | 6 / 8 |
| 运行耗时合计（秒） | 462.05 | 378.00 |

Motif 的 80 次已验证绕过包含统计段 24 次；真实工具仍然执行，绕过次数不能加在工具次数上。正式运行 LLM 请求减少 56.64%，高峰估费减少 15.00%。两组质量及任务构成不同，不能由此宣称已经证明等质量降本。科学评审由独立 AI 逐页完成，非盲评，也非人类领域专家认证。

三个重大科学解释问题原样保留：生物量 baseline r1 对可检出效应与实际意义作无依据排序；技术分析 execute r1 比较不同单位的斜率区间和残差标准差；技术分析 execute r2 把未验证的精度收益表述为当前证据直接支持。技术任务两次 Motif 报告均未通过科学评审。另有两份最终聊天回复遗留模板标记，PDF 本身没有这些标记。

16 份正式 PDF 共 40 页，3 份准备 PDF 共 7 页，全部逐页检查。16 次正式运行各调用一次排版工具；合计尝试 64 个工具内部确定性排版候选，没有 LLM 排版返工。报告没有为发表而人工修改科学内容。人工编辑修复时间未计量；开发时间和独立评审服务成本未纳入 API 估费。

## 成本口径与限制

| token | 普通 DSH | DSH + Motif |
|---|---:|---:|
| 输入缓存命中 | 1,779,840 | 598,400 |
| 输入缓存未命中 | 116,230 | 110,967 |
| 输出 | 52,064 | 45,788 |

两条训练和一条认证共 50 次请求，高峰估费 0.23453344 元，输入命中 587,136、未命中 41,076、输出 16,112 token。这里的“训练费用”是收集和确认工具轨迹的模型调用费用，不是更新模型权重。

本轮准备加正式共 255 次请求、1.56687304 元高峰估费。纳入旧版开发、失败、校准后的累计为 1,419 次请求、7.42098712 元，历史授权预算为 100 元。本次发布没有新增 API 调用。费用由代理按固定价格估算，不是供应商账单，重试和失败均未从分母删除。

本轮 8 次 Motif 执行加准备成本为 0.84670744 元，高于对应 baseline 的 0.72016560 元；按观察到的单次差额估算约需 18 次执行摊销准备成本，但这不是等质量摊销证明。需要扩展独立任务、专家审阅与实际修订时间测量，才能判断实际科研使用的总收益。
