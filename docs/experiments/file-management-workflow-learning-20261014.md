## 免费执行与失败保留

免费程序在独立认证材料的新副本上重放原模型实际选择/预览，由现有TS控制器提出后续调用，再经真实MCP执行。完整集合实际自动调用7次pin、7次read及一次collect；计划实际自动调用一次authorize和一次execute，字节与独立条件一致。它们验证执行协议，0云请求，不能当模型成本收益或训练轨迹。

8项检查为集合正常、输入版本失效、Schema失效，以及计划正常、输入版本失效、Schema失效、权限撤销和真实中断。失效不提出后续动作；撤销在授权工具侧拒绝；MCP退出75后计划控制器停止，未自动重试或restore。重新连接同job时requests/steps/spent/repairs/pending/status/limits不变；固定免费程序用原授权撤销已记录边界并核对初始字节，该撤销不是学得的动作。

首次中断辅助脚本误将裸stdio客户端当作Harness原生客户端复用，已关闭连接上的再次读取失败。保留原部分执行副本、日志和0云费用；修订程序关闭旧传输、重连新副本验证，未更改产物、候选、共享控制器或MCP服务。最终8类检查通过，实际免费尝试9次、原失败1次保留。修订重放源码及SHA单独归档，原付费frozen-source不回写。

10次模型任务有9次工具错误，包括范围/路径、集合汇集及中断连接等拒绝/纠正，全部计费保留；没有新增模型任务验收失败。旧两个恢复失败、旧集合拒绝与所有历史费用保留，不能只汇报最后成功调用。
