先验证真实网页上传、发送、双路运行、可下载产物及刷新保持，再对原样成品核查页数、备注、可编辑对象、实际渲染、来源数据与图文对应。只读渲染前后核对 PPTX SHA，不将检查器通过冒充科学质量通过。若少请求但总费更高、事实或视觉错误增多，明确记录反例，不宣称同质节省。

编译使用既有 Python witnessed-edge 机制及 TypeScript 在线运行时，至少两个独立训练决定和一个独立认证。原始事件不重写、不从助手脚本伪造工具轨迹。失败、重试和诊断费用全部保留；编译没有模型调用。开发与人工评审时间、CPU 成本和账单实付分别说明，不隐含为零。

## 接入与训练结果

已完成新工具入口、独立只读技能安装、命令沙箱依赖接入和结构训练。上线前发现跨语言 JSON Unicode 摘要编码与隔离网关插件路径问题，已修复；这些启动诊断没有模型调用。注册测试须等待网关就绪，避免离线邀请码生成与启动并发。

首轮三次完整 Baseline 制作均交付，但 `read_skill_entry → read_pinned_routing` 的同一常量句柄被现有编译器以“constant values do not prove transferable parameter flow”拒绝。没有修改编译器或手填图。三次共 292 请求、代理估费 $2.25337919，列为排除采集，保留原轨迹及成品。

第二轮将技能入口、归属检查、路由与上传清单合并为普通工具。模型选择真实论文、绑定当前版本并读取首页后继续完整技能制作；三个 PDF 与问题各不相同。两训练分别 75 / 74 请求，留出 112 请求，均 completed，生成 PPTX/PDF/逐页预览。261 请求、代理估费 $2.08351181。合计采集 **553 请求、$4.33689100**，未核服务商账单，开发人工及 CPU 未计价。

Python 既有 witnessed-edge 编译器生成一个 `pin_source → read_source_page` 首页面读取结构，无脚本节点。编译零模型调用，约 1.04 秒。库摘要 `5a7ec5c37f071a20d3db58dfc311939bda69db5cf0332907d9adab31cf4f710f`；manifest 摘要 `b45b15357d131211d947babc24fcd54637880ce2466d6c9b2a220ec881e7c504`。`quality_cost_promoted=false`，只认证参数流。完整实际 MCP schema 为三个工具，另有六项共同能力；原始轨迹和账本在私有 `experiment-sources/`，原被拒绝版本在 `experiment/`。

两侧普通环境优化：关闭不能跨命令保持的额外 HTTP live preview（上游允许的 run-instructions 分支），保留真实 PDF/PNG；将命令 `/tmp` 绑定到会话独立目录，保留跨调用检查报告与缓存；技能、字体与渲染器只读挂载。它们不算 Motif 收益。第二轮采集与最终对照使用同一提示，未逐页介入、未改产物、未反馈具体修订。

共享实现变动后，Paper v7 用原 v6 的两训练/一留出冻结事件重编译兼容证书：图结构、来源证据、工具表不变，新增采集和模型调用均为零。旧 PPT/Paper 目录原样保留；回退要求旧代码与旧证书配套。

## 成品质量与边界

只读、非盲评审：检查两份原始模型 PDF 的全部 12 页、PPTX XML 与备注，核对源论文第 6–10、16–17 页。不是独立人类盲评，没有把机械交付成功当成科研质量通过。原始 PPTX 未修改，缩略图只由原 PDF 渲染生成。

- 两版均为 16:9 六页、含六页备注、原生文字与公式；没有嵌入原论文图片，原图优先要求未充分满足。GLUE、SQuAD 和 XSum 主要表格数值与原文表值一致。
- Baseline：第 5 页方法/预算列与 MNLI 列文字重叠，第 3/4 页模型 PDF 公式横向拉伸；第 2 页 Figure 1 简化为无原数值的条形示意。第 6 页训练开销照录正文 SQuADv2.0，未指出正文与 Table 15 的 SST-2 标签冲突。
- Motif：整体布局较整齐；第 3 页将重要性 s(w) 标成单独的梯度乘权重，混淆它与平滑敏感性乘不确定性的关系；第 5 页热图重绘去掉原单元数值与色标、标签紧贴网格；引用仅图表号，缺题面要求的 PDF 页码；将低预算增益概括到所有任务，忽略原文 XSum 的不同趋势。
- 原文第 6 页确实写所有增益通过 p<0.05 检验，不把 Motif 的这句复述误判为无来源。原文第 9 页 XSum 基线正文与表格有冲突，两版采用第 8 页表格值 20.20。

两版均不满足无需进一步复核的科研交付门槛。一次非盲、随机生成对照不能将视觉差异归因于 Motif，也不能证明可泛化降本。人工审阅时间未独立计时，开发/CPU 未计价；修订次数为零，未以人工修稿改善分数。新库只认证首页面读取结构，不认证内容、科学结论、整份 PPT 或总体成本。
