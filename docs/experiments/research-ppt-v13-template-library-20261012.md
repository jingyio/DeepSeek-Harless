## 1 / 数据集与真实任务

工程生成任务是同一公开 VeRA 原始 PDF（arXiv:2310.11454v2，21 页，SHA256 `b91f11fc716e3dae85ed7954e11a7e3c93cce93cbd4c7bde243735c44426c7ab`），分别生成八页中文科研汇报。要求覆盖方法、原图、实验结果及条件、局限、页码来源、notes 和可编辑正文。模型重新读取原论文并选材，未把 V12 计划换皮当新生成。

训练/认证/后续评测划分为两个不同来源的VeRA与LoRA真实任务、一个独立IA3来源任务、一个后续Prefix-Tuning任务。修订续写和同任务重跑不计为独立任务。认证资料与模型训练包物理隔离；训练成功后由原认证器读取一次留出，未按留出结果修改源码或协议。20/10是来自2/1个真实任务的状态及派生检查，不是30个真实任务。后续四页评测的两组统一使用三种较短页型，这是相同的工程条件，不计为RSI学习能力。

## 2 / 模型在哪里做决定，程序在哪里执行

主链继续使用 Harness 的 Agent 循环与预算代理，私有 TypeScript stdio MCP 固定七工具，顺序为 `read_reference`、`list_templates`、`save_plan`、`read_page`、`write_page`、`revise_design`、`export_deck`。Python 只执行固定上游编译和独立交付验收。没有修改 Harness 核心或复制另一套 Agent 循环。

| 环节 | 责任主体 | 本轮边界 |
|---|---|---|
| 阅读原文、选材、跨页叙事、模板选择 | DeepSeek | 科学判断与文字取舍仍为语义步骤 |
| 短计划及当前页契约读取 | DeepSeek 调用 MCP，服务返回冻结状态 | 计划页数/来源/模板明确，当前页才展开 slots 与容量 |
| 文本/图件绑定 | 公共 TypeScript `registerTemplate` / `bindTemplate` | 几何与字体不可随意改；未知slot、缺项、超容量、非法图片和摘要变化拒绝 |
| 页写入与局部修订 | 私有 MCP 版本/来源/目标页守卫 | 要求当前读取回执和旧 SHA；非目标页保持；科学内容不由字符串规则证明 |
| 编译、交付与渲染 | 固定上游 checker/finalizer/compiler + `validation.py` | 真实 PPTX/PDF/PNG，文字保留、字形和页面几何检查；不等于科学/审美认证 |
| PNG审阅及科学错误反馈 | Codex 辅助审阅与文字反馈、DeepSeek 修订，另有记录的辅助改动 | DeepSeek 本轮没有视觉输入；不称自主视觉闭环 |

公共实现是 `scenarios/research_ppt/ts/template-library.ts`、`scenarios/research_ppt/template-library.schema.json`、素材索引和相关测试。七工具场景服务、任务准备、打包及 RSI 插件仍在私有实验目录；公共绑定器存在不等于正式分发的完整七工具产品。测试通过、真实导出和真实任务稳定性分别报告，不能互相代替。

## 3 / 与普通 DSH 流程及 RSI 的比较

V12 的自由 SVG 让模型直接安排全画布，但布局恢复成本高。V13 普通模板链将版式实现交给确定性素材与绑定器，减少自由创作范围；这属于普通工程/B1优化。V12 与本轮页数、工作流及辅助修订不同，不能直接把两轮总费用差写为公平降本百分比。

RSI 的目标进一步缩小为一个只读决定：首次成功保存完整计划后，按页序读取尚未写入、尚未读取的页面契约，最多四页。历史 Warm 的下一独立请求实际读 1–4，LoRA 实际读 1–2，再独立读 3–4。因此“充分取最多四页”是新工程批次策略，并非全部历史动作的逐字复现。

历史守卫先于候选运行：只允许真实 LLM 合法 `read_page` 因本 job 的 `plan.json` 尚未创建而产生的精确 ENOENT 成为 soft；第一次成功保存完整新计划、此前无任何写入尝试/修订、全部来源/模板/schema/依赖核验且无 hard 历史，才能恢复。未知错误、权限/版本变化、自动失败、未知来源、写入/修订及重复成功 save 永久停止。守卫是手写普通工程，不是模型自动发明的 RSI。

独立参考器与抽取器各自重放原始 Harness 调用、付费 assistant 来源、参数、call/result ID 和回执。模型只读两项固定训练的六文件包，不能读 reference 源码、expected 或认证资料。候选通过现有 [`generated_tools.py`](../../scenarios/research_ppt/generated_tools.py) 的 AST 白名单、strict 编译、受限 Node 执行和一次独立认证后，才有资格在新任务调用。

在线若成功，仅在所选 read 回执及完整后置状态核验通过、确实替代整次模型请求时记 `model_requests_skipped_verified`；自动工具数另列。该生成程序目前不是正式 Motif IR/library，没有 Graph 自动发现/参数流编译/正式库发布。人工根据训练负证据选择范围并多轮修正发现提示，模型生成程序，属于有界的 Code RSI 试用，不能称全自主结构发现。

人工脚本/B1可以执行相同批次规则；本轮没有证明 RSI 比同规则手写程序更省。需要比较后续合格端到端成本及学习投入摊销，而不是将工具封装、缓存或每个自动 read 计成一次模型请求下降。
