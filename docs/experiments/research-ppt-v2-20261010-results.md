## 问题、假设与实现边界

任务是将用户提供的 PDF/PPTX 变成有来源、可编辑且可审阅的科研汇报。比较普通 DSH 逐步发起工具、普通组合工具与认证 Motif，检查局部模型调度旁路是否能降低同质量交付总成本。缺失主要结果/局限、事实错误、失败和增加的修订都可能否定收益；不能只比较请求数量。

目前已经实现 1–8 份输入、1–30 页要求、两种内置风格、原生文字/表格/bar 与 line 图表、论文原图或图注区域提取、已有 PPTX 的受限副本修改，以及真实 LibreOffice → PDF → 逐页 PNG 核验与交付。主要接口和命令见 [场景 README](../../scenarios/research_ppt/README.md) 与 [接口](../interfaces.md)。论文原图仍为位图，不能称为原生可编辑图表；OCR、任意母版、动画保真和复杂嵌入媒体未验证。

LLM 负责选材、论文理解、比较、叙事、科学解释与语义修订；Code/MCP 负责解析、版本固定、素材绑定、PPTX 生成和真实渲染。`build_delivery` 是普通组合脚本，不是学得的 Motif。认证 Graph 当前只有 `pin_source.source_id → read_source.source_id`，`code_nodes=[]`；它跳过固定来源之后一次句柄抄写/读取调度请求，仍执行真实读取工具。未把生成、核验和交付长链蒸馏成新 Motif，也没有模型自主生成的新工具。

## 失败诊断与修复

先前 demo 与首轮会话错误包含 HTTP 429。对应转发账本均为 200，没有 DeepSeek 上游 429 证据。最终估费加上一请求的保守预留超过本地上限，间接支持本地预算代理拒绝；未保存拒绝响应正文，记录为 `likely_local_budget_gate`，不能宣称已观察到上游限流。第二轮提高运行守护上限，保留旧失败与费用。

黑图根因是丢弃 RGBA 的透明度；即使恢复透明度，片段也只是阴影，不是完整论文 Figure。V3 白底合成透明度，过滤纯/近纯色素材和 PDF 遮罩片段，按真实图注几何裁取完整图。真实原图及 1 页交付已目检，4 项图片回归通过；原 R1 成品与结论未被改写。复杂跨页图仍需审查。

另对真实的 15 页、2 张图片、4 个表格的辅助修订稿做无模型 stdio MCP 转换，文字/表格/图片数量/notes 保留，真实渲染和程序交付通过。目视发现初版 `restyle` 未改变普通标题及已有装饰色，而且把深色表头白字改为深字；此反例保留。V4 修复已晋级场景：受限识别标题、转换已知装饰色与表头色，按背景保留文字对比，并核验原 notes 前缀、布局几何、媒体/原生图表及嵌入数据保留。模糊标题和未知用户底色不强猜；不承诺任意母版、动画或 SmartArt 保真。V4 不混入 R2 冻结行为或收益。

最终审查另发现交付前未重新核验 PDF/PNG 的缺口；已补充缓存 `validate_deck` 与 `deliver_deck` 的预览 SHA 守卫，替换、删除和越界路径均拒绝，恢复原文件后可交付。该补丁的真实渲染回归在服务器完成；没有改写旧运行。
