## 问题与设计

验证普通 DeepSeek Harness 的真实调用能否产生带条件分支和可变长度循环的 Motif，独立认证后在新任务复用，以及已选择的跨工具调用能否按真实参数、收据和产物认证。不能把固定页数链、手写路由或模拟模型成绩称为该能力。

使用本机新建、带唯一标识的 PDF 和文本材料，真实模型实际阅读与编辑；这是受控构造的文件管理任务，不代表用户自然分布或生产实测。每份任务包含两份不同页数的 PDF，非末页和末页设置不同文字层空白情况，形成继续/终止与空白/非空的组合；精确修改备忘录，生成新文本产物，保全原输入。不是新科研结论、图片语义或任意代码业务的质量认证。

两份普通任务提供原生训练轨迹；自动队列安排全新材料的原生认证及两次实际候选执行，每次须覆盖所有候选分支和出口。后续任务用新材料验证实际检索与复用。未传 `profile_id` 或指定正确模板，始终使用同一长期经验库；旧最终留出集不参与学习。后续日常轨迹可以继续被学习，不将其宣称为永久封存基准。没有人工盲评、冻结库随机对照或稳定净收益结论。

完整阅读候选的混合任务原生认证曾因额外跨工具失败而拒绝。随后增加一份**独立的纯阅读业务任务**，提前冻结两份 PDF 全文、memo 完整读取及三份原件保全；其新轨迹自动触发同一旧候选按当前源码重新认证。原混合失败不追改，原混合后续任务及精确编辑验收不修改。该阅读候选在新原生材料与两次独立实际执行通过后激活，两次实际执行各8HTTP、14次验证续接，动态路径分别7和9调用。

同一当前库保有两种循环起点：`read_document_chunk` 的2状态/5边和 `open_document` 的3状态/6边。每个候选有两个独立实际认证，所有条件/出口均从原始结果重算。null/非空句柄与空白/非空文字层的四种组合分别有证据；两个带条件的自循环边不等于两种业务循环。一个**无任何回退的独立完整认证任务**还实际观察到 memo 交错，完整执行验证通过。

最后的同批诊断确认两次 open 和 memo read 来自同一条真实模型工具调用消息，调用顺序亦吻合；两个完整文档路径8/11调用逐步重放通过，备忘录读取在两个活动根间保留。该任务随后出现另一项 `prepare_tool_call`，顺序编辑图在此未知交错处回退，因此仅阅读组件验证通过，**整个任务不作为新的无回退认证证据**。保留原 `verify_operation_execution` 的整任务无回退要求，未把失败字段清空重算。

另一份定向混合任务虽然完整循环、精确产物和程序验收通过，原始轨迹显示 memo 在循环后才读取，未满足要求的同批时序，单列为时序反例。当前日常质量谓词能检查文件与全文覆盖，不能代表任意自然语言时序也已验证。顺序 prepare/execute/inspect 链已独立认证并在新任务实际复用；同时存在多个准备请求的更广并行流程仍由普通 Harness 处理。

本轮自动学习及历史维护共留下22份激活回执、13份拒绝回执，跨源码阶段及历史变体计数，不是不同能力数。旧集合图在新目标中失配后自动停用；出现新的合格材料后，维护队列重新独立认证新版本，原失败和旧签名保留。最终同一长期库 v121，当前源码兼容7项，其中2项为循环起点、5项为操作图；包含变体，不能称为7个独立 MCP 场景。
