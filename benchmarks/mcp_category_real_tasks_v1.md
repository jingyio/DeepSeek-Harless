# 六类 MCP 的真实场景任务册与效果判定 v1

2026-09-28 建立，2026-09-29 更新。状态：**六类真实连接器均做过只读操作检查；Zotero、Obsidian 和文献发现已有应用内普通 Agent 试跑，本地数据／Quarto 已有脚本基线，Gmail 已有局部配对，日历有合成测试日历上的同题普通／Motif 在线试跑但未净省钱；六类的同题 Motif 合格交付效果对照仍未完成**。完整质量与成本判断见[六类应用内实测总判断](../experiments/六类MCP应用内实测总判断_2026-09-29.md)。首批数字见[实测记录](../experiments/应用内普通Agent首批实测_2026-09-29.md)，[本地数据脚本基线](../experiments/本地数据Quarto应用内脚本基线_2026-09-29.md)、[日历在线续测](../experiments/日历Motif跳轮续测预览_2026-09-29.md)和文献题[预览及已完成试跑](../experiments/文献发现应用内普通Agent任务预览_2026-09-29.md)。本册按当前六个连接器分层诊断 SSS 的结构执行，不把连接器类别当作六个彼此独立的产品场景。最终产品主线仍是[跨应用科研决定](research_weekly_loop_v1/task_generation_protocol.md)，而类内小任务用于定位哪一种参数边、版本守卫或语义交接真的减少了合格交付成本。

真实连接器的首轮无模型、只读操作检查见[六门类应用内试跑](../experiments/六门类真实MCP应用内只读试跑_2026-09-28.md)：五类操作链完成，文献发现的 arXiv 搜索返回服务不可用但已知编号读取成功。它是工具合同验收，不是本册的 Motif 效果成绩。

## 共同实验口径

每类先收集至少 **3 个独立的真实决定／工作请求**：前两项的普通 Agent 轨迹只用于发现、编译和认证可执行的局部 Motif；第三项事先封存，做留出试跑。同一决定的改写、增量轮次、不同论文段落或同一邮箱请求的重复访问不算新实例。首轮不足三项时标为开发诊断。类内比较可以找到机制故障，但不能代替跨类、跨应用的完整决定测试。

每项冻结两个分开的包：Agent 可见的真实目标、来源范围、权限、时间、预算及交付要求；评审封存的来源版本、必要证据、重大错误、工具机会和后续真实事件。资料留在原应用；私人正文、账号、原始轨迹和账本只放 `.local/benchmarks/mcp-category-real-v1/<task-id>/`。先做元数据预检，再由研究者圈定可读范围；不为了任务数量制造论文、批注、邮件、会议或数据。公开题录查询按原服务记录时间与版本。

同题至少设：A 普通 DeepSeek Harness（合法原生命令与全部授权工具可用）；B 静态预选相关工具或简单脚本／版本化缓存；C 同模型、同来源范围的在线 Motif。必要时另列 `research-workflow + 同一 Agent` 作研究主线强基线。所有后续 DeepSeek 会话显式使用 `reasoning_effort="off"`，稳定模型、提示前缀与工具 schema／顺序；不把既有思考模式记录改成新配置。运行前预览每臂模型请求上限、美元上限、对外摘录和可能写入；无预览不得发起付费或修改用户文件的试验。

先由领域研究者盲评“完成真实决定／工作请求”的质量、证据定位、重大遗漏、误判和人工修订分钟数。只对合格交付再比较逐请求缓存命中／未命中／输出 token、**核账后的费用**、模型请求、重试、人工和端到端时间。逐节点记录 `可用→暴露→调用→成功→用于决定`、被 Motif 接管的真实请求、守卫成功／拒绝、版本失效和语义交接。API usage 的本机价格估算单列，不称实际账单。对一个类没有可跳过的完整请求，也要记录这个负结果；工具调用减少本身不构成收益。

## 类内真实任务候选

表中是研究者已有资料所支持的**候选问题**，不是已经完成或预写给 Agent 的执行路线。每一行还须补独立实例 ID、真实请求时间、读者、来源范围与评审包才能进入确认性试验。`待事件`表示当前没有足够的真实工作事实，不以合成事件补齐。

| 类别 | 可优先冻结的真实请求／决定 | 可观察的结构片段与必须交接处 | 当前就绪程度 |
| --- | --- | --- | --- |
| 文献发现（arXiv／OpenAlex／Crossref／Europe PMC） | AIDD：新论文是否改变 SAR-Diff 对照或泛化划分；Model RSI：是否已有内部状态与检索记忆的直接可比结果；serving：六篇候选是否真的构成缓存基线的反证 | 题录 ID／DOI→版本与开放全文定位可核验；检索路线、方法可比性与反证力度交给模型。检索结果变化时重验去重和结论。 | 三个方向已有公开来源或开发试跑；同题类内留出、研究者质量标签待冻结。 |
| Zotero | AIDD 论文的条目／批注是否要求收窄旧主张；Boltz-2 或 serving 论文批注是否改变一条已有研究判断；另一项目的新批注影响卡 | 模型已选条目后 `pin→read item/annotation` 的来源 ID、权限和版本边；批注的科学含义、与论文正文是否冲突交给模型。条目相似、批注新增或来源版本变动必须打断旧结论。 | 前两种已有真实只读轨迹及开发诊断；第三独立来源簇待定。Zotero 9 本机写入不可用。 |
| Obsidian | 恢复 AIDD 已否决方向后决定首个应用／split；恢复 Model RSI 当前 Idea State 后决定下周反证实验；serving 基线笔记新增实际判断时核对旧结论 | 精确笔记路径／批准摘录／版本可复用；旧否决是否仍约束当前决定、跨笔记冲突必须语义复核。新笔记或人的范围改动不能只因旧路径高频而自动沿用。 | 前两项有真实研究状态；第三项以实际新判断发生为前提。只读评测优先，正式写回另设审阅。 |
| 本地 Python／Quarto／结构化数据 | AIDD PBCNet2.0 的公开 SAR-Diff 数值复算与“配体重合不等于复合物泄漏”审计；Model RSI 若已有原始实验行，比较内部状态与等预算检索基线；serving 若已有原始运行记录，核对缓存基线及图卡 | 数据 ID→哈希→字段／指标→可重放计算→Quarto 可审阅材料；分母、口径和生物学／系统含义须显式交接。渲染成功不能替代数字正确。 | AIDD 有真实公开 CSV 及一次不合格试跑；后两项须先确认原始数据及指标定义，不能用合成表冒充。Python/Quarto 是同一连接器内两个环节，分别记调用与贡献。 |
| Gmail | 研究者已有论文提醒邮件：在限定标签／时间窗口内判断是否出现会改变当前主张的论文；真实合作者就某个已形成证据缺口的来信：定位线程并给出待审答复；收到真实回复后的决定更新 | 查询结果唯一且新鲜时可核验 `search→read` 的消息 ID；多候选、正文解释、收件人和回复内容由模型／人判断。草稿与实际发送分开记。 | 邮件提醒已有不同真实邮件上的只读跳轮开发结果，未独立盲评；合作者线程和真实回复待事件。现有 `send_email` 已合并准备与打开审核页，不能人为拆步制造收益。 |
| Google 日历 | 已有组会／合作者讨论需求时，核对指定参与者的真实忙闲并提出可行时段；收到真实改期请求后检查冲突并更新待审安排；真实会议时间变化后判断哪些准备行动需重排 | 已明确日历、时间窗、参与者后，`freebusy→候选时段核验` 可比较脚本和 Motif；时间偏好、邀请对象和是否建会交给人。时区、忙闲、权限或参与者变化必须打断。 | 专用测试日历的 A/B/C 初轮普通 Agent **0/3 合格**，加入确定性排期工具后 **3/3**；D 留出认证了调用链，E 在线 Motif 重试跳过一次模型请求但整题费用与耗时均高于普通组，见[日历在线续测](../experiments/日历Motif跳轮续测预览_2026-09-29.md)。仍无真实研究排期需求，合成事件不能冒充类内真实效果。 |

每类至少含一个“旧来源可安全沿用”的真实变化和一个“新反证／口径／权限变化必须打断”的真实变化，才能评价有界惯性；若自然事件没发生，只报告初始任务。历史回放、前瞻试用和合成回归分开汇总。类内候选不要求每题都调用该类全部工具；只计算事先登记且实际相关的工具机会。

## 首轮执行顺序与预览

### 早期合成现实任务方案（保留为机制回归，不作为本轮先行顺序）

现有 `research_decision_portfolio_v1/v2` 的 **18 题、六种科研决定**不是六个 MCP 门类的专项覆盖：它们把不同应用对象放在同一隔离服务里，只暴露八个通用只读工具。按 `sources.json` 可见，文献对象出现在部分文献／实验题，Gmail 对象只在 v1 三题出现，日历对象出现在 v1 三题和 v2 两题，Quarto 对象只在 v2 三题出现；对象出现不等于对应真实 MCP 的检索、读写、渲染或排期契约已受测。因此下一步先建**基于真实工作约束的合成脱敏夹具**，每类至少三项独立请求，统一保持实际连接器的工具 schema、关键返回字段、版本和错误语义；若 mock 与真实服务有差异，应登记差异并做少量只读合同检查。它们只证明机制和质量边界，不叫真实用户任务成绩。

| 专项 | 三种独立请求的首版题型 | 必须包含的反例／质量门 |
| --- | --- | --- |
| 文献发现 | 版本不同的预印本／正式版去重；论文被引链中找真正反证；开放全文缺失时决定是否暂缓判断 | DOI 缺失或标题近似不能误合并；新增反证必须打断旧结论。 |
| Zotero | 已批注论文影响一条主张；附件修订后重验旧高亮；两位读者批注相冲突时形成待核查缺口 | 元数据未变时可验证复用；批注或附件版本变化不能沿用旧科学解释。 |
| Obsidian | 恢复否决过的 idea；新笔记改变当前实验条件；无关笔记改动后重验旧决定 | 新人工判断不能被旧高频路径覆盖；无关改动不能导致全量重算。 |
| Python／Quarto | 从原始行复算有分母的指标；实验口径更改后更新表与解释；图卡来源修正后只重渲染受影响交付 | 方向、分母、单位和来源哈希必须正确；生成 HTML 不等于结论合格。 |
| Gmail | 唯一搜索结果读取并分拣；多个相似线程需选对象；有证据缺口的待审回复 | 仅唯一且新鲜 ID 可接管读取；不能自动决定收件人、正文或发送。 |
| 日历 | 真实风格的忙闲窗口建议；跨时区讨论改期；已有日程冲突后的待审安排 | 时间窗、时区、参与者与权限变化须失效；mock 不发邀请，不计真实排期效果。 |

每类先运行**普通 Agent**拿自然轨迹，从两项独立请求编译／认证候选，第三项封存留出；冻结后轮换留出。两臂使用同一任务、模型、工具契约和来源状态，另设普通脚本／缓存；不得只让 Motif 组看到更窄或更简单的工具。报告逐题重大错误、完整模型请求是否核验跳过、缓存计价费用和人工修订，并按“合格任务”重算。遇到无法形成可执行 Motif 的门类，结论应是当前方法对该类**未证明收益**，不改写题目去凑命中。

先做无模型的工具合同和版本失效预检。此后每类前两题各运行一次普通 Agent，共 12 次训练轨迹；留出题各运行普通与 Motif 一次，共 12 次配对试跑。**拟定**每次最多 15 个模型请求、US$0.50，24 次总闸门 US$12；若某类训练轨迹没有可认证 Motif，该类留出只运行普通组并报告“无可测试候选”，不为凑配对手写流程。实际调用付费 DeepSeek 前仍须冻结具体输入、版本、逐臂预览和总预算并得到确认。mock 不发送邮件、创建会议或改写真实 Zotero／Obsidian。

1. **现在可做的只读准备**：运行 `scripts/doctor-mcp.py --json` 核查六个连接器；从 AIDD、Model RSI、serving 及已有邮件提醒的元数据选出任务候选。已有试跑只能作为开发例，不回填为新留出。先核对旧答案的数值和证据错误，确定来源授权与外部模型可见摘录。
2. **先跑自然且有数据的局部任务**：文献发现＋Zotero＋Obsidian 的论文影响卡，以及 AIDD 的公开数据复算＋Quarto。冻结普通 Agent 轨迹后才能用前两项编译 Motif；第三项此前不得参与阈值调整。另设同权限脚本／缓存对照。Gmail 只读提醒任务单独计分，避免把论文提醒分拣当成科研决定全链。
3. **等真实工作事件才进入**：Gmail 合作者答复、日历排期与改期、Obsidian 正式写回。对外发送／建会及已有笔记的修改须在可审阅预览后由研究者批准；同题 A/B/C 共用一次真实外部动作，不重复触达他人。
4. **主线复验**：至少一个跨应用决定使论文发现、Zotero、Obsidian、相关原始数据复算与 Quarto 真正贡献同一交付。以[真实任务生成协议](research_weekly_loop_v1/task_generation_protocol.md)评审；类内节省不能外推为这个主线的收益。

首轮付费预览建议为：每个已冻结小任务每臂 **最多 30 次模型请求、US$1**，两臂配对最多 US$2；较长的真实跨应用任务逐项提高前先给出新的来源与预算预览。此数值是**拟设闸门，不是已获批准的运行或费用预测**。不向模型发送完整私人库；每项只开放任务批准的对象和摘录。除允许写入 `.local` 的草稿、分析结果和 Quarto 预览外，默认不修改用户资料或发出外部动作。

## 截至本册建立时的证据，不计作本册新成绩

- 2026-09-28 的只读连接健康检查：六个服务各有代表性探针通过，工具数为 10＋21＋19＋13＋13＋11＝87；DeepSeek Harness 当时未监听。探针不证明 87 个工具逐项可用，也不评价 Motif。
- [真实跨应用批注诊断](../experiments/跨应用批注影响Motif试跑诊断_2026-09-27.md)在修复后看到一次已验证的 Zotero 批量读取跳轮，但 serving 同题普通与诊断复跑均为 7 次模型请求，估费和耗时反而上升；且修复后组不能替代冻结对照。
- [AIDD SAR-Diff 试跑](../experiments/AIDD-SAR-Diff真实MCP试跑诊断_2026-09-28.md)虽为 65→34 次请求，却有 **0 次** Motif 核验跳过，且两组的证据边界错误使交付暂不合格；不能归因或称节费成绩。
- [Gmail 真实邮件开发试跑](../experiments/Gmail动态搜索锚点Motif试验_2026-09-28.md)已有搜索唯一结果后的只读读取跳轮及费用代理记录，但独立研究者未盲评相关性与答复质量；邮件 HTML 视图压缩是另一个优化，须与 Motif 单独归因。
- [六类合成科研决定](../experiments/科研决定组合质量门槛评测_2026-09-28.md)在共同可用的九题中观察到 77→45 次请求和费用代理约 20.5% 下降，但来源、邮件和日历均为模拟，质量核查也非独立人工盲评。它们是方法开发证据，不是本册要求的真实类内任务成绩。
