## 两次交付与真实增量

1. **A：当前状态。** 研究者确定决定和资料范围后，按同一快照运行各组。产出主张—证据账本、支持／反证／未知、论文与批注的来源定位、Idea Delta、一个可证伪的下一步及停止条件。生成材料须能区分论文作者主张、实测结果、批注、邮件说法和 Agent 推断。
2. **E：后来实际发生的事件。** 只在研究者真实新增或修订 Zotero 批注、Obsidian 决定、论文版本、邮件回复或实验结果时释放。保存原始发生时间和释放时间；不得把未来事件给阶段 A。若观察期内没有新事件，可使用**有真实时间顺序的历史记录**单独回放，绝不与前瞻试用混算。
3. 每次 E 记录旧主张和报告段落哪些复用、重验、失效或需要重新语义判断。新科学证据不能只凭文件哈希未变就自动宣告“无影响”。

## 同题对照与效果门

所有 Agent 组看到同一初始 Idea State、同一允许来源、同一事件释放顺序、同一生成模型、工具权限与预算；如工具能力不齐，单独记录而不归因于方法。先保存研究者不借助 Agent 的现有做法与耗时，再比较：

1. **research-workflow + 同一 Agent／模型**：按它自己的 Idea State、路线、论文卡、证据账本和每周综合流程执行。这是主基线。
2. **简单脚本 + 同一生成模型**：脚本只做快照、哈希、去重、数值复算和引文可定位检查；语义决定仍交给同一模型。
3. **通用 Agent + 同一模型及 MCP 资料范围**：自由多步调用，作为产品能力参照。
4. **SSS MotifAgent + 同一模型**：Motif 主控持有节点、参数流、依赖和恢复；只把确切语义缺口交给模型。单独消融局部复用和窄上下文／普通缓存。

两名领域评审盲评关键文献／反证是否漏掉、引文是否支持主张、任务／split／量纲是否混淆、旧否决是否被无据复活、Idea Delta 与下一步是否可执行。重大事实错误、虚构引文或无依据大转向为不合格；争议由第三人仲裁。只有**合格交付**才比较总成本。并列记录：人工核查与修订分钟数、研究者是否采纳、实际模型请求及缓存／非缓存 token、账单费用、本地计算、端到端时间、增量复用／失效和错误跳过。DR³-Eval 中文 003 与合成办公资料仅用于回归和预检。

## SSS 机制如何在此受检

| 操作类别 | Motif 可自行执行的证据 | 必须退级的边界 |
| --- | --- | --- |
| 结构操作 | 已授权来源 ID／版本、哈希、论文版本关系、已验证参数来源、相同输入的确定性 Python 复算 | 来源变化、权限变化、工具失败或输入缺失时停止，形成失败凭据 |
| 半结构操作 | 经研究者确认过的“主张—证据”映射和引文位置在本轮快照中仍可逐项重验 | 新批注、近似论文、冲突结果、映射范围不明时交有界 Jev／DeepSeek 判断或人工 |
| 语义操作 | 无结构跳过授权；模型只收到已裁剪、标识清楚的候选和当前问题 | 新颖性、科学含义、路线停止、Idea 改写与跨证据综合须返回受约束答案并经 Motif 核对后重入 |

每次跳过模型要记录本来会调用的判断点、证据／依赖签名、重验结果和未覆盖风险。Jev 仅是可替换的有界判断端口，不能以概率充当事实证据。工具执行失败先阻断并记录匿名化凭据；重复、可复现的失败才产生守卫修订候选，独立任务质量门通过前不启用。

## 启动主实验还缺的最少信息

1. 确认上面的 AIDD 决定仍是近期真实任务；给出**一句话决定、截止时间、交付读者**。若已换方向，指定现有 idea 的权威状态位置。
2. 指定**一个 Zotero 集合或若干条目 ID**和**一至数篇 Obsidian 笔记路径**，并明确允许读取批注及可发给外部模型的摘录范围。无需先提供整库或私有 seed。
3. 给首轮付费模型的**具体上限**和可接受的报告存放位置；同意前只运行只读快照、预览与无模型检查。Gmail 线程、数值数据、会议对象和后续真实事件可在确有其物时补充。

获得第 1–2 项后先生成只读来源清单与预算预览，让研究者核对。AIDD 可在后续做**单独标记的局部试点**；完整工作流主实验还需真实的数值材料、相关沟通／讨论和可释放的增量事件。第 3 项预算确认也不单独构成启动完整主实验的条件。
