# 真实文献初筛：SSS 外部强基线先读哪两篇

状态：2026-09-28 开发性科研任务。研究者从已有 Zotero 集合中的六篇真实论文条目选择下一步值得读全文和实现的两种强基线。候选覆盖 Agent 调度、推测工具执行、工具值缓存和提示前缀缓存；Obsidian 当前研究判断提供 SSS 的比较目标。任务只要求**摘要级初筛**，不得把未读全文的数字写成已核验结果。

这是日常科研中实际有用的文献阅读优先级决定。Agent 自行选取读取顺序；条目和笔记留在原应用，通过限定只读 MCP 提供。交付待审初筛卡，指出两篇优先阅读全文的理由、至少两篇暂缓的理由、摘要证据边界和一项后续验证动作。原始条目键、来源哈希、批准范围、提示及轨迹保存在 `.local/benchmarks/research-weekly-loop/serving-baseline-triage-20260928/`。

机制预注册：多条独立 Zotero“固定版本→按返回句柄读取元数据”的参数链来自此前独立任务轨迹认证；若模型先固定来源，在线 Motif 可在唯一后继、版本与权限守卫通过时批量读取。挑选哪两篇、判断可比性和后续实验仍由模型完成。同题普通 Harness 与 Motif 使用 DeepSeek Flash、`reasoning_effort="off"`、相同工具和提示，每组 US$2 费用闸。此任务与先前缓存基线设计题同属系统研究项目，不能当作跨项目独立留出；它也不评价全文阅读或真实增量事件。
