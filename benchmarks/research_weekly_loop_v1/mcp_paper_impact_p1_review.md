# P1 论文影响卡：运行前的评审核查表

本文件不进入 Agent 上下文。P1 与此前 AIDD 大任务共享来源和研究决定，因此首轮只作**开发试跑**，不算一个新的独立 Motif 训练任务或留出成绩。

## 来源与任务边界

- 已批准的 AIDD 范围中选 `current_state`、`open_questions`、`antibody_pdf`、`antibody_item` 与六个 `antibody_annotation_*` 角色；运行时用版本／哈希重新核验。其余批准来源本轮不必暴露。
- 既有批准记录绑定了先前大任务的提示词与工具配置。P1 付费模型试跑前须生成本题独立预算／来源／提示词预览，并按项目批准流程记录确认；不能改写旧批准记录。
- 不把上次 AIDD Agent 的答案、未来 PBCNet 增量事件或本表给本轮 Agent。
- 文献发现仅核对必要公开来源；没有新论文也不判为缺失。Quarto 渲染可在卡片内容通过核对后由同一运行环境完成，不为多一次 MCP 调用强制模型制作无用格式。

## 人工质量门

1. 是否准确描述 Obsidian 当时的旧判断，并标出主张范围？
2. 论文作者主张、正文方法／结果、Zotero 人的批注和 Agent 推断是否分开？重要事实是否定位到论文页或批注？
3. 是否明确回答“这篇论文改变了什么”，而不是泛泛综述？答“没有改变”也必须有证据。
4. 下一步是否具体且与未解决的问题相称？是否遗漏反证或把未读页当成已读？
5. 研究者实际修订分钟和是否愿意保存此卡；不合格时记录重大错误与补救成本。

## 机制观察门

逐模型请求记录当前问题、工具 schema／顺序、调用参数来源、返回版本、未命中／命中输入、输出 token、费用、重试与失败。逐工具记录 `可用 → 暴露 → 调用 → 成功 → 对卡片有贡献`。标出是否有独立的模型轮次只做已经被来源句柄和参数流决定的读取；若该轮还选择页码或判断科学含义，就不算安全跳过。后续仅比较**实际执行过的** Motif／缓存条件，不把离线候选当节省。

P1 初次影响判断是轨迹与质量试跑，**不预期凭任务描述直接跳过模型**。若基线没有可分离的确定性轮次，或下一轮没有由真实事件给出的条目／主张绑定，本任务族不进入“跳过模型请求”的 Motif 对照；转用更合适的任务或缩小为缓存工程实验。
