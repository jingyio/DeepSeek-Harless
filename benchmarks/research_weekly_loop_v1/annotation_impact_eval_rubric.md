# 跨应用批注影响卡的人工验收

两条新任务及其普通 Harness／Motif 组共用此表。评审者先看去掉路线标识的答案，再看工具轨迹。模拟释放的历史批注不能写成真实新增事件。

每项记 0（错误／缺失）、1（部分满足）、2（满足）：

1. 准确找回原有研究判断，并说明本次要决定哪一部分。
2. 逐条区分 Zotero 批注、论文作者结论、PDF 实测和 Agent 推论；关键事实可定位到批准来源。
3. 正确核对版本、附件与论文关系及 PDF 页码；来源不明时如实标记。
4. 维持、收窄、修改或暂缓的决定与证据强度相称，明确支持、反证和迁移边界。
5. 给出一个研究者可以执行的最小后续阅读或实验动作。

合格门槛为总分至少 8/10，且第 2、3 项均不为 0。把附件当成另一篇论文、伪造新批注、将别的系统结果当作当前系统实测，均为关键错误并判不合格。若 Motif 得 7 分且无关键错误，可记录为“可修订草稿”，但不能称与合格基线等质。另记录人工修订分钟数、工具失败、完整模型请求数、缓存命中／未命中 token、输出 token、账单可核对费用和端到端耗时。
