# AIDD 增量事件 01：公开基准数据到位

**任务关系**：这是 F1-02 初始 AIDD 研究决定的后续资料事件，供同一任务的局部更新与恢复评测使用。它不是第二个独立研究任务，不能用来凑 Motif 的跨任务支持度或留出题。

## 给科研 Agent 的任务

你先前给研究者的 AIDD 决定材料把 PBCNet2.0 突变基准的平均 Spearman 约 0.53 标成“正文引用、补充数据未核验”，并建议先做训练／测试泄漏审计。现在作者仓库的突变测试 `predict.csv`、对应补充表和 Zenodo 的训练索引已作为新的公开资料到位。请在读过你原先的决定材料和这些新资料后，向研究者交付一份**增量修订**：哪些数值或判断现在可以核实，哪些仍未核实；原先“本周最有价值的取证行动”是否仍然可执行、应如何缩小到真正可完成的一步；这是否改变启动最小实验或暂缓原型的决定。允许维持原决定，也允许推翻它，但要说明新旧证据如何导致该决定。

资料入口：原先的 `paid-run-01/finish-01/agent-answer.md` 由运行器在本机私有任务目录提供；公开资料的冻结来源与各文件哈希见 `pbcnet_mutation_public_manifest.json`。原始 CSV／XLSX 快照由运行器放在 `.local/benchmarks/` 下的任务输入目录。研究者可用的结构化 MCP 支持来源固定、字段检查和按指定字段计算统计量；Python 也可用于独立复算或超出工具能力的探索。Agent 自行决定检索、计算和阅读顺序，不要求调用指定工具或达到某个调用次数。

交付中区分四层：作者论文声称的结果、公开文件可重算的数字、训练／测试独立性的证据、对当前 Idea State 的研究建议。特别是，如果只能匹配文件名，不能把“字面没有重合”写成“没有生物学泄漏”。任何要修改 Obsidian、发送邮件、安排日历或调用付费训练资源的后续动作只列为提案，本轮不执行。

## 运行与评分边界

- 运行前固定原回答、公开来源、Agent 工具配置和费用预算；初始任务与此事件共用一份研究决定链，续写和额外模型请求均计入增量总成本。
- 评审重点：数字复算是否正确且可追溯；是否发现训练索引缺蛋白序列、口袋残基与沉积年份；是否提出可执行的下一项取证行动；是否把相关系数重现与科学泛化证据分开。评审不根据 MCP 调用数量打分。
- Motif 路线只能复用已有轨迹证明的局部结构；新数据对原判断造成的失效范围必须记录。普通 Harness、窄上下文／缓存和 Motif 在同一来源和交付质量门下比较。人工准备的脚本与冒烟调用不得计入 Agent 轨迹。
