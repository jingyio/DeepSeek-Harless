# DR³-Eval 中文任务 003：公开质量对照输入

本任务取自 [DR³-Eval 官方数据](https://huggingface.co/datasets/NJU-LINK/DR3-Eval)，固定到 `manifest.json` 的仓库版本、任务 ID、32k 文本资料库与文件 SHA-256。问题是根据一篇 3D 高斯溅射重定位论文，结合资料库对比从粗定位到精优化的近期算法。它用于测试**真实研究报告质量**，不是归档或增量更新题。

将原始资料下载到被忽略的 `.local/`，并把资料库切成 SSS 可读取的逐文件文本：

```bash
python3 scripts/prepare_dr3_zh003.py
```

准备后的 `query.md` 是题目，`sources/` 含一篇原论文和 15 份固定资料库摘录。生成的文本文件保留原始网页标题并注明它是 benchmark 快照。预处理不改变答案或追加外部搜索；所有方法应读相同的输入。`answer_points.json` 是 SSS 为本地流程准备的补充评分清单，**不属于 DR³-Eval 官方题面**；同题实验若使用它，应同时提供给各组并单独标注设置。正式 DR³-Eval 分数应走[官方评估实现](https://github.com/NJU-LINK/DR3-Eval)，并抽样人工核查事实、引文与比较质量；SSS 当前程序尚未完成该评估接线。原 benchmark 还含图片／视频任务，本条专选文本范围，不代表全量成绩。

2026-09-25 将 SSS 补充清单的 `methods` 项加上 `min_sources: 2`，要求比较至少绑定两份不同资料。旧版保留在 `answer_points.v1.json`，现行版为 `answer_points.json`。这是**实验设置修订**，不是对官方题面或答案的修改；不同版本的结果必须分开报告。

DR³-Eval 提供多文件报告任务和固定资料库，但不直接测试同一报告在新来源加入后的状态失效。后者由 SSS 的[合成机制回归题](../office_research_v0/README.md)补充；两类分数应分开报告。

**无模型预览记录（2026-09-25）：** 首次读取 16 份来源时，`research-points.py` 在规划提示超过 8,000 字符处停下；随后将每份来源的标题和与题目相关的片段纳入自适应预算，重跑预览保留全部 16 份来源、31 页与 4 个必答点，提示为 7,808 字符。片段按最终长度重新选择，防止裁剪时丢掉方法关键词。这只是模型调用前的结构容量检查；尚未调用 DeepSeek，也没有报告质量或 DR³-Eval 分数。详见[基准登记](../../experiments/办公科研基准选型与冻结.md)。

来源读取现由迁移的 Motif 状态／绑定证据模块执行。一次预览后将结果保存为 `motif-source-state.json`，再次用 `--previous-source-state /path/to/motif-source-state.json` 运行会先核对每份文件哈希，复用未变来源、使已变或移除来源失效。公开题本机第二次预览实际复用了 16 份来源、重读 0 份，仍得到 31 页和相同的 7,808 字符规划输入。规划边界写入 `planning-handoff.json`。这验证的是来源快照与恢复机制；检索、选页和综合的 Motif 内核迁移仍待完成。

另在**临时副本**中给 `web-01.txt` 追加一条测试更正，未触及冻结资料；再次读取时 Motif 依赖签名仅使该文件失效，记录为复用 15、重读 1、失效 1。两次预览的规划输入长度因命令行是否保留题目末尾换行分别是 7,808 和 7,809 字符，两者都在 8,000 字符限制内。

**双来源比较诊断（无模型）：** 用本地手写、非官方的检索计划进入选页阶段，每个必答点得到 4 个候选；`methods` 的候选包含 RegGS 与 3R-GS 所在的不同资料。以绑定候选指纹的本地选择文件继续预览，结构层重验了两份资料并打包出 10 个可引用片段；综合输入 9,037 字符，未调用模型。运行记录在被忽略的 `.local/point-research-runs/20260925T010817Z-46cc18/`。这些候选和手选证据只检验执行链及预算，**不能算作报告质量成绩**。

为每个必答问题挑选的原文证据现在保存为 `motif-selection-state.json`，依赖该问题的候选指纹和要求签名。使用 `--previous-selection-state` 再次预览时，4 项选择全部复用、综合输入仍为 9,037 字符且调用数为 0；修改某项候选或要求，只使该项旧选择失效。手写计划与手选证据仅存 `.local/benchmarks/dr3-zh003/`，避免把它们误当成官方 benchmark 答案。[Motif skill 进化机制记录](../../experiments/EvoGraph启发的MotifSkill进化.md)对比了全局依赖与逐问题依赖在两份临时资料变化时的安全复用数，尚不涉及报告质量分数。

后续增加了双来源**输出覆盖门**：`methods` 不仅要选两份资料，最终被接受的结论也必须实际引用两份不同来源，否则状态为 `insufficient_sources`。输出改为按必答点、未知项和证据索引组织的可审阅简报。新增提示后无模型综合输入为 9,295 字符，仍低于 16,000 字符上限；旧 9,037 字符数字对应先前提示版本。两来源引用仍不能证明方法比较正确，需人工判断语义蕴含、遗漏和报告完整度。
