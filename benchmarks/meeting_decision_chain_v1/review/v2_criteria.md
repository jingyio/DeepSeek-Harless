# v2 封存评审包：仅供事后盲评

下面三题全部为合成研究决定，均不参与 Motif 编译、独立认证或相似度门槛校准。先匿名评估答案的可核查性和研究判断，再看模型请求、费用和时间。两组分别记录：合格／不合格、人工修订分钟数、需修改的事实、格式问题。不能因某组跳过模型请求就放宽质量门槛。

## `site_transfer`

- 当前总体：基线 162/240 = 67.5%，候选 168/240 = 70%，仅 +2.5 个百分点。
- 内站：基线 90/120 = 75%，候选 102/120 = 85%。外站：基线 72/120 = 60%，候选 66/120 = 55%。
- 上一轮外站候选 78/120 = 65%；新结果跌 10 个百分点。内站数据不变。
- 必须收窄或暂停“可迁移到外站”的旧主张；优先说明采集口径审查或外站独立验证。不能由整体提升推断外站受益。

## `tail_terms`

- 当前总体：基线 168/240 = 70%，候选 171/240 = 71.25%，仅 +1.25 个百分点。
- 高频：基线 96/120 = 80%，候选 108/120 = 90%。低频：基线 72/120 = 60%，候选 63/120 = 52.5%。
- 上一轮低频候选 75/120 = 62.5%；新结果跌 10 个百分点。高频数据不变。
- 必须收窄或暂停低频术语覆盖主张，说明词频分箱／词表版本的核查与独立低频样本复测的先后。

## `lot_stability`

- 当前总体：基线 30,000/240 = 125 ms，候选 31,200/240 = 130 ms；候选已无整体延迟优势。
- 批次 A：基线 100 ms，候选 90 ms；批次 B：基线 150 ms，候选 170 ms。
- 上一轮批次 B 候选 140 ms；当前上升 30 ms。上一轮整体候选 115 ms。
- 必须撤回“整体更快”的旧主张，区分批次 A 的描述性改进和批次 B 的退化；下一步核查批次校准或做同批次配对测量。不能直接把批次效应归因为算法变化。

## 共同判定

- 必须读取必要的实验数据、旧主张与虚构批注，给出当前/上一轮版本依据；不得把虚构资料写成真实论文或真实课题组结果。
- 在数字没有支持时不能沿用旧结论；未提供统计推断时不能宣称显著性或因果。
- 交付应为可直接渲染的 Markdown 主体，不能只给代码围栏或工具日志。
- 质量合格后才比较实际 API 请求数和总费用；费用分开报告未缓存输入、缓存命中输入、非推理输出、推理输出（后两者可按同一输出价合并计费）。逐请求区分最终写稿前和最终写稿请求，同时报告总推理 token，不能只看最后一轮。
- 每项配对是两个独立会话；即使条件相同，单项成本差仍可能有会话波动。不得用三题同一种结果推广到全部科研办公任务。
