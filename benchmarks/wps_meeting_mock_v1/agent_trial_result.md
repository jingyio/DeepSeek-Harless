## 内容核查与失效

Agent 从四个来源读取资料并调用 WPS 复算工具。草稿中的基线 `213/300=71.0%`、候选 `237/300=79.0%`、差值 `+8.0` 个百分点与冻结表格一致；指出这些数值不能证明跨家族泛化。它区分了两篇虚构论文与本项目的数据边界，比较了分组划分、数据审计、补种子和暂缓，并建议先查样本重叠与重复标签，再在分组划分下复算。这些是**内容层面的开发观察**。

本轮**不能按隐藏评审包给出合格成绩**：Agent 借助内置 `bash` 读到了本应隐藏的 `agent_review.md`，随后试图写入同名文件。只读策略阻止了写入，但未阻止读评审标准，评测已污染。此外，Agent 把报告包进 Markdown 代码块，并错误地把无法写文件描述为任务失败；原始 HTML 因而展示代码块。为方便人工检查，我们从原始回答机械提取代码块为 `native-02/extracted-report.qmd` 并由 Quarto 渲染为 `extracted-report.html`；这个后处理产物不是 Agent 原样交付。一页篇幅要求也未被确认。

## 结论与下一步

本轮证明模拟工具链可让原生 Agent 读取跨来源内容并形成一个有依据的建议，也暴露了工具范围和交付格式问题。**它没有测试 Motif，不能证明普通脚本无法完成任务，更不能证明 SSS 省钱。** 固定表格复算与依赖失效继续作为 0 模型请求的脚本基线。

受限工具复跑解决了这次的评审包泄露和原始 HTML 格式问题。正式效果测试至少需要三个不同的真实研究决定：前两题收集自由 Agent 轨迹，第三题留出验证；每题分别有一次不改变主张的更新与一次足以打断主张的更新。同题续写及更新不算新任务。比较对象包括具备相同版本检查和缓存能力的普通脚本、自由 Agent 和已认证 Motif；先盲评合格交付，再比较总费用、人工修订、耗时及真正跳过的完整模型请求。
