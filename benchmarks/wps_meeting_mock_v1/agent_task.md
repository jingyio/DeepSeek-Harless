# 合成组会任务：下一步先做什么？

你协助研究者准备本周组会的一页审阅稿。研究者正在评估一个候选方法，目标是提升**未见过的目标家族**上的泛化。本周需要决定：先做分组划分验证、先核查数据质量、补重复实验，还是暂缓这条路线。可以提出其他有证据支持的行动，也可以说明目前不能决定。

已圈定的只读资料分散在三个模拟应用中。请通过工具读取需要的内容，不要把文件名或论文题名当作结果：

- WPS 实验表：`wps:experiment_log`；
- Obsidian 当前研究状态：`obsidian:idea_state`；
- Zotero 已读论文及批注：`zotero:split_study`、`zotero:replication_study`。

交付一页可由 Quarto 渲染的 Markdown 草稿，给出可复算数字、支持和反对各行动的证据、证据的适用范围、未决问题，以及你建议的下一步。**最终回答只输出 Markdown 正文，不加代码围栏，不尝试创建或修改文件；执行器会负责保存并渲染。**区分虚构论文作者结果、研究者批注、表格实测和你自己的推断。若资料不足以作决定，请明确说明缺口。不要改写这些模拟应用的来源。这里的所有内容都是**合成夹具**，不能作为真实论文或科研结论引用。

任务只规定交付和允许读取的范围，不规定工具顺序、必调次数、答案或未来增量事件。
