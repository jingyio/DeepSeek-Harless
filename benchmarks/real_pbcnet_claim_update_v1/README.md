## 运行与评分边界

1. 执行包只包含 [task.md](task.md)、批准的来源角色、实际工具 schema、预算预览和当次来源锁；旧审计结论、复算结果及评审标准不能进入 Agent 工作区。尤其不能让 Python 列出评审目录。
2. 先用同一来源与工具顺序运行普通 DeepSeek Harness，再用**从其他独立任务轨迹认证、且兼容真实工具 schema** 的 Motif 做对照。两组都显式关闭思考模式；记录逐请求缓存命中／未命中、输出、失败、MCP 调用、实际跳过、时间和费用。没有兼容产物时，本题先收集原生轨迹，不手写本题专用 Motif 冒充迁移。
3. 研究者先匿名审阅数字、泄漏边界和行动建议，再比较合格交付的费用与人工修订时间。当前既有的 AIDD 初始决定及其增量属于**同一决定链**，不能算两个独立任务或新的留出题。
4. 预期的结构机会是来源版本固定与复算时的参数传递；是否形成可跳过的完整模型轮次由真实轨迹决定。若普通 Harness 一次请求就选完工具，或需要模型先确定统计口径，可能跳过 0 次。Quarto 渲染和单纯复算也可能被普通程序完成，须分开归因。

这是一项已有材料支撑、可以产生有用科研修订的**真实资料回放任务**；尚未对这个新执行包做付费 A/B 或独立人工盲评。它检验合成任务的结构能否迁移到真实来源，不能预先继承合成任务的节省比例。
